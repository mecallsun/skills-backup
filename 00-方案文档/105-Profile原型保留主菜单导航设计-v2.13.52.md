## 四、设计原则

### 4.1 一致性 > 个性化

个人中心虽是独立场景，但**保留主菜单 Tab 导航**：

| 设计原则 | 应用 |
|---------|------|
| **导航一致性** | 用户在任意页面（包括 Profile）都能直接点击 10 个主菜单 Tab 跳转，不丢失上下文 |
| **入口一致性** | 顶部品牌栏的「管理员」胶囊是入口，所有页面行为相同 |
| **快捷键一致性** | Ctrl+1~9/0 切换 Tab 在 Profile 页面同样生效 |
| **视觉一致性** | 所有页面 Tier 1+3 高度固定 88px，用户体验一致 |

### 4.2 8 子菜单 vs 10 主 Tab 的层次区分

```
主菜单（Tier 3，横向 Tab）：
├ 首页 / 办理登记 / 住宿管理 / 人员清单 / 费用标准 /
├ 住宿账单 / 员工账单 / 抄表记录 / 基础资料 / 系统设置
│
└ [用户胶囊点击 → Profile 入口]
    ↓
子菜单（Tier 4 内，左侧 200px pills，垂直）：
├ 账号总览 / 基本资料 / 修改密码 / 安全问题 /
├ 微信绑定 / 偏好设置 / 筛选缓存 / 操作日志
```

**层次清晰**：主菜单（业务模块切换）+ 子菜单（账号设置功能）= 完整两级导航。

## 五、tab-bar.js 行为确认

### 5.1 当前实现（v2.13.51 状态）

```javascript
// _shared/tab-bar.js
const FIXED_TABS = [
    { id: 'tab-home',          title: '首页',       url: 'index.html' },
    { id: 'tab-booking',       title: '办理登记',   url: 'booking/index.html' },
    // ... 10 个固定 Tab
];

function inferActiveTabId(currentUrl, basePath) {
    // 按路径前缀匹配
    if (url === 'index.html') return 'tab-home';
    if (url.startsWith('booking/')) return 'tab-booking';
    // ... 10 个 Tab 匹配规则
    // 不匹配时默认 tab-home（高亮首页）
    return 'tab-home';
}
```

- 渲染 10 个 Tab（无变化）
- URL `profile/index.html` 不匹配任何 Tab 路径前缀
- **默认高亮「首页」Tab**（不影响用户操作，仅视觉提示）

### 5.3 不修改 tab-bar.js

v2.13.52 明确决定：**不动 tab-bar.js**，保留当前"个人中心页面也显示主菜单 Tab"的统一行为。
