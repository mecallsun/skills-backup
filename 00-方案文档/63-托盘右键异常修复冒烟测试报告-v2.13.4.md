## 4. 风险评估

### 4.1 已消除风险

| 原风险 | v2.13.4 缓解措施 |
|--------|----------------|
| 右键 → 系统设置 "创建窗口出错" | OwnerForm + MainForm + ShowDialog(_ownerForm) |
| AboutForm Font 为 null 时 NRE | SafeMessageBoxFont 三层兜底 |
| SettingsForm 单点失败拖死构造 | 拆分 InitializeControls + 整体 try-catch |
| 单次弹窗失败拖死右键菜单 | SafeInvoke / SafeInvokeAsync / SafeShow 三层兜底 |
| 双 UI 职责不清 | "系统设置..."明确命名 + 字段与 CLAUDE.md 一致 |

### 4.2 残余风险

| 风险 | 缓解 |
|------|------|
| FolderBrowserDialog 在 Win11 高 DPI 下偶发 COMException | `BrowseImageFolder` 包 try-catch + 提示手动输入 |
| 端口被占用导致 Api/Admin 启动失败 | `ProcessManager.StartApiAsync` 已检测 + 抛 `InvalidOperationException` |
| 5 分钟内重启 > 3 次 | `CanAutoRestart` 已限制 + 弹窗提示 |
| 用户退出但子进程未结束 | `ExitAsync` + `Process.Kill(entireProcessTree: true)` |

## v2.13.109 备注：SQLite Provider 彻底移除

自 v2.13.109 起，DormManage 运行时仅支持 SQL Server。SQLite 代码路径、EF Core SQLite Provider、SQLite 备份恢复逻辑均已移除。历史配置中的 SqlitePath 字段仅为旧配置反序列化兼容，不代表运行时继续支持 SQLite。生产数据库初始化以 init_schema.sql 和 SQL Server 运维脚本为准，不使用 EnsureCreated()。
