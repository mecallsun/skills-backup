# 用户管理列表「最后登录」拆分（v2.13.186）

> **版本**：v2.13.186  
> **日期**：2026-07-27  
> **类型**：UI 字段拆分 + 历史数据兼容  
> **用户原话**：「对 用户管理 列表中，将 最后登录 拆分为 最后时间 和 登录IP 两项，并对历史数据按规范处理」

---

## 一、规则定义（v2.13.186 系统级唯一真相）

### 1. 列定义

| 列名 | 数据源 | 格式 | 空值占位 |
|------|--------|------|---------|
| **最后时间** | `SysUser.LastLoginTime` (DateTime?) | `yyyy-MM-dd HH:mm` | `从未登录`（灰色）|
| **登录IP** | `SysUser.LastLoginIp` (string?) | 原样输出 | `—`（灰色短横线）|

### 2. 渲染规则

```csharp
// 最后时间列
if (u.LastLoginTime.HasValue)
{
    // 输出 u.LastLoginTime.Value.ToString("yyyy-MM-dd HH:mm")
}
else
{
    // 输出 <span class="text-muted">从未登录</span>
}

// 登录IP列
if (!string.IsNullOrEmpty(u.LastLoginIp))
{
    // 输出 <code>u.LastLoginIp</code>
}
else
{
    // 输出 <span class="text-muted">—</span>
}
```

### 3. 历史数据兼容（零迁移）

**所有现有 SysUser 记录自动兼容**，**无需数据迁移 SQL**：

| 数据库状态 | UI 显示（最后时间列） | UI 显示（登录IP列）|
|----------|---------------------|-------------------|
| `LastLoginTime IS NULL` | `从未登录`（灰色）| `—`（灰色）|
| `LastLoginTime IS NOT NULL`, `LastLoginIp IS NULL` | 具体时间（黑/灰色）| `—`（灰色）|
| `LastLoginTime IS NULL`, `LastLoginIp IS NOT NULL` | `从未登录` | IP 值 |
| `LastLoginTime IS NOT NULL`, `LastLoginIp IS NOT NULL` | 具体时间 | IP 值 |

数据库 schema 完全不变（v2.13.92 起即有 `LastLoginTime` 和 `LastLoginIp` 两个独立字段），仅 UI 渲染从单列拆分为两列。

## 二、数据模型

**文件**：`DormManage.Shared/Models/SysUser.cs`

```csharp
public class SysUser
{
    // ... 其他字段 ...

    // v2.13.92 起存在的独立字段
    public DateTime? LastLoginTime { get; set; }  // 最后登录时间
    public string? LastLoginIp { get; set; }      // 最后登录 IP

    // ... 其他字段 ...
}
```

**字段来源**：
- `LastLoginTime`：用户登录成功后由认证服务更新（`Account/Login` POST handler）
- `LastLoginIp`：同 handler 从 `HttpContext.Connection.RemoteIpAddress` 读取

**v2.13.186 之前的行为**：两个字段在同一列内显示（time 在上、IP 在下）
**v2.13.186 起的行为**：两个字段拆分为独立两列

## 八、v2.13.186 永久教训

1. **数据模型先行原则**：v2.13.92 已设计两个独立字段（`LastLoginTime` + `LastLoginIp`），v2.13.64 UI 单列展示是「显示未到位」而非「模型设计错误」。本版本只是修复 UI 渲染逻辑，验证了**数据模型先行**原则的正确性。

2. **历史数据零迁移**：拆分只改 UI 渲染逻辑，所有历史数据（无论 `LastLoginIp` 是否为 NULL）都能正确显示。**不要为简单的 UI 拆分写数据库迁移脚本**。

3. **空值占位符分级**：时间 NULL → 「从未登录」（明确语义）；IP NULL → 「—」（视觉简洁）。两种不同的占位符反映不同的语义层级。

4. **colspan 同步**：列数从 8 → 9，所有 colspan（包括空状态行）必须同步 +1。漏改 colspan 会导致空状态行错位（与 v2.13.185 Personnel colspan BUG 同源）。
