## 一、需求（用户报告原文）

> 程序编程的成果 与 原型相关的实际功能中 各主菜单导航 点击菜单后显示的记录列表中，都缺失了页数设置翻页数，与原型不一致的问题；必须确认程序的所有人员清单/宿舍登记/宿舍档案等多个主菜单下的记录列表中的底部，必须按原型 100%显示

- ❌ 现状：各页用 Bootstrap 默认 `« ‹ 1 2 3 › »` 简单按钮 + `共 N 条记录，第 X / Y 页` 文案（粗略、不符合原型）
- ✅ 必须按原型 100% 显示：
  - 分页器：**« 1 2 3 … 65 »** 智能截断（不是简单 ±2 固定 5 个按钮）

  - 8 个主菜单全部覆盖：人员清单、宿舍登记、宿舍档案、抄表记录、账单、费用标准、系统设置用户管理等

### 2.2 关键技术点

| 功能点 | 实现 |
|--------|------|
| **智能截断 « 1 2 3 … 65 »** | pageNumbers 列表：始终显示第一页 + 当前页 ± 2 + 最后一页，中间用 `-1` / `-2` 占位渲染 `…` |

| **响应式布局** | d-flex justify-content-between，768px 以下 `@media` 自适应堆叠（Bootstrap 默认） |

## 四、关键代码

### 4.1 智能截断算法

```cshtml
var pageNumbers = new List<int>();
for (int p = 1; p <= totalPages; p++)
{
    if (p == 1 || p == totalPages || (p >= Model.PageIndex - 2 && p <= Model.PageIndex + 2))
    {
        pageNumbers.Add(p);
    }
    else if (p < Model.PageIndex - 2)
    {
        if (pageNumbers.Count == 0 || pageNumbers[pageNumbers.Count - 1] != -1)
        {
            pageNumbers.Add(-1);  // 左侧省略占位
        }
    }
    else if (p > Model.PageIndex + 2)
    {
        if (pageNumbers.Count == 0 || pageNumbers[pageNumbers.Count - 1] != -2)
        {
            pageNumbers.Add(-2);  // 右侧省略占位
        }
    }
}
```

### 4.2 URL 参数保留

```cshtml
string Url(int pageIndex)
{
    var qs = queryString.TrimStart('?').Split('&', StringSplitOptions.RemoveEmptyEntries)
        .Where(p => !p.StartsWith("pageIndex=", StringComparison.OrdinalIgnoreCase) && !p.StartsWith("pageSize=", StringComparison.OrdinalIgnoreCase))
        .ToList();
    qs.Add($"pageIndex={pageIndex}");
    if (Model.PageSize != 20) qs.Add($"pageSize={Model.PageSize}");
    return currentPath + "?" + string.Join("&", qs);
}
```

### 4.3 pageSize localStorage 持久化

```javascript
(function () {
    var moduleKey = (location.pathname || '').split('/').filter(Boolean).pop() || 'list';
    var pageSizeKey = 'pager_pageSize_' + moduleKey;

    window.changePageSize = function (newSize) {
        localStorage.setItem(pageSizeKey, newSize);
        var url = new URL(location.href);
        url.searchParams.set('pageSize', newSize);
        url.searchParams.set('pageIndex', '1');
        location.href = url.toString();
    };
})();
```

## 五、教训

### 5.1 关键教训

1. **重复代码 = 必须抽象**：8 个列表页每页 25-50 行相似分页代码 = ~300 行重复 partial 化后 = 8 行 × 8 页 = 64 行 + 1 个 80 行 partial = 节省 200+ 行且保证统一。
2. **Bootstrap 默认分页 ≠ 原型**：Bootstrap 默认 `« ‹ 1 2 3 › »` 4 按钮是基础实现，原型 `« 1 2 3 … 65 »` 智能截断是大数据场景必备。
3. **PageSize localStorage 持久化是关键体验**：用户上次选 50 条/页，下次进入任何列表页都默认 50 条/页（per-module 隔离）。
4. **URL 参数保留对筛选页非常重要**：原分页代码每页重新拼接一长串参数，partial 化后统一从 `Context.Request.QueryString` 提取，可避免遗漏新参数。

### 5.2 强制检查清单（分页器自检）

- [ ] 8 个主菜单列表页底部都使用 `@await Html.PartialAsync("_PaginationPartial", ...)`
- [ ] 没有手写的 `pagination-footer` 块（除 partial 内部）
- [ ] 没有手写的 `page-item` `<a class="page-link">` 块（除 partial 内部）
- [ ] 没有 `« ‹ 1 2 3 › »` 4 按钮实现
- [ ] 没有 "共 N 条记录，第 X / Y 页" 文案（必须有"第 X-Y 条 · 共 N 页"格式）

违规 grep：
```bash
grep -rn "共.*条记录\|‹\|›\|&lsaquo;&rsaquo;" DormManage.Admin/Pages/  # 不应有命中（除 partial 内部）
```
