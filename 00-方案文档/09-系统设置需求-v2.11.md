## 1. 业务背景

原功能需求缺少「系统设置」模块。系统实际由 **.NET 8 自托管 EXE + 托盘守护** 运行，所有连接串、端口、路径均需可视化配置。

**双 UI 入口职责划分**：

| 入口 | 职责 | 权限控制 |
|------|------|---------|
| **托盘系统配置窗口**（SettingsForm） | 仅配置核心服务端参数（PDA/Web 端口、数据库连接、图片存储路径、服务器域名），**无角色权限项控制** | 仅运维/管理员本地维护 |
| **Web 后台系统设置**（`/Settings`） | 承载全部系统设置功能（服务管理、数据库、PDA版本、用户角色、备份恢复、系统集成、筛选缓存），**受角色权限管控** | 仅管理员可访问 |

> **设计原则**：托盘窗口仅保留系统启动所必需的核心服务端参数配置，其他所有业务配置功能均在 Web 端实现，统一由角色权限体系管控。

**仅「管理员」角色可访问 Web 端「系统设置」模块**（见权限矩阵）。

| 7 | **系统集成** | **HR / K3ERP 系统连接配置（服务器地址/账号/密码/启用状态/连接测试/保存参数）** |

## 3. 字段与规则

### 3.1 服务与端口（方案 6.4.2）

| 字段 | 默认 | 校验 |
|------|------|------|
| PDA 服务端口 | 5000 | 1–65535 |
| Web 服务端口 | 8080 | 1–65535 |
| 服务器域名/IP | 127.0.0.1 | IP / 域名 / localhost，PDA 用此访问 |
| 图片保存路径 | D:\MeterImages | 绝对路径且目录可写 |
| 服务状态 | 运行中/已停止 | 仅显示，联动托盘守护进程启停 |

- 「打开网址」按钮**仅托盘桌面端提供**；Web 后台自身即在浏览器中运行，无需该功能，**Web 端不显示**。
- 端口/路径改动 **保存后需重启对应服务** 生效。

### 3.2 数据库连接（方案 6.4.7）

| 字段 | 默认 | 校验 |
|------|------|------|
| 数据库服务器 | 192.168.1.237 | IP / 主机名 / host,port / host\instance |
| 端口号 | 1433 | 1–65535 |
| 数据库名称 | DormManageDb | 非空 |
| 账号 | __DB_USER__ | 非空 |
| 密码 | — | 非空，掩码显示 |

**读写深度验证（8 步，命中失败即停）**：
```
TCP 连接 → SQL 登录 → 库可见 → CREATE 建表 → INSERT → SELECT → UPDATE → DELETE/DROP 清理
```
> 解决「配置保存成功但服务启动后才发现权限不足」的运维难题。

### 3.3 PDA App 版本管理

- 列表：版本号、大小、发布日期、更新说明、是否最新。
- 发布新版本：上传 APK → 写入 `update.json`（含 releaseNotes）。
- PDA 下载地址：`http://{域名}:{Web端口}/app/download`，抄表员用 PDA 浏览器访问安装最新版。
- 支持回滚（将历史版本设为当前发布）。

### 3.4 用户与角色

**角色（3 种）**：管理员 / 财务 / PDA操作员。

**用户字段**：用户名、姓名、角色、状态（启用/停用）、最近登录、备注。
**操作**：新增、编辑、重置密码、启用/停用。

**角色权限矩阵**：

| 模块 | 管理员 | 财务 | PDA操作员 |
|------|:---:|:---:|:---:|
| 抄表管理 | 增删改查 | 只读 | 仅上传 |
| 宿舍档案 | 增删改查 | 只读 | 无 |
| 办理登记 | 增删改查 | 无 | 无 |
| 人员清单 | 增删改查/导入导出 | 只读 | 无 |
| 费用标准 | 编辑 | 只读 | 无 |
| 账单/分摊 | 生成/发布/导出 | 查看/导出 | 无 |
| 系统设置 | 全部 | 无 | 无 |

> PDA 操作员仅「抄表」（上传），Operator 角色访问 /Personnel 等应返回 403。

### 3.5 备份与恢复（方案第 10 章）

- 自动策略：每日 02:00 全量备份，保留最近 30 天；图片目录随文件系统单独备份。
- 手动「立即备份」；备份历史列表含文件名/大小/时间/类型。
- 支持下载备份、从备份恢复（恢复前二次确认，会覆盖当前数据）。

### 3.7 系统集成

> **新增（v2.11）**：配置系统与外部系统（HR / K3ERP）的连接参数，支持启用状态切换与连接测试。

**功能说明**：

| 功能 | 说明 |
|------|------|
| 系统名称 | 系统显示名称，**可编辑修改** |
| 服务器地址 | 外部系统的 API 服务地址，格式 `http(s)://host:port`，**可编辑修改** |
| 账号 | 用于 API 认证的连接账号，**可编辑修改** |
| 密码 | API 认证密码，掩码显示，AES-256 加密存储，**可编辑修改** |
| 是否启用 | 开关控制，启用后系统才会尝试与该外部系统通信 |
| 连接测试 | 点击按钮向外部系统发送 HTTP 请求，验证连通性与认证有效性 |
| 保存参数 | 将配置写入数据库（密码加密后存储），**仅具有"修改"权限的用户可见** |

**HR 系统接口说明**：
- 可获取：员工花名册、在职状态、最近 3 个月离职人员、员工考勤班次类型

**K3ERP 系统接口说明**：
- 可获取：员工花名册、在职状态

**字段与规则**：

| 字段 | 默认 | 校验 | 编辑权限 |
|------|------|------|---------|
| 系统编码 | HR / K3ERP | 预置两条记录，不可删除 | 只读 |
| 系统名称 | 人力资源系统 / K3 ERP 系统 | 非空 | 可编辑 |
| 服务器地址 | — | 必填，格式 `http(s)://host:port`，URL 合法性校验 | 可编辑 |
| 账号 | — | 必填，非空 | 可编辑 |
| 密码 | — | 掩码显示，AES-256 加密存储 | 可编辑 |
| 是否启用 | 停用 | 开关控制，默认停用 | 可切换 |
| 连接测试结果 | — | 点击测试后显示，成功/失败及响应时间 | 只读 |

**页面布局**：

```
┌─────────────────────────────────────────────────────────────────────┐
│ 系统集成配置                                                         │
│ ┌──────┬──────────┬──────────────────────────┬──────────┬────────┬──┬──────┬──────┐ │
│ │系统编码│ 系统名称  │ 服务器地址                │ 账号     │ 密码   │启用│ 操作  │连接状态│ │
│ │ HR   │[人力资源..│ http://hr..:8080/api      │ hr_user  │ ●●●●●  │☑️  │🔌测试│连接成功│ │
│ │ K3ERP│[K3 ERP.. │ http://erp..:8081/api     │ k3_user  │ ●●●●●  │☐   │🔌测试│ 未测试 │ │
│ └──────┴──────────┴──────────────────────────┴──────────┴────────┴──┴──────┴──────┘ │
│ [ 保存参数 ]  （仅具"修改"权限的用户可见）                                       │
└─────────────────────────────────────────────────────────────────────┘
```

**交互流程**：
```
1. 用户编辑系统名称、服务器地址、账号、密码（全部可编辑）
2. 点击「连接测试」→ 发送 HTTP 请求验证连通性 → 在"连接状态"列显示结果
3. 点击「保存参数」→ 加密密码 → 写入数据库（仅具"修改"权限可见）
4. 切换「启用」开关 → 即时生效，影响数据同步任务调度
```

**权限控制**：
- 「保存参数」按钮仅在用户具有"修改"权限时显示
- 系统编码列只读，不可编辑
- 其余字段（系统名称/服务器地址/账号/密码）均可编辑

## 6. UI 与交互要求

- 左侧竖向 pills 导航（宽度固定 200px）+ 右侧 tab 面板，**左右两侧上边严格水平对齐（flexbox 布局 `display: flex; align-items: flex-start; gap: 12px`）**，单页内切换，专业紧凑。
- 所有列表页筛选条件区域使用 `flex-nowrap` 一行排列，根据屏幕宽度自适应调整字段宽度。
- 服务状态用绿/红圆点 + 文字实时展示；启停即时联动。
- 数据库测试逐步反馈 8 步结果；全部通过时高亮成功。
- 危险操作（恢复数据库、停用用户）二次确认。
- 仅管理员可见「系统设置」导航入口。

## 7. 双 UI 职责划分

| 入口 | 职责范围 | 权限控制 |
|------|---------|---------|
| **托盘系统配置窗口**（SettingsForm） | 核心服务端参数：PDA/Web 端口、数据库连接、图片存储路径、服务器域名、服务启停、保存参数 | **无角色权限项控制**，任何本地用户均可打开和修改 |
| **Web 后台系统设置**（`/Settings`） | 全部系统设置功能：服务管理、数据库、PDA版本、用户角色、备份恢复、系统集成、筛选缓存 | **仅管理员可访问**，各子功能受角色权限矩阵管控 |

> **设计原则**：托盘窗口仅保留系统启动所必需的核心服务端参数配置，确保运维工程师在紧急情况下能够快速修改端口、数据库连接等关键参数；Web 端承载全部业务配置功能，统一由角色权限体系管控。
