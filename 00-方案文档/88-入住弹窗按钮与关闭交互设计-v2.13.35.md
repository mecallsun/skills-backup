## 一、5 种关闭触发器 + 1 种提交触发器

### 1.1 触发器矩阵

| # | 触发器 | 原型 | 实现 | 关闭前确认 |
|---|--------|------|------|-----------|
| 1 | **取消按钮** | `<a href="index.html" class="btn btn-outline-secondary">` | `<button id="ciBtnCancel">` | ✅ confirmCloseCheckIn |
| 2 | **X 关闭按钮** | 原型无 modal（独立页面无 X） | `<button id="ciBtnClose">` | ✅ confirmCloseCheckIn |
| 3 | **ESC 键** | 原型无 modal | Bootstrap 默认 keyboard.esc | ✅ hide.bs.modal 拦截 |
| 4 | **backdrop 点击** | 原型无 modal | Bootstrap 默认 backdrop click | ✅ hide.bs.modal 拦截 |
| 5 | **页面跳转** | `<a href="index.html">` | history.back() | ❌ 浏览器原生 |
| 6 | **提交按钮** | `<button type="submit">` + `<form onsubmit>` | `<button type="submit">` + `<form onsubmit>` | ❌ 直接提交 |

### 1.2 关闭确认机制

```
用户触发关闭（取消/X/ESC/backdrop）
    ↓
hide.bs.modal 事件触发
    ↓
isCheckInFormDirty() 检查是否已选员工
    ├─ 是 → e.preventDefault() → confirm('已选择员工【姓名】，确定放弃...')
    │      ├─ 用户确认 → dataset.allowClose=1 → 触发 modal.hide() → 真正关闭
    │      └─ 用户取消 → 不做任何操作（弹窗保留）
    └─ 否 → 直接放行（弹窗关闭）
```

```html
<button type="button" class="btn btn-outline-secondary" id="ciBtnCancel">
```

**关键设计**：

## 三、modal 行为配置（v2.13.35 新增）

```html
<div class="modal fade" id="checkInModal"
     tabindex="-1"
     aria-labelledby="checkInModalLabel"
     aria-hidden="true"
     data-bs-backdrop="static"
     data-bs-keyboard="false">
```

**关键设计**：

- ✅ 移除所有 `data-bs-dismiss="modal"`：统一改用 JS 拦截

## 四、JS 函数详细说明

### 4.1 isCheckInFormDirty() — 脏表单检测

```javascript
function isCheckInFormDirty() {
    return selectedCiEmp != null;
}
```

**判定逻辑**：只要选中了员工（selectedCiEmp 不为 null），即视为"已输入内容"。
**未触发情况**：
- 员工搜索框输入文字但未选择（视为试探，可丢弃）
- 日期选择但未选员工（视为调整参数，可丢弃）
- 操作类型 radio 切换（无副作用，可丢弃）

**触发情况**：
- 选中员工（核心状态，需要确认）

### 4.2 confirmCloseCheckIn() — 显式关闭

```javascript
function confirmCloseCheckIn() {
    if (isCheckInFormDirty()) {
        if (!confirm(`已选择员工【${selectedCiEmp.realName}】，确定放弃当前录入并关闭吗？`)) {
            return false;
        }
    }
    const modalEl = document.getElementById('checkInModal');
    const modal = bootstrap.Modal.getInstance(modalEl);
    if (modal) modal.hide();
    return true;
}
```

**调用方**：取消按钮 + X 关闭按钮
**行为**：先弹确认（如果有员工），再 hide

### 4.3 hide.bs.modal 拦截（被动关闭）

```javascript
ciModal.addEventListener('hide.bs.modal', function (e) {
    if (ciModal.dataset.allowClose === '1') {
        ciModal.dataset.allowClose = '0';
        return;  // 已通过 confirmCloseCheckIn 主动确认过 → 直接放行
    }
    // ESC / backdrop 触发 → 走确认逻辑
    if (isCheckInFormDirty()) {
        e.preventDefault();
        if (confirm(`已选择员工【${selectedCiEmp.realName}】，确定放弃当前录入并关闭吗？`)) {
            ciModal.dataset.allowClose = '1';
            bootstrap.Modal.getInstance(ciModal).hide();
        }
    }
});
```

**调用方**：ESC 键 + backdrop 点击 + 外部 .hide() 调用
**双重确认机制**：`dataset.allowClose` 标记位防止 hide.bs.modal 被多次触发时重复弹窗

### 4.4 form onsubmit — Enter 自动提交

```html
<form id="checkInForm" onsubmit="event.preventDefault(); submitCheckIn(); return false;">
```

**调用方**：Enter 键（任何 form 内的 input 元素） + 提交按钮点击
**行为**：先 preventDefault 阻止 form 默认 POST 行为，再调用 submitCheckIn() 走 fetch API
