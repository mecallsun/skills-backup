## 5. 一键部署指南

### 5.1 用户操作（Windows）

1. **打开** `publish-final\V1.0\` 目录
2. **右键** `deploy.bat` → **以管理员身份运行**（重要！）
3. 等待脚本自动完成：
   - 检查 .NET 8 Runtime
   - 写入数据库连接
   - 启动 API（5100）+ Admin（5200）
   - 健康检查
4. 浏览器自动打开 `http://localhost:5200/Personnel`

### 5.2 访问地址

| 服务 | URL |
|------|-----|
| API Swagger | http://localhost:5100/swagger |
| API 人员清单 | http://localhost:5100/api/v1/personnel |
| Admin 首页 | http://localhost:5200/ |
| Admin 人员清单 | http://localhost:5200/Personnel |
| Admin 宿舍管理 | http://localhost:5200/Dorms |
| Admin 基础资料 | http://localhost:5200/Basics |

### 5.3 部署状态

**当前主机环境**：由于 WDAC（Windows Defender Application Control）策略限制，`bash` 子进程无法加载未签名 .NET 程序集。但用户以管理员身份双击 `deploy.bat` 通常可以正常启动（管理员上下文有不同的应用控制策略）。

**部署文件已就绪**：
- `publish-final/V1.0/Api/`（17 MB，含所有依赖）
- `publish-final/V1.0/Admin/`（24 MB，含所有依赖）
- `publish-final/V1.0/deploy.bat`（一键部署）

**已知部署前置条件**：
- .NET 8 Desktop Runtime（已确认安装在主机上）
- 管理员权限运行 deploy.bat（解决 WDAC 阻止）
- 网络可达 192.168.1.237:1433（SQL Server）

## v2.13.109 备注：SQLite Provider 彻底移除

自 v2.13.109 起，DormManage 运行时仅支持 SQL Server。SQLite 代码路径、EF Core SQLite Provider、SQLite 备份恢复逻辑均已移除。历史配置中的 SqlitePath 字段仅为旧配置反序列化兼容，不代表运行时继续支持 SQLite。
