# 需求规格说明书 — v2.11.6 补充（员工账单筛选区布局重构）

> **范围**：员工账单页面筛选区布局调整、筛选条件参照人员清单风格、业务按钮迁移到页头
> **日期**：2026-07-12
> **版本**：v2.11.6（在 v2.11.4 基础上修订；v2.11.5 个人中心筛选缓存保持不变）
> **关联需求**：`17-员工分摊清单调整-v2.11.2.md`、§§3.4 35-列表页面统一UI设计规范-v2.11.6、§27-抄表记录需求-v2.11.4.md（v2.11.6 修订）
> **对应原型**：`04-HTML原型/billing/employee-bills.html`、`04-HTML原型/index.html`

## 1. 变更背景

### 1.1 v2.11.4 版本遗留问题

v2.11.4 版本（`28-员工分摊筛选布局调整-v2.11.4.md`）采用 Bootstrap 栅格系统（`col-md-2`）实现员工账单筛选区，存在以下问题：

| 问题 | 现状 | 影响 |
|------|------|------|
| **强制多行排列** | 9 个筛选字段，每个 `col-md-2`，中等屏幕下排成 2 行（共 5+4） | 与"所有筛选条件项必须一行排列"规范冲突 |
| **分摊合计被拉宽** | 分摊合计使用 `col-md-2`（与其他字段同宽），实际只显示一个金额 | 浪费水平空间，视觉不专业 |
| **操作按钮混入筛选区** | "查询/重置/发布"放在筛选区第 5/6/7 列，"生成/重生成/导出"放在第 8/9 列 | 与"业务类按钮应放页头 btn-group"规范冲突 |
| **缺少自动换行/横向滚动** | Bootstrap 栅格自动换行后不滚动，超长筛选条件会变形 | 移动端体验差 |
| **与其他列表风格不一致** | 抄表记录、宿舍管理、办理登记均已升级到 `flex-nowrap` 模式 | 视觉风格割裂 |

### 1.2 v2.11.6 变更目标

1. **风格统一**：员工账单筛选区**完全参照"人员清单"筛选条件区域**的设计风格（`flex-nowrap` 一行排列 + 条件输入框宽度自适应 + 固定查询/重置按钮）
2. **强制一行排列**：所有筛选条件项必须一行排列不可换行
3. **分摊合计最小自适应**：分摊合计字段宽度最小自适应（不允许被拉到与其他字段同宽）
4. **业务按钮迁移**：将"生成/重生成/导出/发布"等业务类按钮从筛选区迁移到页面标题右侧的 `btn-group` 中
5. **查询/重置按钮强制**：与所有列表页一致，必须有 90×38px 的"查询"和"重置"按钮

## 2. 员工账单筛选区 v2.11.6 最终版

### 2.1 布局总览

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
```

| # | 字段 | 类型 | 宽度策略 | 控件/类 |
|---|------|------|---------|--------|
| ① | **计费月份** | month 输入 | 自适应（`flex-grow-1`，`min-width: 120px`） | `.filter-item` |
| ② | **宿舍房号** | datalist 输入 | 自适应（`flex-grow-1`，`min-width: 120px`） | `.filter-item` |
| ③ | **员工（工号/姓名）** | text 输入 | 自适应（`flex-grow-1`，`min-width: 120px`） | `.filter-item` |
| ④ | **分摊合计** | 只读显示 | **最小自适应**（`flex: 0 1 auto`，`min-width: 90px`，`max-width: 140px`） | `.filter-item.filter-item-stats` |
| ⑤ | **查询** | submit 按钮 | 固定 90×38px | `.btn.btn-primary.filter-btn` |
| ⑥ | **重置** | a 链接按钮 | 固定 90×38px | `.btn.btn-outline-secondary.filter-btn` |

### 2.2 强制一行排列（不可换行）

| 规则 | 说明 |
|------|------|
| **行容器** | `<form>` 内使用 `<div class="row g-2 align-items-end flex-nowrap filter-row">` |
| **强制规则** | **禁止使用** `col-md-2` / `col-md-3` / `style="width:200px"` 等任何固定宽度方案 |
| **溢出处理** | 屏幕宽度不足以容纳所有字段时横向滚动（`overflow-x: auto`），**绝对不自动换行** |
| **小屏断点** | 768px 以下允许改为 2 列布局（`flex-wrap: wrap`，每项 `min-width: calc(50% - 8px)`） |
| **业务按钮位置** | 不放在筛选区内，统一迁移到页面标题右侧 `btn-group` 中 |

### 2.3 分摊合计最小自适应（强制）

| 属性 | 值 | 强制 | 说明 |
|------|-----|------|------|
| **CSS 类** | `.filter-item.filter-item-stats` | ✅ | 专用类，与普通输入控件区分 |
| **`flex`** | `0 1 auto` | ✅ | 不强制拉伸，按内容自适应 |
| **`min-width`** | `90px` | ✅ | 最小宽度 90px（刚好容纳"¥999.99"金额） |
| **`max-width`** | `140px` | ✅ | 最大宽度限制，避免在大屏下被拉得太宽 |
| **显示样式** | `text-success fw-bold bg-light` | — | 绿色高亮、浅灰背景，区别于可输入控件 |
| **小屏行为** | `min-width: calc(50% - 8px)`，`max-width: none` | ✅ | 768px 以下允许拉宽以适应 2 列布局 |

### 2.4 操作按钮强制（90×38px）

| 按钮 | 类名 | 图标 | 颜色 | 位置 | 尺寸 |
|------|------|------|------|------|------|
| **查询** | `btn btn-primary filter-btn` | `bi-search` | 蓝色（主操作） | 筛选区右侧第 1 位 | **90×38px** |

## 3. 页头业务按钮（迁移到 btn-group）

### 3.1 业务按钮清单

员工账单页头的业务类操作按钮全部迁移到页面标题右侧的 `btn-group` 中，与所有列表页统一：

| # | 按钮 | 图标 | 颜色 | 功能 |
|---|------|------|------|------|
| 1 | **生成** | `bi-bar-chart-line` | `btn-success`（绿色） | 生成当月员工账单 |
| 2 | **重生成** | `bi-arrow-repeat` | `btn-info`（青色） | 强制重新计算 |
| 3 | **导出** | `bi-download` | `btn-outline-secondary` | 导出当前筛选结果的 Excel |
| 4 | **发布** | `bi-send` | `btn-primary`（蓝色） | 批量发布已确认账单 |

### 3.2 页头代码标准

```html
<div class="d-flex justify-content-between align-items-center mb-3">
    <h2 class="mb-0">
        <i class="bi bi-wallet2"></i> 员工分摊
        <small class="text-muted fs-6">（共 <span id="totalCount">{总数}</span> 条）</small>
    </h2>
    <div class="btn-group" role="group" aria-label="员工分摊操作">
        <button class="btn btn-success" onclick="generate(false)">
            <i class="bi bi-bar-chart-line"></i> 生成
        </button>
        <button class="btn btn-info text-white" onclick="generate(true)">
            <i class="bi bi-arrow-repeat"></i> 重生成
        </button>
        <button class="btn btn-outline-secondary" onclick="exportExcel()">
            <i class="bi bi-download"></i> 导出
        </button>
        <button class="btn btn-primary" onclick="publishAll()">
            <i class="bi bi-send"></i> 发布
        </button>
    </div>
</div>
```

### 3.3 页头排列规范

按 `35-列表页面统一UI设计规范` §2.3 强制执行：

| 原则 | 说明 |
|------|------|
| **同一行** | 所有业务按钮必须放在 `btn-group` 内，视觉上呈一行 |
| **宽度自适应** | 按钮宽度由内容决定，不强制等宽 |
| **按钮顺序** | 生成 → 重生成 → 导出 → 发布（按"主→次→单次→批量"操作类型降序） |
| **颜色区分** | 主操作绿色（生成）、信息青色（重生成）、次要灰色（导出）、批量蓝色（发布） |
