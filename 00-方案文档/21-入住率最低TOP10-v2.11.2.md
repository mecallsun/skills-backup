## 0. 重要更正：入住率取数逻辑修正

### ⚠️ 问题描述

原设计将首页"入住率排名 TOP 20"与宿舍管理列表页的"使用率"使用了**不同的数据源**，导致同一宿舍 D-002 在两处显示不一致：
- **首页图表**：显示 D-002 为 **1%**
- **宿舍管理列表**：显示 D-002 为 **100%**

### 🔍 根因分析

| 页面 | 数据源 | 函数/条件 | D-002 结果 |
|------|--------|-----------|------------|
| 首页图表 | `PERSONNEL` 表 | `status=1`（在职） | 0人 → **1%** |
| 宿舍列表 | `RESIDENCIES` 表 | `status=1`（在住） | 1人 → **100%** |

### ✅ 修正方案

**统一使用 `RESIDENCIES` 表作为入住率的数据源**：

| 字段 | 来源 | 说明 |
|------|------|------|
| `dormCode` | DORMS | 宿舍编号 |
| `building` | DORMS | 楼栋 |
| `address` | DORMS | 详细地址 |
| `capacity` | DORMS | 床位数（入住率计算的分母） |
| `bedCount` | DORMS | 实际床位数 |
| `currentResidents` | **RESIDENCIES** | 当前在住人数（**status=1** 且 **leaveDate IS NULL**） |
| `occupancyRate` | 计算 | currentResidents / capacity |

### 🔧 修正后的算法

```sql
SELECT
    d.DormCode,
    d.Building,
    d.Address,
    d.Capacity,
    d.BedCount,
    COUNT(r.Id) AS CurrentResidents,
    CAST(COUNT(r.Id) AS DECIMAL) / d.Capacity AS OccupancyRate
FROM Dorm d
LEFT JOIN Residency r 
    ON d.DormCode = r.DormCode 
    AND r.Status = 1           -- 状态：在住
    AND r.LeaveDate IS NULL    -- 未退房
WHERE d.IsActive = 1           -- 已启用的宿舍
GROUP BY d.DormCode, d.Building, d.Address, d.Capacity, d.BedCount
ORDER BY OccupancyRate ASC, d.DormCode ASC
LIMIT 20;
```

## 3. "入住率排名 TOP 20"详细设计

### 3.1 算法

```sql
SELECT
    d.DormCode,
    d.Building,
    d.Address,
    d.Capacity,
    d.BedCount,
    COUNT(r.Id) AS CurrentResidents,
    CAST(COUNT(r.Id) AS DECIMAL) / d.Capacity AS OccupancyRate
FROM Dorm d
LEFT JOIN Residency r ON d.DormCode = r.DormCode AND r.Status = 1  -- 当前在宿
WHERE d.IsActive = 1
GROUP BY d.DormCode, d.Building, d.Address, d.Capacity, d.BedCount
ORDER BY OccupancyRate ASC, d.DormCode ASC
LIMIT 20;
```

### 3.2 字段定义

| 字段 | 来源 | 说明 |
|------|------|------|
| `dormCode` | DORMS | 宿舍编号 |
| `building` | DORMS | 楼栋 |
| `address` | DORMS | 详细地址 |
| `capacity` | DORMS | 床位数 |
| `currentResidents` | **RESIDENCIES** | 当前在住人数（**status=1 且 leaveDate=null**） |
| `occupancyRate` | 计算 | currentResidents / capacity |

> ⚠️ **重要**：入住率统计以 **RESIDENCIES 表**（入住记录表）为准，而非 **PERSONNEL 表**（员工档案表）。因为员工离职后，其 PERSONNEL 记录会变更 status=2，但 RESIDENCIES 中仍有历史入住记录，且 leaveDate 字段标识退房状态。

### 3.3 UI 设计

**图表类型**：水平条形图（bar, indexAxis='y'）

**标题**：入住率排名 TOP 15（%）（TOP 20→TOP 15，删除"入住率由低到高"文字，改为括号内标注"%"）

## 5. 后端 SQL 实现

```sql
SELECT TOP 20
    d.DormCode, d.Building, d.Address,
    d.Capacity, d.BedCount,
    COUNT(r.Id) AS CurrentResidents,
    CAST(COUNT(r.Id) AS DECIMAL) / d.Capacity AS OccupancyRate
FROM Dorm d
LEFT JOIN Residency r
    ON d.DormCode = r.DormCode
    AND r.Status = 1           -- 状态：在住
    AND r.LeaveDate IS NULL    -- 未退房
WHERE d.IsActive = 1
GROUP BY d.DormCode, d.Building, d.Address, d.Capacity, d.BedCount
ORDER BY
    CAST(COUNT(r.Id) AS DECIMAL) / d.Capacity ASC,
    d.DormCode ASC;
```

**性能**：
- 建议索引：`Dorm(IsActive)`、`Residency(DormCode, Status, LeaveDate)`
