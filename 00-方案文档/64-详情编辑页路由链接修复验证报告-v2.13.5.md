# 详情/编辑页路由链接修复验证报告 — v2.13.5

> **版本**：v2.13.5
> **日期**：2026-07-16
> **作者**：Claude Opus 4.8 (1M context)
> **范围**：住宿详情/编辑/历史、办理登记编辑、抄表编辑 —— 列表页跳转链接由「路径式」纠正为「查询式」，消除点击后 HTTP 404
> **关联文档**：52-页面500错误全面修复报告-v2.12.43、35-列表页面统一UI设计规范-v2.11.4
> **关联提交**：5a522ef（`fix(admin): Razor Pages @page 路由模板 500 错误修复`）

---

## 1. 背景

提交 `5a522ef` 为修复详情/编辑/历史页面的 HTTP 500，将 5 个页面的路由指令由
`@page "{id:int}"`（拼接相对路由模板，与 ASP.NET Core 8 路由约定冲突）改为纯 `@page`，
并配合 `PageModel.OnGetAsync(int id)` / `[BindProperty(SupportsGet = true)] public int Id` 显式参数绑定。

改为纯 `@page` 后，页面路由退化为 `/Dorms/Details` 等固定路径，`id` 只能经**查询字符串**传入
（`?id=5`）。但列表页与页内跳转链接**未同步修改**，仍生成**路径式** URL（`/Dorms/Details/5`）。

**后果**：500 错误消除，但点击「详情/修改/住宿详情」等按钮时路由不匹配，页面由 500 变为 **HTTP 404**——从用户视角仍无法打开。

## 2. 验证方法

实际启动 `DormManage.Admin`（端口 5001，Development），以 `admin/admin123` 登录获取 Cookie 后
逐一访问路径式与查询式两种 URL，对比 HTTP 状态码：

| URL 形式 | 修复前结果 |
|---------|-----------|
| 路径式 `/Dorms/Details/1`（列表按钮实际使用） | ❌ HTTP 404 |
| 查询式 `/Dorms/Details?id=1`（纯 `@page` 期望） | ✅ HTTP 200 |

5 个页面（Details/Edit/History/Booking·Edit/Meter·Edit）表现一致：路径式全 404，查询式全 200。

## 3. 修复内容

将 5 处路径式链接改为查询式（`/X/Y/@id` → `/X/Y?id=@id`）：

| # | 文件 | 位置 | 修改前 | 修改后 |
|---|------|------|--------|--------|
| 1 | `Pages/Dorms/Index.cshtml` | 详情按钮 | `/Dorms/Details/@item.Id` | `/Dorms/Details?id=@item.Id` |
| 2 | `Pages/Dorms/Index.cshtml` | 修改按钮 | `/Dorms/Edit/@item.Id` | `/Dorms/Edit?id=@item.Id` |
| 3 | `Pages/Dorms/Details.cshtml` | 编辑按钮 | `/Dorms/Edit/@Model.Dorm?.Id` | `/Dorms/Edit?id=@(Model.Dorm?.Id)` |
| 4 | `Pages/Dorms/History.cshtml` | 住宿详情按钮 | `/Dorms/Details/@Model.Id` | `/Dorms/Details?id=@Model.Id` |
| 5 | `Pages/Booking/Index.cshtml` | 修改按钮 | `/Booking/Edit/@item.Id` | `/Booking/Edit?id=@item.Id` |

> 说明：抄表记录列表（`Meter/Index`）的「修正」按钮走 Modal + API（`correctRecord()`），
> 不跳转 `Meter/Edit` 页面，故无破损链接；`Meter/Edit?id=` 页面本身经查询字符串可正常访问（200）。

## 4. 修复后验证结果

编译：`dotnet build DormManage.Admin -c Debug` → **0 错误**。
重启服务并从**渲染后的真实列表页 HTML** 提取按钮链接后逐一访问：

| 验证项 | 结果 |
|--------|------|
| Dorms/Index 生成链接形式 | ✅ `?id=` 查询式 |
| `/Dorms/Details?id=1` | ✅ HTTP 200 |
| `/Dorms/Edit?id=1` | ✅ HTTP 200 |
| Details 页内 Edit 链接 | ✅ `?id=1` → 200 |
| History 页内 Details 链接 | ✅ `?id=1` → 200 |
| `/Booking/Edit?id=1` | ✅ HTTP 200 |
| `/Meter/Edit?id=1` | ✅ HTTP 200 |
| 旧路径式 `/Dorms/Details/1`（回归） | ✅ 仍 404（已无任何链接使用） |

## 5. 结论

`5a522ef` 的 500 修复方案正确但**不完整**——仅改了页面路由指令，遗漏了指向这些页面的跳转链接，
导致缺陷由 500 转化为 404。本次补齐 5 处链接后，详情/编辑/历史全链路验证通过（全部 200），缺陷闭环。
