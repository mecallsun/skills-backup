# 列表页按钮区 靠右 + 强制一行排列 — v2.13.165

> **日期**：2026-07-25
> **类型**：UI 统一规范（响应式按钮区）
> **范围**：所有有列表的主菜单页面（人员清单/住宿档案/办理登记/费用标准/智能抄表/基础资料/首页等）

---

## 一、用户原话

> 「将本项目的 UI 设计的相关文档 更改 主菜单导航 有 列表的页面（如：人员清单、智能抄表等都有列表的页面），在其列表之上的按键区的所有按钮 调整为靠右显示 且强制一行排列」

**3 项硬要求**：
1. **作用范围**：所有有列表的页面（人员清单、智能抄表等）
2. **靠右显示**：按钮区在「列表之上、页头之下」的右端
3. **强制一行排列**：窄屏下不换行（按钮过多时横向滚动）

---

## 二、实现

### 2.1 复用现有 `PageHeader` 组件

系统已有 `DormManage.Admin/Pages/Shared/Components/PageHeader/Default.cshtml`，所有主菜单列表页（Personnel/Dorms/Booking/BillingStandard/DormBilling/EmployeeBilling/Meter/Index 等）都通过 `@await Component.InvokeAsync("PageHeader", ...)` 渲染页头按钮区。

**无需为每个列表页单独改 Razor**，只需在共享组件 + 全局 CSS 上加约束即可全站生效。

### 2.2 共享组件 `Default.cshtml` 变更

```html
<!-- 按钮区 div 加 flex-nowrap + page-header-actions 类 -->
<div class="d-flex align-items-center gap-2 page-header-actions flex-nowrap">
    
    <!-- 主操作按钮：加 text-nowrap 强制单按钮不换行 -->
    <a href="@Model.PrimaryAction.Url" class="btn @btnClass btn-sm text-nowrap">...</a>
    
    <!-- 次操作按钮循环：每个 a/button 都加 text-nowrap -->
    <a href="@action.Url" class="btn @styleClass btn-sm text-nowrap">...</a>
    <button class="btn @styleClass btn-sm text-nowrap" onclick="@action.OnClick">...</button>
</div>
```

### 2.3 全局 CSS（`Shared/_Layout.cshtml`）

```css
/* v2.13.165：所有列表页按键区靠右 + 强制一行排列 + 按钮不换行 */
.page-header-actions { flex-wrap: nowrap; overflow-x: auto; }
.page-header-actions .btn { white-space: nowrap; flex-shrink: 0; }
.page-header h2 { flex-shrink: 1; min-width: 0; }
```

**3 行 CSS 的 4 层效果**：
- `flex-wrap: nowrap` → 按钮容器不换行
- `overflow-x: auto` → 按钮过多时出现横向滚动条（替代「堆叠到第二行」）
- `.btn { white-space: nowrap; flex-shrink: 0 }` → 单个按钮文本不换行也不被压缩
- `h2 { flex-shrink: 1; min-width: 0 }` → 标题可被压缩让位给按钮（防止按钮被挤出右端）

### 2.4 父容器已正确（无需改）

`<div class="page-header">` 内部使用 `d-flex justify-content-between align-items-center`（已存在的样式）：
- 标题 `<h2>` 居左
- 操作按钮 `<div class="page-header-actions flex-nowrap">` 居右 ✓


各 PageHeader 字段的 actions 数组：`新增设备记录` + `批量删除` + `导入` + `导出Excel`，同样应用 `text-nowrap` ✓

同上结构，全部通过 PageHeader 组件渲染 → 一次修改全站生效。

## 五、永久教训

| # | 教训 |
|---|------|
| 1 | **「全站 UI 约束」优先在共享组件 + 全局 CSS 上修改**。本系统的 PageHeader 组件被 10+ 页面复用，一次修改即可全站生效——**避免逐页改 Razor 引起的实现漂移**。 |
| 2 | **「flex-nowrap + overflow-x: auto」是窄屏按钮防换行的最佳实践**。与 `white-space: nowrap`（单按钮防换行）+ `flex-shrink: 0`（按钮不被压缩）组合，实现「窄屏横向滚动而非堆叠」。 |
| 3 | **「标题 flex-shrink: 1 + 按钮 flex-shrink: 0」是优先级策略**。窄屏空间不足时，让标题先被截断或省略号处理，按钮保持完整可点。 |
| 4 | **「靠右」≠「margin-left:auto」**：本系统用 `justify-content-between`（父容器两端对齐）+ 子元素自然排右，比 flex-grow/margin-left 更简洁且语义清晰。 |
| 5 | **「text-nowrap」vs「flex-nowrap」** 是不同对象：前者是按钮文本不换行（白名单词组），后者是容器不换行（布局）。两者必须同时使用。 |
