## 1. 概述

### 1.1 业务定位

宿舍管理是宿舍档案的核心管理模块，用于维护宿舍的基本信息（楼栋、楼层、容量、性别等），并提供宿舍详情查看、人员入住情况追踪、历史记录查询等功能。

### 1.2 功能范围

| 子模块 | 功能 | 路径 |
|--------|------|------|
| **宿舍列表** | 列表筛选、分页、CRUD | `/Dorms` |
| **宿舍详情** | 基本信息、当前入住、历史记录 | `/Dorms/Details/{id}` |
| **新增宿舍** | 表单录入 | `/Dorms/Create` |
| **编辑宿舍** | 表单编辑 | `/Dorms/Edit/{id}` |

### 1.3 菜单入口

**位置**：顶部导航栏 → "宿舍管理"

**图标**：`bi bi-building`

## 3. 数据模型

### 3.1 Dorm 表

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 主键 |
| DormCode | nvarchar(20) | 宿舍号（唯一） |
| BuildingId | int | 楼栋ID（外键） |
| BuildingName | nvarchar(50) | 楼栋名称（冗余） |
| FloorId | int | 楼层ID（外键） |
| AddressId | int | 地址ID（外键） |
| AddressText | nvarchar(200) | 地址描述（冗余） |
| Capacity | int | 容量（人） |
| Gender | int | 性别：1=男 2=女 |
| Remark | nvarchar(500) | 备注 |
| IsActive | bit | 是否启用 |
| CreatedAt | datetime | 创建时间 |
| UpdatedAt | datetime | 更新时间 |

### 3.2 关联字段

| 关联表 | 外键字段 | 关系 |
|--------|---------|------|
| Building | BuildingId | 多对一 |
| Floor | FloorId | 多对一 |
| Address | AddressId | 多对一 |
| DormBooking | DormCode | 一对多 |

## 4. API 设计

### 4.1 宿舍 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/dorms | 获取宿舍列表 |
| GET | /api/dorms/{id} | 获取宿舍详情 |
| POST | /api/dorms | 新增宿舍 |
| PUT | /api/dorms/{id} | 编辑宿舍 |
| DELETE | /api/dorms/{id} | 删除宿舍 |

### 4.2 列表查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| dormCode | string | 否 | 宿舍号（模糊） |
| buildingId | int | 否 | 楼栋ID |
| floorId | int | 否 | 楼层ID |
| addressId | int | 否 | 地址ID |
| page | int | 否 | 页码（默认1） |
| pageSize | int | 否 | 每页条数（默认20） |

### 4.3 响应格式

```json
{
  "success": true,
  "data": {
```

## 5. 业务规则

| 规则 | 说明 |
|------|------|
| R-DORM-001 | 宿舍号全表唯一，新增/编辑时校验 |
| R-DORM-002 | 删除前检查是否有在宿人员（status=2），有则提示"该宿舍有在宿人员，无法删除" |
| R-DORM-003 | 容量字段必填，范围 1-20 |
| R-DORM-004 | 性别字段必填，1=男 / 2=女 |
| R-DORM-005 | 楼栋、楼层、地址均使用基础资料模块字典 |
| R-DORM-006 | 当前入住数实时统计 DormBooking WHERE Status=2 |
