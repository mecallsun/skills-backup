## 1. 变更背景

### 1.1 本次变更内容

| 变更项 | 说明 |
|--------|------|
| **A. 删除"已作废"状态** | 简化状态系统，删除 status=3 |
| **B. 每日自动生成占位记录** | 每天0时检查并生成未完成记录 |
| **C. 禁止重复记录** | 同月同房号只能有一条记录，覆盖更新 |
| **D. 历史记录** | 覆盖时在备注中记录历史 |

### 1.2 变更前的状态系统

v2.11.3 定义了 5 种状态：
- status=0 未抄表 → 已合并到 status=4
- status=1 正常
- status=2 已修正
- status=3 已作废 → **本次删除**
- status=4 未完成

### 1.3 变更后的状态系统

**3 种状态**：

| Status | 含义 | Badge | 数据完整性 | 参与计费 |
|--------|------|-------|-----------|:---:|
| 4 | **未完成** | 蓝 `bg-info text-dark` | 三表至少一个有值，或全为 0 | ❌ |
| 1 | **正常** | 绿 `bg-success` | 三表完整且读数正常 | ✅ |
| 2 | **已修正** | 黄 `bg-warning text-dark` | 三表完整（已修正过） | ✅ |

## 2. 核心业务规则

### 2.1 每日自动生成占位记录（R-METER-Q-10）

| 规则 | 说明 |
|------|------|
| R-METER-Q-10 | **每天 0 时，系统自动检查当月（当前月份）的所有启用住宿** |
| R-METER-Q-11 | 对于未生成抄表记录的住宿，自动生成占位记录 |
| R-METER-Q-12 | 占位记录：status=4，三表全为 0，Operator="系统"，DeviceSn="AUTO" |
| R-METER-Q-13 | 住宿停用后不再为其生成占位记录 |
| R-METER-Q-14 | 已存在记录的住宿不再生成（保持唯一性） |

**实现方式**：

```csharp
// 定时任务：每天0时执行
public async Task GeneratePlaceholderRecordsAsync()
{
    // 获取当月
    var currentMonth = DateTime.Now.ToString("yyyy-MM");

    // 获取所有启用住宿
    var activeDorms = await _db.Dorms
        .Where(d => d.IsActive)
        .Select(d => d.DormCode)
        .ToListAsync();

    // 获取当月已有记录的住宿
    var existingMonths = await _db.MeterRecords
        .Where(r => r.ReadMonth == currentMonth)
        .Select(r => r.DormCode)
        .ToHashSetAsync();

    // 找出缺失的住宿
    var missingDorms = activeDorms.Where(c => !existingMonths.Contains(c)).ToList();

    foreach (var code in missingDorms)
    {
        _db.MeterRecords.Add(new MeterRecord
        {
            DormCode = code,
            ReadMonth = currentMonth,
            ColdMeter = 0,
            HotMeter = 0,
            ElectricMeter = 0,
            Status = 4,  // 未完成
            Operator = "系统",
            DeviceSn = "AUTO",
            Remark = $"[{DateTime.Now:yyyy-MM-dd HH:mm}] 系统自动生成占位记录",
            CreatedAt = DateTime.Now
        });
    }

    if (missingDorms.Count > 0)
    {
        await _db.SaveChangesAsync();
        Console.WriteLine($"[{DateTime.Now}] 已自动生成 {missingDorms.Count} 条占位记录");
    }
}
```

### 2.2 禁止重复记录（R-METER-Q-20）

| 规则 | 说明 |
|------|------|
| R-METER-Q-20 | **每月每房号只能有且仅有一条抄表记录** |
| R-METER-Q-21 | PDA上传/手动新增/批量导入时，同月同房号命中已有记录 → **覆盖更新** |
| R-METER-Q-22 | 覆盖时旧数据快照追加到备注（历史记录） |
| R-METER-Q-23 | **不存在新增操作**，只有"更新覆盖" |
| R-METER-Q-24 | 覆盖操作人记录为实际操作用户，而非"系统" |

**覆盖场景处理**：

| 场景 | 旧记录状态 | 处理方式 |
|------|-----------|---------|
| PDA上传 | status=4 | 覆盖 + 历史记录 |
| PDA上传 | status=1 | 拒绝（已定稿） |
| 手动补录 | status=4 | 覆盖 + 历史记录 |
| 手动补录 | status=1 | 拒绝（需走修正流程） |
| 批量导入 | status=4 | 覆盖 + 历史记录 |
| 批量导入 | status=1 | 拒绝（已定稿） |
| 批量导入 | status=2 | 拒绝（已修正不可改） |

### 2.3 历史记录机制（R-METER-Q-30）

| 规则 | 说明 |
|------|------|
| R-METER-Q-30 | **每次覆盖操作，必须在备注中追加历史快照** |
| R-METER-Q-31 | 历史记录格式：`[时间] 覆盖前数据: cold=X, hot=Y, electric=Z, status=N, operator=XXX` |
| R-METER-Q-32 | 多次覆盖保留完整历史，不覆盖旧历史 |

**历史记录格式**：
```
备注:
[2026-07-15 14:30 覆盖前数据] cold=100.00, hot=50.00, electric=200.00, status=1, operator=陈师傅
[2026-07-16 09:15 覆盖前数据] cold=105.00, hot=55.00, electric=210.00, status=4, operator=刘师傅
```

**实现代码**：
```csharp
private string BuildHistoryEntry(MeterRecord old)
{
    return $"[{DateTime.Now:yyyy-MM-dd HH:mm} 覆盖前数据] " +
           $"cold={old.ColdMeter:F2}, hot={old.HotMeter:F2}, " +
           $"electric={old.ElectricMeter:F2}, status={old.Status}, " +
           $"operator={old.Operator}";
}

private string AppendHistory(string? currentRemark, string historyEntry)
{
    if (string.IsNullOrWhiteSpace(currentRemark))
        return historyEntry;
    return currentRemark + "\n" + historyEntry;
}
```

**删除 API 实现**：
```csharp
// DELETE /api/v1/meter/records/{id}
[HttpDelete("{id:long}")]
[RequirePermission("Meter:Delete")]
public async Task<ApiResponse> DeleteAsync(long id, [FromBody] DeleteRecordRequest req)
{
    var record = await _db.MeterRecords.FindAsync(id);
    if (record == null)
        return ApiResponse.Error(404, "记录不存在");

    if (string.IsNullOrWhiteSpace(req.Reason))
        return ApiResponse.Error(400, "删除原因必填");

    // 记录删除日志
    _logger.LogInformation(
        "删除抄表记录: Id={Id}, DormCode={DormCode}, ReadMonth={Month}, " +
        "Cold={Cold}, Hot={Hot}, Electric={Electric}, Status={Status}, " +
        "Reason={Reason}, Operator={Operator}",
        record.Id, record.DormCode, record.ReadMonth,
        record.ColdMeter, record.HotMeter, record.ElectricMeter,
        record.Status, req.Reason, GetCurrentUser());

    // 删除记录
    _db.MeterRecords.Remove(record);
    await _db.SaveChangesAsync();

    return ApiResponse.Ok();
}
```

```javascript
function determineStatus(cold, hot, electric) {
    const nonZeroCount = (cold > 0 ? 1 : 0) + (hot > 0 ? 1 : 0) + (electric > 0 ? 1 : 0);
    if (nonZeroCount < 3) return 4;  // 未完成
    return 1;  // 正常
}
```

## 6. API 端点设计

### 6.1 上传接口（覆盖模式）

```csharp
// POST /api/v1/meter/upload
public async Task<ApiResponse> UploadAsync([FromBody] MeterUploadRequest req)
{
    var existing = await _db.MeterRecords
        .FirstOrDefaultAsync(r => r.DormCode == req.DormCode && r.ReadMonth == req.ReadMonth);

    if (existing != null)
    {
        if (existing.Status == 1 || existing.Status == 2)
        {
            return ApiResponse.Error(1001, "该记录已定稿，不可覆盖。如需修改请走修正流程。");
        }

        // 构建历史记录
        var historyEntry = BuildHistoryEntry(existing);
        req.Remark = AppendHistory(req.Remark, historyEntry);

        // 更新记录
        existing.ColdMeter = req.ColdMeter;
        existing.HotMeter = req.HotMeter;
        existing.ElectricMeter = req.ElectricMeter;
        existing.Operator = req.Operator;
        existing.Remark = req.Remark;
        existing.Status = DetermineStatus(req.ColdMeter, req.HotMeter, req.ElectricMeter);
        existing.UpdatedAt = DateTime.Now;
    }
    else
    {
        // 新增记录
        var record = new MeterRecord { ... };
        _db.MeterRecords.Add(record);
    }

    await _db.SaveChangesAsync();
    return ApiResponse.Ok();
}
```

### 6.2 删除接口

```csharp
// DELETE /api/v1/meter/records/{id}
[HttpDelete("{id:long}")]
[RequirePermission("Meter:Delete")]
public async Task<ApiResponse> DeleteAsync(long id, [FromBody] DeleteRecordRequest req)
{
    var record = await _db.MeterRecords.FindAsync(id);
    if (record == null)
        return ApiResponse.Error(404, "记录不存在");

    if (record.Status != 4)
        return ApiResponse.Error(400, "仅未完成状态的记录可以删除");

    if (string.IsNullOrWhiteSpace(req.Reason))
        return ApiResponse.Error(400, "删除原因必填");

    // 记录删除日志
    _logger.LogInformation(
        "删除抄表记录: Id={Id}, DormCode={DormCode}, ReadMonth={Month}, Reason={Reason}",
        record.Id, record.DormCode, record.ReadMonth, req.Reason);

    _db.MeterRecords.Remove(record);
    await _db.SaveChangesAsync();

    return ApiResponse.Ok();
}

public class DeleteRecordRequest
{
    public string Reason { get; set; } = "";
}
```

### 6.3 定时任务

```csharp
// 后台托管服务
public class MeterPlaceholderGenerator : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            var now = DateTime.Now;

            // 检查是否每天0时（0:00-0:05）
            if (now.Hour == 0 && now.Minute < 5)
            {
                try
                {
                    await _service.GeneratePlaceholderRecordsAsync();
                    Console.WriteLine($"[{now}] 已完成当月占位记录检查");
                }
                catch (Exception ex)
                {
                    Console.WriteLine($"[{now}] 占位记录生成失败：{ex.Message}");
                }
            }

            // 每5分钟检查一次
            await Task.Delay(TimeSpan.FromMinutes(5), stoppingToken);
        }
    }
}
```
