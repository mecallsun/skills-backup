# 需求规格说明书 — v2.11.2 增补 (h)：员工账单删除"本月合计"行

> **范围**：员工账单（billing/employee-bills.html）表格底部
> **日期**：2026-07-11
> **对应原型**：`04-HTML原型/billing/employee-bills.html`

---

## 1. 变更背景

员工账单表格底部原本显示"本月合计"行（`本月合计：¥63355.11`），与顶部 KPI 卡片"分摊合计"功能重复。

合计信息已在页面顶部 KPI 卡片显示（员工数 / 分摊合计 / 人均费用），表格底部再显示合计造成视觉冗余。

## 2. 变更对照

### 2.1 修改前

表格底部：

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ...明细行...                                                             │
├──────────────────────────────────────────────────────────────────────────┤
│                        本月合计：│ ¥63355.11 │                    │       │
└──────────────────────────────────────────────────────────────────────────┘
```

### 2.2 修改后

表格底部：

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ...明细行...                                                             │
├──────────────────────────────────────────────────────────────────────────┤
│ （无 tfoot 内容）                                                       │
└──────────────────────────────────────────────────────────────────────────┘
```

## 3. 详细变更

### 3.1 删除内容

| 元素 | 原内容 | 状态 |
|------|--------|------|
| 表格 tfoot "本月合计" 行 | `<tr><td colspan="9">本月合计：</td><td>¥63355.11</td>...</tr>` | **已删除** |
| JS 渲染 tfoot 的代码 | `tfoot.innerHTML = '<tr>...本月合计...</tr>'` | **已删除** |

### 3.2 保留内容

| 元素 | 内容 | 状态 |
|------|------|------|
| KPI 卡片"分摊合计" | `¥63355.11`（页面顶部） | 保留 |
| KPI 卡片"员工数" | `479` | 保留 |
| KPI 卡片"人均费用" | `¥132.27` | 保留 |

## 4. 设计意图

1. **避免信息冗余**：合计已在 KPI 卡片显示，表格底部无需重复
2. **简化表格**：明细行直接结束，无额外合计行
3. **视觉层次**：KPI（汇总）→ 表格（明细）的结构更清晰
4. **保持合计可见**：用户仍可在页面顶部一眼看到本月分摊合计
