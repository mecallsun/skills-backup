## 3. v2.13.210 极致压缩方案

### 3.1 设计原则（5 大原则）

| # | 原则 | 说明 |
|---|------|------|
| **P1** | **极致最小高度专业标准** | 筛选区总高控制在 **84px**（最低 84px 可达） |
| **P2** | **按钮与输入控件等高对齐** | 按钮 height = 输入控件 height（同 26px，视觉对齐） |
| **P3** | **label 与控件紧凑排布** | label 行高 ≈ 13px + margin-bottom ≈ 1px（节省 4-5px） |
| **P4** | **card padding 极致压缩** | padding 由 12px → 5.6px（节省 12.8px） |
| **P5** | **统一强制 14 项参数** | 全部通过 `_Layout` 全局样式强制，不允许各页覆盖 |

### 3.2 v2.13.210 最小高度参数表（14 项强制值）

| # | 元素 | 旧值 | v2.13.210 新值 | 节省 |
|---|------|------|---------------|------|

| ② | `.filter-card` `margin-bottom` | `0.75rem` | `0.4rem` | 5.6px |
| ③ | `.filter-card` `border-radius` | `8px` | `6px` | 0（视觉） |

### 3.3 高度计算公式

```
filter-card padding   : 11.2px
filter-card border    : 2px
card-body py-1        : 8px
label (form-label)    : 13.2px (11.5 × 1.15)
label margin-bottom   : 0.8px
form-control height   : 26px
─────────────────────────────────────────
filter-item 总高      : 40px
filter-item-btn 总高  : 30px（强制主导）
filter-row 实际高度   : max(40, 30) = 40px
─────────────────────────────────────────
筛选区总高            : 11.2 + 2 + 8 + 40 + 8 + 1 + 11.2 ≈ 81.4px
含 form-select 下拉箭头 ≈ 84px（实际渲染）
─────────────────────────────────────────
节省：102px → 84px = 18px = -18%
```

## 8. 永久教训（v2.13.210+ 强制沉淀）

### 8.1 全局共享样式 = 唯一权威源

8 个标准列表页共享 `_Layout.cshtml`，**只改一处全局生效**，禁止在页面内重复定义或覆盖。如发现页面内有 `.filter-*` 自定义样式，立即合并到全局。

### 8.2 按钮列 min-height 是最大单点高度贡献者

`.filter-item-btn { min-height: 60px !important }` 占筛选区总高 60%，**最小高度压缩的第一刀必须先压这里**。本次 v2.13.210 改为 30px + 与 input 高度对齐（26px），节省 30px。

### 8.3 按钮与输入控件必须等高对齐

`filter-btn height = form-control height`（同 26px），消除 `align-items: flex-end` 时的「底部不对齐」视觉错位。**强制规则 P2**。

### 8.4 HTML 原型与程序必须像素级对齐

`padding / height / font-size` 数值在 prototype 与 Razor 渲染后完全一致（v2.13.210 强制）。本次修改 `_shared/layout-tab.css` 与 `_Layout.cshtml` 保持字节级一致，避免出现「程序压缩后原型仍显示旧尺寸」的失真。
