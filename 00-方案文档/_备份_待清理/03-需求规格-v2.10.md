## 1. 业务背景

公司当前仅能「抄表 → 存数据」，无法按月给员工算水电费、无法批量维护人事信息。本次升级将系统从「抄表工具」升级为「完整的水电费用管理平台」：

- 人事部门可批量维护 156+ 员工档案（入职 → 在职 → 离职 生命周期）
- 财务部门可按月生成宿舍账单和员工分摊账单
- 业务闭环：抄表 → 费用标准 → 宿舍账单 → 员工分摊 → Excel 报表 → HR 工资扣除

| 角色 | 操作场景 |
|------|---------|

## 3. 业务规则（关键约束）

### 3.1 人员清单规则

| 规则 | 说明 |
|------|------|
| R-EMP-01 | 工号全局唯一，重复导入报错 |
| R-EMP-02 | 入职日期必填，离职日期可选 |
| R-EMP-03 | 离职为软删除（Status=2，LeaveDate 必填） |
| R-EMP-04 | 5 种员工类型：合同工/临时工/外包/实习生/驻场 |
| R-EMP-05 | 8 个可选部门：生产部/技术部/行政部/财务部/销售部/后勤部/仓储部/其他 |
| R-EMP-06 | **列表默认仅显示在职人员**；离职人员（Status=2）默认隐藏，勾选「显示离职人员」后才全部显示 |
| R-EMP-07 | **离职人员禁止参与办理入住**：办理入住的员工模糊查询/选择仅返回在职（Status=1）员工 |

### 3.2 费用分摊规则

| 规则 | 说明 |
|------|------|
| R-BILL-01 | 仅向 **在职**员工（Status=1）分摊 |
| R-BILL-02 | 员工分摊按其 **EmployeeType** 查找当前生效的对应类型费用标准；无对应标准时单价=0，该员工不参与分摊 |
| R-BILL-03 | 平均分摊：每人 1/N（N = 宿舍**实际参与分摊**的在职员工数） |
| R-BILL-04 | 金额精度：DECIMAL(12,2)，分摊误差允许 ±0.01 元 |
| R-BILL-05 | 同一宿舍同月只有一条账单（UNIQUE 约束） |
| R-BILL-06 | 同一员工同月只有一条分摊（UNIQUE 约束） |
| R-BILL-07 | 发布后 IsPublished=1，可撤销再编辑 |
| R-BILL-08 | 用量 = 该月抄表记录值；多版本则取首条 |

## 4. 数据模型（精简字段表）

### 4.1 SysEmployee 人员表

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| Id | INT | PK | 主键自增 |
| EmployeeCode | NVARCHAR(20) | 是 | 工号（UNIQUE） |
| RealName | NVARCHAR(50) | 是 | 姓名 |
| Department | NVARCHAR(50) | 是 | 部门 |
| EmployeeType | NVARCHAR(20) | 是 | 员工类型 |
| Phone | NVARCHAR(20) | 否 | 手机号 |
| HireDate | DATE | 是 | 入职日期 |
| LeaveDate | DATE | 否 | 离职日期 |
| DormCode | NVARCHAR(20) | 否 | 关联宿舍 |
| Status | TINYINT | 是 | 1=在职 2=离职 3=停薪留职 |
| Remark | NVARCHAR(500) | 否 | 备注 |
| CreatedAt | DATETIME | 是 | 创建时间 |
| CreatedBy | NVARCHAR(50) | 否 | 创建人 |

**索引**：
- `UX_SysEmployee_EmployeeCode`（UNIQUE）
- `IX_SysEmployee_Department(Department, Status)`
- `IX_SysEmployee_TypeStatus(EmployeeType, Status)`
- `IX_SysEmployee_DormCode(DormCode)`
- `IX_SysEmployee_StatusHireDate(Status, HireDate DESC)`

### 4.2 BillingStandard 费用标准表

| 字段 | 类型 | 必填 |
|------|------|------|
| Id | INT PK | — |
| StandardName | NVARCHAR(50) | 是（UNIQUE） |
| EffectiveFrom | DATE | 是 |
| EffectiveTo | DATE | 否 |
| HotWaterPrice | DECIMAL(10,2) | 是 >0 |
| ColdWaterPrice | DECIMAL(10,2) | 是 >0 |
| ElectricityPrice | DECIMAL(10,4) | 是 >0 |
| ApplicableTypes | NVARCHAR(200) | 是 |
| IsActive | BIT | 是 |

### 4.3 DormBilling 宿舍月度账单表

| 字段 | 类型 | 必填 |

**索引**：`UX_DormBilling_DormMonth(DormCode, BillingMonth)` UNIQUE

## 7. 页面跳转矩阵

```
Personnel/Index
  ├─ +新增按钮      → Personnel/Create
  ├─ 编辑按钮       → Personnel/Edit/{id}
  ├─ 离职按钮       → Personnel/Index（标记离职后刷新）
  ├─ 📥导入按钮     → Personnel/Import
  ├─ 📤导出按钮     → 直接下载 Excel
  └─ 分页按钮       → Personnel/Index?page=N

BillingStandard/Index
  ├─ +新增标准按钮  → BillingStandard/Create
  ├─ 编辑按钮       → BillingStandard/Edit/{id}
  └─ 删除按钮       → BillingStandard/Index（确认后删除）

DormBilling/Index?billingMonth=YYYY-MM
  ├─ 生成该月账单    → DormBilling/Index（提示后刷新）
  ├─ 重新生成（覆盖）→ 同上
  ├─ 单条发布        → DormBilling/Index（标记后刷新）
  ├─ 撤销发布        → 同上
  └─ 导出 Excel     → 直接下载

EmployeeBilling/Index?billingMonth=YYYY-MM
  ├─ 生成分摊账单    → EmployeeBilling/Index
  ├─ 重新生成分摊    → 同上
  ├─ 单条发布        → EmployeeBilling/Index
  ├─ 全部发布        → EmployeeBilling/Index
  └─ 导出 Excel     → 直接下载
```

## 10. 数据流图

```
PDA 抄表 → MeterRecord 表
              ↓
BillingStandard（人工配置）
              ↓
点击「生成账单」→ 计算 dorm 用量 × 标准单价
              ↓
DormBilling 表（宿舍月度）
              ↓
点击「生成分摊」→ 计算 1/N × 适用类型过滤
              ↓
EmployeeBilling 表（员工月度）
              ↓
Excel 导出 → 财务 / HR
```
