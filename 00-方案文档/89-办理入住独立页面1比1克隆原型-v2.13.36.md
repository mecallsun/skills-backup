## 二、技术实现

### 2.1 架构升级：Modal → 独立 Page

| 维度 | Modal 弹窗（v2.13.35） | 独立 Page（v2.13.36） |
|------|----------------------|----------------------|
| **路由** | 无独立 URL（嵌入 Index 页面） | `/Booking/CheckIn`（独立路径） |
| **布局** | `_Layout` 嵌入 Modal | `Layout = null`（独立完整布局） |
| **导航** | PageHeader 按钮触发 Modal.show() | PageHeader 按钮 `<a href="/Booking/CheckIn">` 跳转 |
| **生命周期** | Modal hide/show 事件 | 标准 Razor Page 加载/卸载 |
| **用户感知** | "页面内的小窗口" | "独占的完整页面" |
| **适用场景** | 快速录入 | 复杂表单 + 完整流程 |

## 四、API 端点对接（v2.13.36）

### 4.1 新增的 API 调用

| 用途 | API 端点 | 方法 | 说明 |
|------|---------|------|------|
| 员工搜索 | `/api/v1/bookings/employee-search?keyword=xxx` | GET | 按姓名模糊匹配 |
| 员工历史 | `/api/v1/bookings/employee-history/{empId}` | GET | 该员工所有办理记录 |
| 在宿记录 | `/api/v1/bookings/staying-records/{empId}` | GET | 该员工当前在宿记录 |
| 可用房间 | `/api/v1/bookings/available-dorms?empId=xxx&date=xxx` | GET | 过滤余量 + 不冲突的房间 |
| 入住提交 | `/api/v1/bookings/check-in` | POST | 入住办理 |
| 退房提交 | `/api/v1/bookings/{id}/check-out` | POST | 退房办理 |

### 4.2 真实 API 替换 mock-data.js

**原型**使用 `mock-data.js` 的工具函数（lastBookingOf / activeBookingsOf / hasDateConflict / availableDorms），**CheckIn.cshtml** 改为调真实 API：

```javascript
// 原型（mock-data.js）
const last = lastBookingOf(PERSONNEL, selectedEmp.id);
const active = activeBookingsOf(BOOKINGS, selectedEmp.id);

// v2.13.36（真实 API）
fetch(`/api/v1/bookings/employee-history/${selectedEmp.id}`).then(...)
fetch(`/api/v1/bookings/staying-records/${selectedEmp.id}`).then(...)
```

## 六、关闭行为升级

### 6.1 取消按钮

**之前**（Modal 内）：`data-bs-dismiss="modal"` 关闭弹窗
**现在**（独立页面）：`<a href="/Booking">` 跳转回办理登记列表

```html
<a href="/Booking" class="btn btn-outline-secondary">
    <i class="bi bi-x"></i> 取消
</a>
```

### 6.2 X 按钮

独立页面**没有 X 按钮**（因为不是弹窗）。如需"返回"，点击"取消"按钮或浏览器后退按钮即可。

### 6.3 提交按钮

```html
<button type="submit" class="btn btn-primary">
    <i class="bi bi-check-lg"></i> 提交
</button>
```

提交成功 → `alert()` 提示 → `location.href = '/Booking'` 跳转回列表。

### 6.4 快捷键

| 快捷键 | 行为 |
|--------|------|
| Enter | 提交表单（type=submit） |
| ESC | 浏览器后退（无 modal 可关闭） |
