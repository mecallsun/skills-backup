## 二、v2.13.39 实施变更

### 2.1 Details.cshtml — 当前入住人员表加 3 列

**改造位置**：`DormManage.Admin/Pages/Dorms/Details.cshtml` 第 189-242 行（当前入住人员 table）

**变更详情**：

| 原型列 | 改造前 | 改造后 |
|--------|--------|--------|
| 工号/姓名/部门/手机/考勤班次/床号/入住日期 | 7 列已有 | ✅ 保留 |
| **员工类型** | ❌ 缺 | ✅ Badge（FK 关联 SysEmployee.EmployeeTypeId → EmployeeType） |
| **已入住** | ❌ 缺 | ✅ Badge（天数计算：today - CheckInDate） |
| **操作** | ❌ 缺 | ✅ 调宿按钮（→ Booking/Edit）+ 退宿按钮（POST /api/v1/bookings/{id}/check-out） |

**PageModel 配套改造**（`Details.cshtml.cs`）：
1. `DormDetailDto` 新增 `RoomCount` 字段（与原型 basicInfo 第 5 行对齐）
2. `BookingRecordDto` 新增 `EmployeeTypeId` 字段（FK id）
3. 新增 `EmployeeTypeMap`（Dictionary<int, EmployeeTypeBadgeDto>）
4. 新增 `EmployeeTypeBadgeHelper.GetEmployeeTypeBadgeClass()`：与原型 Badge 颜色映射完全一致
   - CONTRACT → bg-secondary
   - TEMPORARY → bg-warning text-dark
   - OUTSOURCE → bg-info text-dark
   - INTERN → bg-success
   - ONSITE → bg-dark

### 2.2 Details.cshtml — 基本信息加房间数

**改造位置**：`Details.cshtml` 第 110-116 行（地址后、容量前）

```html
<div class="info-item">
    <span class="info-label">房间数</span>
    <span class="info-value">@Model.Dorm.RoomCount 间</span>
</div>
```

### 2.3 Details.cshtml — 退宿 JavaScript 函数

**新增**：`checkoutResident(bookingId, name)` 函数，POST 到 `/api/v1/bookings/{id}/check-out`，含 confirm 二次确认 + 错误捕获 + 成功后 location.reload()。
