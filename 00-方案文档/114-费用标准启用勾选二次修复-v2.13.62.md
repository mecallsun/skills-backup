## 二、深度根因排查（v2.13.62）

### 2.1 渲染 HTML 实际分析

通过 curl 抓取 `/BillingStandard/Edit?id=3` 的渲染 HTML，得到**实际输出**：

```html
<!-- asp-for 在 hidden field 上自动渲染（基于 ModelState） -->
<input type="hidden" name="Input.IsActive" value="false" />

<!-- asp-for 在 checkbox 上自动渲染 + 自动追加一个 hidden（用于未勾选时 fallback） -->
<input type="checkbox" class="form-check-input" data-val="true"
       data-val-required="The IsActive field is required."
       id="Input_IsActive" name="Input.IsActive" value="true" />
<input type="hidden" name="Input.IsActive" value="false" />
```

**总共 3 个 Input.IsActive 字段**（2 个 hidden + 1 个 checkbox）。

### 2.2 ASP.NET ModelBinder 行为分析

当用户勾选 checkbox 并提交表单，浏览器按 HTML 顺序发送：

```
Input.IsActive=false  ← 来自第一个 manual hidden
Input.IsActive=false  ← 来自 asp-for 自动生成的 hidden
Input.IsActive=true   ← 来自 checkbox
```

ASP.NET Core 的 `FormValueProvider` 使用 `NameValueCollection` 保留插入顺序。
`SimpleTypeModelBinder` 在绑定 `bool` 时**取第一个能成功转换的值**。

由于第一个值是 `"false"`，能成功转换为 bool（false），所以：
- **`Input.IsActive = false`** ← 用户的勾选被忽略！

### 2.3 v2.13.61 修复不彻底的原因

v2.13.61 增加了**第一个 manual hidden**（`<input type="hidden" asp-for="Input.IsActive" value="false" />`），但 asp-for 在 hidden field 上又会**自动生成第二个 hidden**（用于未勾选 fallback）。最终导致：

| 表单字段 | 数量 | 来源 |
|---------|------|------|
| manual hidden | 1 | v2.13.61 错误添加 |
| asp-for auto hidden | 1 | tag helper 自动生成 |
| checkbox | 1 | asp-for |

**3 个字段同名 → ModelBinder 取第一个 → 永远 false** ❌

## 三、修复方案（v2.13.62）

### 3.1 修复策略

**保留 asp-for 自动生成的 hidden，移除 manual hidden**：

- ✅ 保留 `<input asp-for="Input.IsActive" type="checkbox" />` → asp-for 自动追加 hidden 作为 fallback
- ❌ 移除 `<input type="hidden" asp-for="Input.IsActive" value="false" />` → 不再干扰 ModelBinder

修复后的渲染 HTML（仅 2 个字段）：

```html
<!-- asp-for 自动生成（checkbox + hidden 配对） -->
<input type="checkbox" class="form-check-input"
       id="Input_IsActive" name="Input.IsActive" value="true" />
<input type="hidden" name="Input.IsActive" value="false" />
```

### 3.2 修复后 ModelBinder 行为

**用户勾选时**提交顺序：
```
Input.IsActive=true   ← 来自 checkbox
Input.IsActive=false  ← 来自 asp-for 自动 hidden
```
ModelBinder 取第一个能转换的值 → `"true"` → `bool.TrueString` → **`true`** ✅

**用户未勾选时**只提交：
```
Input.IsActive=false  ← 来自 asp-for 自动 hidden
```
ModelBinder → `"false"` → **`false`** ✅

## 七、教训总结（v2.13.61 → v2.13.62）

### 7.1 核心教训

1. ❌ **`asp-for` 复选框会自动生成 hidden field**（用于未勾选时提交 false）—— 在 hidden field 上使用 `asp-for` + `value="false"` 静态值是**双重 hidden**，导致 ModelBinder 取错值
2. ❌ **`<input type="hidden" asp-for="X" />` + `<input asp-for="X" type="checkbox" />` 组合 = 2 个 hidden + 1 个 checkbox** —— 永远会让 X=false
3. ✅ **正确做法**：只写 `<input asp-for="X" type="checkbox" />`，让 asp-for 自动管理 hidden

### 7.2 强制检查清单（checkbox 表单持久化）

- [ ] 检查渲染 HTML 中 `name="X"` 字段数量（应该是 1 hidden + 1 checkbox）
- [ ] 如果有 2 个以上 hidden，立即删除手动添加的（asp-for 已自动处理）
- [ ] 通过 curl 模拟 POST 验证 IsActive 真值/假值都能正确持久化
- [ ] 不依赖 ModelState 推断 HTML 渲染结果（asp-for 行为会因 ModelState 变化而变化）
