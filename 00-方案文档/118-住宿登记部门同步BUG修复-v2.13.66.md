### 2.2 根因 — BookingService.GetListAsync LINQ 投影缺 Department

源码（v2.13.65 修复前）：

```csharp
// DormManage.Shared/Services/BookingService.cs
var query =
    from b in _db.DormBookings.AsNoTracking()
    join emp in _db.Employees.AsNoTracking() on b.EmployeeId equals emp.Id into empGroup
    from emp in empGroup.DefaultIfEmpty()
    select new
    {
        Booking = b,
        AttendanceTypeId = (int?)(emp != null ? emp.AttendanceTypeId : b.AttendanceTypeId),
        RealName = emp != null && !string.IsNullOrEmpty(emp.RealName) ? emp.RealName : (b.EmployeeName ?? ""),
        EmployeeCode = emp != null && !string.IsNullOrEmpty(emp.EmployeeCode) ? emp.EmployeeCode : (b.EmployeeCode ?? "")
        // ❌ 缺 Department 投影！
    };
```

DTO 直接取 `x.Booking.Department`（冗余字段），没用 `emp.Department`：

```csharp
Department = x.Booking.Department,  // ← 直接读 DormBooking.Department（冗余字段，未覆盖）
```

物化覆盖循环也只覆盖 AttendanceTypeId / RealName / EmployeeCode，**没有覆盖 Department**：

```csharp
foreach (var item in items)
{
    if (item.AttendanceTypeId.HasValue) item.Booking.AttendanceTypeId = item.AttendanceTypeId;
    if (!string.IsNullOrEmpty(item.RealName)) item.Booking.EmployeeName = item.RealName;
    if (!string.IsNullOrEmpty(item.EmployeeCode)) item.Booking.EmployeeCode = item.EmployeeCode;
    // ❌ 缺 Department 覆盖！
}
```

## 三、修复方案（v2.13.66）

### 3.1 LINQ 投影增加 Department

```csharp
select new
{
    Booking = b,
    AttendanceTypeId = (int?)(emp != null ? emp.AttendanceTypeId : b.AttendanceTypeId),
    RealName = emp != null && !string.IsNullOrEmpty(emp.RealName) ? emp.RealName : (b.EmployeeName ?? ""),
    EmployeeCode = emp != null && !string.IsNullOrEmpty(emp.EmployeeCode) ? emp.EmployeeCode : (b.EmployeeCode ?? ""),
    // v2.13.66 BUG：实时取最新部门（人员清单为唯一真源；档案缺失/为空时回退冗余字段；都不存在则 NULL）
    Department = emp != null && !string.IsNullOrEmpty(emp.Department) ? emp.Department : b.Department
};
```

### 3.2 部门筛选条件同步扩展

原代码只用 `x.Booking.Department` 筛选（冗余字段），修改为 JOIN 优先 + 回退冗余：

```csharp
if (!string.IsNullOrWhiteSpace(department))
{
    var dept = department.Trim().ToLower();
    query = query.Where(x =>
        (x.Department != null && x.Department.ToLower().Contains(dept)) ||     // v2.13.66 新增：JOIN 优先
        (x.Booking.Department != null && x.Booking.Department.ToLower().Contains(dept)));
}
```

### 3.3 DTO 和物化覆盖循环增加 Department

```csharp
// DTO
Department = x.Department ?? x.Booking.Department,

// 物化覆盖循环
foreach (var item in items)
{
    if (item.AttendanceTypeId.HasValue) item.Booking.AttendanceTypeId = item.AttendanceTypeId;
    if (!string.IsNullOrEmpty(item.RealName)) item.Booking.EmployeeName = item.RealName;
    if (!string.IsNullOrEmpty(item.EmployeeCode)) item.Booking.EmployeeCode = item.EmployeeCode;
    // v2.13.66 BUG：覆盖显示用部门（仅 RAM，DB 不写；人员清单为唯一真源）
    if (!string.IsNullOrEmpty(item.Department))
    {
        item.Booking.Department = item.Department;
    }
}
```

### 3.4 RepairBookingEmployeeNamesAsync 扩展为同时回填 Department

```csharp
public async Task<ApiResponse<(int Updated, int Skipped, int NotFound)>> RepairBookingEmployeeNamesAsync()
{
    var allBookings = await _db.DormBookings
        .Where(b => !string.IsNullOrEmpty(b.EmployeeCode))
        .Select(b => new { b.Id, b.EmployeeId, b.EmployeeCode, b.EmployeeName, b.Department })  // v2.13.66 新增
        .ToListAsync();
    
    var employees = await _db.Employees
        .Where(e => empIds.Contains(e.Id) || empCodes.Contains(e.EmployeeCode))
        .Select(e => new { e.Id, e.EmployeeCode, e.RealName, e.Department })  // v2.13.66 新增
        .ToListAsync();
    
    foreach (var b in allBookings)
    {
        // ... 取 emp ...
        // v2.13.66：扩展为任一字段不一致即更新
        bool deptChanged = !string.IsNullOrEmpty(emp.Department) && !string.Equals(emp.Department, b.Department, StringComparison.Ordinal);
        if (!nameChanged && !codeChanged && !deptChanged) { skipped++; continue; }
        
        var entity = await _db.DormBookings.FindAsync(b.Id);
        if (entity is null) continue;
        if (nameChanged) entity.EmployeeName = emp.RealName;
        if (codeChanged) entity.EmployeeCode = emp.EmployeeCode;
        if (deptChanged) entity.Department = emp.Department;  // v2.13.66 新增
        entity.UpdatedAt = DateTime.Now;
        affected.Add(entity);
        updated++;
    }
    
    if (affected.Count > 0) await _db.SaveChangesAsync();
    return ApiResponse<(int, int, int)>.Ok((updated, skipped, notFound));
}
```

## 七、教训总结

### 7.1 关键教训

1. **「人员维度冗余字段」必须 JOIN 覆盖** — `DormBooking` 表冗余存储 `EmployeeName / EmployeeCode / Department` 等员工信息字段。**列表展示规则**：必须通过 `EmployeeId` FK JOIN `SysEmployee` 实时取最新档案值。任何新增冗余字段都必须遵循此规则。
2. **同步策略三件套要齐备** — 每次新增冗余字段同步都要同步做 3 件事：
   - LINQ 投影增加字段（`Department = emp?.Department ?? b.Department`）
   - 物化覆盖循环增加字段（`if (!IsNullOrEmpty) item.Booking.X = x`）
   - 筛选/Repair API 同步扩展
3. **v2.13.32-hotfix / v2.13.47 / v2.13.66 三次同主题 BUG** — 揭示出**同模式 BUG 必须全字段审计**：每修复一个字段，都要审视其他同结构字段（RealName 修了 → EmployeeCode 修了 → Department 修了）。建议未来**新增 DormBooking 冗余字段时一次性把 JOIN + 覆盖 + 筛选 + Repair 都加上**。

### 7.2 强制检查清单（住宿登记同步字段自检）

- [ ] LINQ 投影包含 `Field = emp?.Field ?? b.Field`
- [ ] 物化覆盖循环包含 `if (!IsNullOrEmpty) item.Booking.Field = x.Field`
- [ ] 筛选条件包含 JOIN 字段 + 回退冗余字段
- [ ] Repair API 包含同步字段比较 + 回写
- [ ] SysEmployeeLite 内部 DTO 包含同步字段
- [ ] 端到端 curl 验证：列表/筛选/Repair 三种入口都正确
