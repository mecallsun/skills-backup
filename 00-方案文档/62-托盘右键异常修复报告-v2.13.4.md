## 1. 问题描述

### 1.1 用户反馈

> 当前托盘程序，右键出错，提示：UI异常，创建窗口出错。

### 1.2 影响范围

| 项 | 内容 |
|----|------|
| 模块 | DormManage.TrayApp（托盘守护程序） |
| 触发路径 | 右键托盘 → 系统设置... |
| 错误位置 | `TrayAppContext.ShowSettings()` → `new SettingsForm(...).ShowDialog()` |
| 阻断 | 托盘右键菜单仍能弹出，但点击"系统设置..."立即抛"创建窗口出错" |
| 严重等级 | **P0**（核心运维入口失效，配置无法可视化修改） |

---

## 2. 根因分析

### 2.1 根本原因（5 项叠加）

| # | 根因 | 影响 |
|---|------|------|
| ① | **TrayAppContext 继承 `ApplicationContext` 但无主 Form**，所有 `Form.ShowDialog()` 无 Owner 时 WinForms 内部尝试创建隐式 Owner 窗口，在 Win11 高 DPI / 主题加载未完成 / 时序敏感环境下 `CreateWindowEx` 失败 | "创建窗口出错" |
| ② | **NotifyIconManager 右键菜单未关联到任何 Form**，ContextMenuStrip.Show 时找不到宿主窗口 | 右键菜单可能无法弹出 |
| ③ | **AboutForm 使用 `SystemFonts.MessageBoxFont!.FontFamily`**（null-forgiving 强行通过），在极少数场景下 `MessageBoxFont` 为 null 时 NRE | 后续右键 → 关于 也崩溃 |
| ④ | **SettingsForm 构造函数无异常保护**，任一控件/字段构造失败即整窗崩溃 | 右键 → 设置 永久 500 |
| ⑤ | **TrayAppContext.ShowSettings / ShowAbout 无 try-catch**，弹窗失败会拖死整个 UI 线程，一次失败后右键失效 | 故障放大 |

### 2.2 错误堆栈（典型）

```
System.InvalidOperationException: 创建窗口句柄时出错。
   at System.Windows.Forms.NativeWindow.CreateHandle(CreateParams cp)
   at System.Windows.Forms.Control.CreateHandle()
   at System.Windows.Forms.Form.ShowDialog(IWin32Window owner)
   at DormManage.TrayApp.TrayAppContext.ShowSettings()
```

### 2.3 触发时序

```
托盘启动 (Program.Main)
  ↓
TrayAppContext 构造 → 继承 ApplicationContext（无 Form）
  ↓
NotifyIcon 显示图标（右键菜单 ContextMenuStrip）
  ↓ [用户操作]
用户右键 → "系统设置..." 菜单项 Click
  ↓
TrayAppContext.ShowSettings()
  ↓
new SettingsForm(...).ShowDialog()    ← ❌ 无 Owner
  ↓
WinForms 内部尝试隐式创建 Owner
  ↓ [失败点]
CreateWindowEx 返回 NULL
  ↓
InvalidOperationException: 创建窗口句柄时出错
  ↓
Application.ThreadException 捕获
  ↓
MessageBox.Show("UI 异常：创建窗口出错。")  ← 用户看到的提示
```

## 3. 修复方案

### 3.1 修复原则

> 严格按需求规格 57 §3.2（配置窗口）+ §3.1（托盘菜单）+ §5（验收用例）生成。
> 双 UI 职责划分（CLAUDE.md 强制）：托盘 SettingsForm 仅保留核心服务端参数，无权限控制。

### 3.2 核心修复（5 项）

| # | 修复 | 文件 | 实现 |
|---|------|------|------|
| ① | **TrayAppContext 内嵌不可见 OwnerForm** | `TrayAppContext.cs` | `new Form { Opacity=0, ShowInTaskbar=false, FormBorderStyle=None, Size=0,0 }`，强制 `Handle` 创建，并设为 `MainForm` |
| ② | **NotifyIconManager 接受 owner 参数** | `NotifyIconManager.cs` | 构造函数加 `Form owner` 参数；ContextMenuStrip 不再依赖隐式宿主 |
| ③ | **三层 Font 兜底** | `NotifyIconManager.cs` / `AboutForm.cs` | `SystemFonts.MessageBoxFont ?? SystemFonts.MenuFont ?? new Font("Microsoft YaHei UI", 9f)` |
| ④ | **SettingsForm 拆分 + 整体 try-catch** | `Forms/SettingsForm.cs` | 拆分为 `InitializeControls()` / `BuildUI()` / `AttachEventHandlers()` / `StartStatusTimer()`，整体包 try-catch，构造失败时抛出 `InvalidOperationException` 让调用方接住 |
| ⑤ | **所有弹窗路径 try-catch** | `TrayAppContext.cs` | `ShowSettings` / `ShowAbout` / `OpenLogsFolder` / `ToggleAutoStart` 全部包 try-catch + 友好 MessageBox |

### 3.3 SettingsForm 重构要点

| 区域 | 原版 | v2.13.4 |
|------|------|---------|
| 窗口尺寸 | 620×580 | **680×620** + MinimumSize 620×560 |
| 顶部标题区 | 无 | **新增 蓝色 header（48px）**，⚙ 系统设置 — 核心服务端参数 |
| 服务端口 | 内嵌 TableLayoutPanel | 同，但增加 dock=Fill 防挤压 |
| Api/Admin 路径 | 同 | + Browse 失败 try-catch |
| 数据库类型 | 同 | + SelectedIndex<0 时回退到 0 |
| SQL Server 连接串 | 内嵌子面板 | **改为独立 TextBox（多行 56px）** |
| SQLite 路径 | 内嵌子面板 | **独立一行 + 浏览**（OpenFileDialog） |
| 图片路径 | FolderBrowserDialog | FolderBrowserDialog + COMException 兜底回退到手动输入 |
| 行为配置 | 同 | CheckBox 加中文说明 |
| 服务状态 | 同 | 1s 定时刷新 + try-catch 静默 |
| 底部按钮 | 顺序 Start/Stop/Restart/Save/Cancel | **顺序调整为 Cancel/Save/Restart/Stop/Start**（常用操作靠右） |
| ESC 关闭 | 无 | **新增 KeyPreview + ESC 关闭** |
| 释放 | 定时器 Stop/Dispose | + null 检查 + try-catch |

### 3.4 NotifyIconManager 重构要点

| 项 | 原版 | v2.13.4 |
|----|------|---------|
| 构造函数参数 | 9 个 Action/Func | **增加 Form owner（10 个）** |
| MenuItem 构造 | 内联 new ToolStripMenuItem + lambda | **拆分 NewMenuItem / NewStatusItem 工厂方法**，明确避免 nullable 歧义 |
| Font 兜底 | 无 | **SafeMenuFont 三层兜底** |
| Click 回调 | 内联 lambda | **SafeInvoke / SafeInvokeAsync 统一异常捕获** |
| 菜单项"设置" | "设置..." | **改为"系统设置..."**（按 CLAUDE.md 双 UI 职责规范） |

### 3.5 TrayAppContext 重构要点

| 项 | 原版 | v2.13.4 |
|----|------|---------|
| 基类 | `ApplicationContext`（无 Form） | 仍继承 `ApplicationContext`，**但内嵌 OwnerForm + MainForm=_ownerForm** |
| Dispose | `new void Dispose()` | 同（已正确加 new 关键字消除 CS0108） |
| ShowSettings | 直接 `form.ShowDialog()` | **`form.ShowDialog(_ownerForm)` + 整体 try-catch** |
| ShowAbout | 直接 ShowDialog | **+ try-catch + _ownerForm** |
| OpenLogsFolder | 无 try-catch | **+ try-catch + _ownerForm** |
| ToggleAutoStart | MessageBox 无 Owner | **+ _ownerForm + try-catch** |
| ExitAsync 退出确认 | 无 Owner MessageBox | **SafeShow 三层兜底** |

## 7. 风险与回滚

### 7.1 残余风险

| 风险 | 缓解 |
|------|------|
| OwnerForm.Handle 创建失败 | 已包 try-catch，失败时回退到无 Owner ShowDialog |
| FolderBrowserDialog 在 Win11 高 DPI 下偶发 COMException | try-catch + 提示用户手动输入 |
| 右键菜单连续点击导致多次弹窗 | 单实例窗口 + Form.ShowDialog 的模态语义天然阻止 |

### 7.2 回滚方案

如出现严重问题，回滚至 v2.13.3 提交 `b753c1c`，重新生成 SettingsForm 入口。
