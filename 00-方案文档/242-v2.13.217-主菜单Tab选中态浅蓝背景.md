## 2. 现状分析

### 2.1 现有 Tab 选中态实现

**JS 激活态逻辑**（`_shared/tab-bar.js:162-164`）：
```js
const itemsHtml = FIXED_TABS.map(tab => {
  const cls = tab.id === activeId ? 'active' : '';
  // ...
});
```

**激活态推断**（`_shared/tab-bar.js:50-75`）：
- `inferActiveTabId(currentUrl, basePath)` 根据 URL 路径前缀匹配
- 激活 ID 持久化到 localStorage（`STORAGE_KEYS.ACTIVE_TAB`）

**激活态 CSS**（修改前 `_shared/layout-tab.css:202-231`）：
```css
.tab-item.active {
    background: #ffffff;       /* 白底 */
    color: var(--tab-primary);  /* 蓝字 */

    border-bottom-color: var(--tab-primary);

.tab-item.active[data-module="booking"],
.tab-item.active[data-module="dorms"] { border-bottom-color: var(--tab-primary); }
.tab-item.active[data-module="personnel"] { color: var(--tab-success); ... }   /* 绿 */

.tab-item.active[data-module="meter"] { color: var(--tab-info); ... }    /* 青 */
.tab-item.active[data-module="basics"], ... { color: #546e7a; ... }      /* 灰 */
```

### 2.2 现状问题

- **当前选中态**：**白底** + 3px 下边框 + 模块色文字
- **不符合用户需求**：用户明确要求**浅蓝色背景**
- **5 种模块配色**：设计较复杂，视觉一致性差

## 3. v2.13.217 修复方案（统一浅蓝色背景）

### 3.1 设计原则

| 原则 | 说明 |
|------|------|
| **统一配色** | 所有 10 个 Tab 选中态统一为浅蓝色（**用户原话「浅兰色」**） |
| **背景为主** | 视觉强调从「下边框」转为「背景色」，更明显 |
| **保留识别** | 选中态文字加深 + 加粗，保持可识别 |
| **hover 区分** | hover 用更浅的蓝色（`#f5f9ff`），与选中（`#e3f2fd`）区分 |

### 3.2 颜色方案（Material Design Blue 色阶）

| 状态 | 颜色 | RGB | 用途 |
|------|------|-----|------|
| 未选中 | 透明 | — | 默认 |
| hover | `#f5f9ff` | Blue 50- | 鼠标悬浮 |
| **选中背景** | **`#e3f2fd`** | **Blue 50** | **用户要求的浅蓝色** |
| 选中文字 | `#0d47a1` | Blue 900 | 深蓝文字 |
| 选中下边框 | `#1976d2` | Blue 700 | 2px 辅助强调 |

### 3.3 修改前后对比

| 维度 | 修改前（v2.13.216） | 修改后（v2.13.217） |
|------|---------------------|---------------------|
| **背景色** | `#ffffff`（白） | **`#e3f2fd`（浅蓝）** ✅ |
| **文字色** | 5 种模块色（蓝/绿/黄/青/灰） | **统一 `#0d47a1`（深蓝）** ✅ |
| **下边框** | 3px 模块色 | **2px `#1976d2`（深蓝）** |
| **hover 背景** | `rgba(25, 118, 210, 0.04)` | **`#f5f9ff`（更浅蓝）** ✅ |
| **模块分组配色** | 5 种颜色 | **统一删除（保留兼容代码）** |

### 3.4 CSS 改动（`_shared/layout-tab.css:197-231`）

```css
/* v2.13.217 修改前 */
.tab-item:hover {
    background: rgba(25, 118, 210, 0.04);
    color: var(--tab-primary);
}
.tab-item.active {
    background: #ffffff;
    color: var(--tab-primary);
    border-bottom: 3px solid;
    border-bottom-color: var(--tab-primary);
    font-weight: 600;
    z-index: 1;
}
.tab-item.active[data-module="booking"],
.tab-item.active[data-module="dorms"] { border-bottom-color: var(--tab-primary); }
.tab-item.active[data-module="personnel"] { color: var(--tab-success); ... }
... (省略 5 种模块色)

/* v2.13.217 修改后 */
.tab-item:hover {
    background: #f5f9ff;  /* hover 浅蓝背景 */
    color: #1565c0;
}
.tab-item.active {
    background: #e3f2fd;   /* 浅蓝色（用户要求） */
    color: #0d47a1;         /* 深蓝文字 */
    border-bottom: 2px solid #1976d2;
    border-bottom-color: #1976d2;
    font-weight: 600;
    z-index: 1;
}
/* 5 种模块配色保留为兼容历史（已不再生效） */
.tab-item.active[data-module="booking"], ... { /* 统一浅蓝 */ }
```

## 7. 永久教训（v2.13.217+ 强制沉淀）

### 7.1 **用户原话中关键词必须严格执行**

用户原话「**浅兰色**」（浅蓝色）= **`#e3f2fd`（Material Blue 50）**。不要自作主张用「白色 + 蓝色下边框」（虽然技术上也是「蓝色提示」），要严格按用户原话执行。

### 7.2 **统一配色 > 多模块配色**

旧的「按模块分组配色」（5 种颜色）虽然在分类上合理，但**视觉一致性差**。当用户要求「统一浅蓝」时，简化配色更易管理。

### 7.3 **共享 CSS 修改 = 全站自动生效**

只需修改 `_shared/layout-tab.css` 一个文件，27+ 个原型页面**自动同步**。这是「单一权威源」原则的胜利。

### 7.4 **兼容代码保留为历史文档**

本次修改保留了「按模块分组配色」的 CSS 规则但改为「统一浅蓝」。**保留代码**而不是删除，让历史设计思路可追溯（v2.13.x 风格规范）。

### 7.5 **先原型后程序**

用户明确说「先实现原型功能」——意味着本版本**只改 `00-方案文档/04-HTML原型/`**。**程序端（DormManage.Admin `_Layout.cshtml`）不在本次范围**，留待 v2.13.218 或后续版本同步实施。
