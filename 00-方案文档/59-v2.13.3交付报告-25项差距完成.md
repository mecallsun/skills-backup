## 5. v2.13.3 新增：DormManage.TrayApp IPC Server 集成

为闭环 P1-11 服务启停 API，托盘程序集成 IPC Server：

- 端口：5099（仅 127.0.0.1）
- 命令：`ping` / `status` / `start` / `stop` / `restart`
- 服务参数：`api` / `admin` / `all` / `null`
- 处理：`TrayAppContext.HandleIpcCommand` 分发，异步处理

**完整控制链**：
```
Web Admin（API Controller）
  ↓ HTTP POST /api/v1/system/services/{name}/{action}
  ↓ IpcClient.SendAsync
  ↓ TCP 127.0.0.1:5099
  ↓ IpcServer.HandleClientAsync
  ↓ TrayAppContext.HandleIpcCommand
  ↓ ProcessManager.StartApiAsync / StopApiAsync / RestartAllAsync
  ↓ Process.Start / Process.Kill / Process.Exited
```

## v2.13.109 备注：SQLite Provider 彻底移除

自 v2.13.109 起，DormManage 运行时仅支持 SQL Server。SQLite 代码路径、EF Core SQLite Provider、SQLite 备份恢复逻辑均已移除。历史配置中的 SqlitePath 字段仅为旧配置反序列化兼容，不代表运行时继续支持 SQLite。
