## 一、需求背景

**用户原话：**
> "将 人员清单 住宿详情 中的 列表里 显示的 考勤班次 全部简称显示为「班次」，同步更新文档 及程序，发布程序文件包"

**业务目标**：
1. **列名缩短**：列表/详情/筛选条件中所有「考勤班次」列名/标签简称化为「班次」，节省表格宽度（避免 4 字标签导致窄屏列截断）
2. **值单字化**：数据库 `AttendanceType.Name` 从「早班/中班/晚班/夜班」改为「早/中/晚/夜」，配合列名简化形成「单字列名 + 单字值」的紧凑布局

**关键决策（用户已确认 — AskUserQuestion 选项 C）**：
- ✅ **方案 C：直接修改 Name 为单字（动 DB）** — 同步改 `AttendanceType.HasData`（开发/新部署自动同步）+ 生产手工 UPDATE 脚本（idempotent）
- ❌ 方案 A/B（仅 UI 别名 / 视图层映射）— 不彻底，导出 CSV/Excel 仍显示全字

## 三、数据迁移 SQL（生产环境）

**触发条件**：已存在生产数据 + 名称显示不符合 v2.13.98 规范  

**SQL 脚本**（事务回滚安全 + idempotent）：
```sql
BEGIN TRAN;
UPDATE AttendanceType SET Name = N'早'   WHERE Id = 2 AND Name = N'早班';
UPDATE AttendanceType SET Name = N'中'   WHERE Id = 3 AND Name = N'中班';
UPDATE AttendanceType SET Name = N'晚'   WHERE Id = 4 AND Name = N'晚班';
UPDATE AttendanceType SET Name = N'夜'   WHERE Id = 5 AND Name = N'夜班';
-- Id=1 '默认' / Id=6 '其他' 已是单字，无需修改
COMMIT;
```

**幂等性**：4 行 UPDATE 都有 `WHERE Name = N'X班'` 守卫，已是单字时不重复执行

**回滚**：
```sql
UPDATE AttendanceType SET Name = N'早班' WHERE Id = 2;
UPDATE AttendanceType SET Name = N'中班' WHERE Id = 3;
UPDATE AttendanceType SET Name = N'晚班' WHERE Id = 4;
UPDATE AttendanceType SET Name = N'夜班' WHERE Id = 5;
```

**PowerShell 一键脚本**：`scripts/rename_v2.13.98_attendance_label.ps1 -SqlServerInstance "192.168.1.237" -Database "WaterMeterDB"`

**EF Core 自动路径**：新部署环境 `EnsureCreated` 会读取 `HasData(单字)` 自动初始化，无需手工执行

## 七、风险与回退

### 7.1 风险评估

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 字符串冲突 | 极低 | 低 | 仅改 AttendanceType 6 行；不动其他表 |
| 历史数据 NULL | 极低 | 低 | UPDATE 有 WHERE 守卫，NULL 值不匹配 |
| API 响应变更 | 中 | 低 | 客户端 JS 按 Code 渲染 Badge，不依赖 Name |
| 旧模板导入 | 中 | 中 | 模板 header 改「班次」；旧模板仍可导入（值映射按 Name 模糊匹配） |

### 7.2 回退方案

**方案 1：数据库回滚**（5 行 SQL）
```sql
UPDATE AttendanceType SET Name = N'早班' WHERE Id = 2;
UPDATE AttendanceType SET Name = N'中班' WHERE Id = 3;
UPDATE AttendanceType SET Name = N'晚班' WHERE Id = 4;
UPDATE AttendanceType SET Name = N'夜班' WHERE Id = 5;
```

**方案 2：代码回滚**（git revert）
```bash
git revert HEAD
# 或回滚到上一版本
git checkout v2.13.97 -- DormManage.Admin DormManage.Api DormManage.Shared DormManage.TrayApp
```

**方案 3：UI 层适配**（如果 DB 不允许动）
- 仅回退数据层 + service 层保留 UI 简化
- 列表显示 UI 截断：`@Html.DisplayName(model => model.AttendanceTypeName).Substring(0, 1)` 强制单字
