# 需求规格说明书 — v2.11.4 增补 (t)：住宿管理列表删除"历史"按键

> **范围**：住宿管理列表页面（dorms/list.html）
> **日期**：2026-07-11
> **对应原型**：`04-HTML原型/dorms/list.html`

---

## 1. 变更背景

住宿管理列表的操作列中原有"历史"按键，点击后跳转到 `history.html` 页面查看该住宿的住宿历史。

由于住宿详情页（`details.html`）已内置"查看住宿历史"功能（点击展开 timeline 时间线），无需再从列表页跳转到独立历史页面。

本次删除列表页的"历史"按键，减少冗余操作。

---

## 2. 变更内容

### 2.1 修改前

```
┌────────────────────────────────────────────────────────┐
│ 操作列                                              │
│ [详情] [历史] [编辑] [删除]                        │
└────────────────────────────────────────────────────────┘
```

### 2.2 修改后

```
┌────────────────────────────────────────────────────────┐
│ 操作列                                              │
│ [详情] [编辑] [删除]                               │
└────────────────────────────────────────────────────────┘
```

### 2.3 理由

1. **功能重复**：住宿详情页已有"查看住宿历史"开关按钮
2. **操作简化**：减少列表页的操作按钮
3. **路径一致**：查看历史 → 详情页 → 查看历史

---

## 3. 验收清单

- [x] 删除"历史"按钮链接 `<a href="history.html?code=...">`
- [x] 保留"详情"按钮（跳转到 details.html）
- [x] 保留"编辑"和"删除"按钮
- [x] 列表页功能不受影响
