## 一、用户原话

> "在 原型 中的 住宿档案 列表 中，增加列"班组" ，记录对应 显示为 该住宿房号 已在宿 人员的 员工档案 中 员工 的 班组 id 的 集合，如：A101 住宿入住 3人，分别 员工的 班组是 A班、B班、B班，则班组列表中 根据 在宿 员工 班组 显示 该房号 的 班组 为：A/B"

> （追加澄清）"房号 无人入住 则 班组 对应记录 显示 空白 无字符"

## 二、需求深度解读

### 2.1 数据关系

```
Dorm (房号 A101)
  ↓ 1:N (DormCode FK)
DormBooking (Status=2 在宿)  ← 派生查询起点
  ↓ N:1 (EmployeeId FK)
SysEmployee (TeamId FK)
  ↓ N:1 (TeamId FK)
Team (Name + SortOrder)
```

### 2.2 显示规则（业务定义）

| 场景 | 在宿员工班组 | 显示 |
|------|-------------|------|
| 3 人 A班/B班/B班 | TeamId=1, 2, 2 | **A/B**（去重 + 按 Team.SortOrder 升序）|
| 4 人 A/A/B/C | 1, 1, 2, 3 | **A/B/C** |
| 单人 A | 1 | **A** |
| 无人入住 | — | **空白（无任何字符）** |
| 员工无班组 | TeamId 异常 | 不计入（孤儿数据过滤）|

/// <summary>当前在宿员工的班组名称集合（按 Team.SortOrder 升序 + 去重）。
/// 数据关系：DormBooking (Status=2 在宿) → SysEmployee (TeamId FK) → Team (Name + SortOrder)。</summary>
public List<string> TeamNames { get; set; } = new();
/// <summary>渲染为「一班/三班」格式字符串（前端直接展示）</summary>
public string TeamNamesText => string.Join("/", TeamNames);

### 4.2 Index.cshtml.cs 派生 SQL

```csharp
// v2.13.111 派生班组（基于当前在宿员工的 TeamId FK → Team.Name，去重 + 按 SortOrder 升序）
// JOIN DormBookings(Status=2) → SysEmployee(TeamId) → Team(Name + SortOrder)
var teamStats = await _db.DormBookings
    .Where(b => dormCodes.Contains(b.DormCode) && b.Status == 2)
    .Join(_db.Employees.AsNoTracking(),
          b => b.EmployeeId, e => e.Id,
          (b, e) => new { b.DormCode, e.TeamId })
    .Join(_db.Teams.AsNoTracking(),
          x => x.TeamId, t => t.Id,
          (x, t) => new { x.DormCode, TeamId = t.Id, TeamName = t.Name, SortOrder = t.SortOrder })
    .GroupBy(x => x.DormCode)
    .Select(g => new
    {
        DormCode = g.Key,
        TeamNames = g.OrderBy(x => x.SortOrder).ThenBy(x => x.TeamId)
                     .Select(x => x.TeamName).Distinct().ToList()
    })
    .ToDictionaryAsync(x => x.DormCode, x => x.TeamNames);
```

## 七、核心原则

1. **去重 + 排序标准化**：所有班组派生列统一 `Distinct().OrderBy(SortOrder)`，避免重复显示（A/B/B → A/B）
2. **批量 JOIN 避免 N+1**：与 v2.13.95 班次、v2.13.85 性别完全对称（IN 列表 + GroupBy + Dictionary）
3. **无人入住空白**：用户追加需求 — `<td>` 完全空白，不渲染 `-` 或 `0` 或 `N/A`
4. **Badge 单色**：与 v2.13.97 Booking 列表班组列对齐 `bg-primary`（不再按 TEAM_X 首字母派生 6 色）
5. **无 schema 迁移**：完全派生字段，无数据库 schema 变更
