### 0.2 URL 推断激活 Tab 的规则

```javascript
function inferActiveTabId(currentUrl, basePath) {
  // 移除 basePath 前缀
  // 按路径前缀匹配：
  if (url === 'index.html')                        return 'tab-home';
  if (url.startsWith('booking/'))                  return 'tab-booking';
  if (url.startsWith('dorms/'))                    return 'tab-dorms';
  if (url.startsWith('personnel/'))                return 'tab-personnel';
  if (url.startsWith('billing/employee-bills'))    return 'tab-employee-bills';
  if (url.startsWith('billing/dorm-bills'))        return 'tab-dorm-bills';
  if (url.startsWith('billing/standards'))         return 'tab-billing';
  if (url.startsWith('billing/standard-form'))     return 'tab-billing';  // 表单页归属"费用标准"
  if (url.startsWith('meter/'))                    return 'tab-meter';
  if (url.startsWith('basics/'))                   return 'tab-basics';
  if (url.startsWith('settings/'))                 return 'tab-settings';
  return 'tab-home'; // 默认
}
```

### 0.3 业务含义

v2.12.2 之后，Tab 完全作为**菜单项切换**使用：

- ✅ 所有页面访问时，Tab 列表始终是固定的 10 个；
- ✅ 子页面（详情/编辑/创建）自动归属到对应的父级菜单 Tab，无需手动打开；
- ✅ 切换 Tab = 跳转到对应菜单的页面（首页/列表页）；
- ✅ 任意页面 URL 都能自动找到对应的激活 Tab，无需调用 `TabManager.open()`；
- ✅ localStorage 仅保存激活 Tab ID，不保存 Tab 列表（列表是常量）；
- ✅ 个人中心"清除 Tab 缓存"重置激活 Tab 为首页。

## 1. 设计理念

将原本"每页独立绘制 + 单层菜单导航"的模式升级为 **"共用页头 + Tab 页签切换"** 模式：

| # | 旧模式（v2.11 及以前） | 新模式（v2.12 起） |
|---|----------------------|------------------|
| 1 | 顶部品牌栏 + 单层菜单导航横向排列所有一级菜单 | 顶部品牌栏 + **紧凑型图标导航条**（仅图标） |
| 2 | 点击菜单即整页跳转（URL 切换） | 点击图标**新增 Tab 页签**，原 Tab 不关闭 |
| 3 | 浏览器后退/前进依赖 history | Tab 列表持久化（localStorage），支持任意关闭 |
| 4 | 列表页头与导航各页独立 | 所有页面共用页头（图标导航 + Tab + 内容切换） |

### 1.1 核心价值

- **降低切换成本**：用户无需离开当前页即可打开任意模块；
- **多任务并行**：可以同时打开"宿舍管理"和"抄表记录"两个 Tab 互相参照；
- **视觉一致性**：所有页面共享同一套页头和 Tab 框架，符合 §35 列表页规范；
- **响应更迅速**：Tab 内切换不重新加载页头，DOM 缓存复用。

## 2. 整体架构（v2.12.3 三层架构）

```
┌──────────────────────────────────────────────────────────────────────┐
│ Tier 1  顶部品牌栏 (top-bar)                                              │
│  [Logo + 品牌名 + 版本号]                          [用户胶囊 + 退出]   │
├──────────────────────────────────────────────────────────────────────┤
│ Tier 2  Tab 页签栏 (tab-bar) — 直接作为菜单项切换使用                       │
│  [首页][办理登记][宿舍管理][人员清单][费用标准][宿舍账单]                │
│  [员工账单][抄表记录][基础资料][系统设置]                                │
├──────────────────────────────────────────────────────────────────────┤
│ Tier 3  页面内容区 (page-content)                                          │
│   ┌──────────────────────────────────────────────────────────────┐  │
│   │  当前激活 Tab 对应的页面（iframe / fetch-html / Razor 渲染）  │  │
│   └──────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.1 三层职责

| 层 | 名称 | 职责 | 是否全局共享 |
|----|------|------|------------|
| Tier 1 | 顶部品牌栏 | 品牌标识 + 用户信息 + 退出 | ✅ 全局共享 |
| Tier 2 | Tab 页签栏 | 菜单项切换（10 个固定 Tab） | ✅ 全局共享 |
| Tier 3 | 页面内容区 | 当前 Tab 的实际业务内容 | ❌ 各页独立 |

### 2.2 v2.12.3 架构变更说明

> **v2.12.2 → v2.12.3**：移除原 Tier 2"紧凑型图标导航条"。

**变更原因**：
- 原四层架构中，Tier 2（图标导航条）与 Tier 3（Tab 栏）功能重复——两者都提供模块入口
- Tab 栏已包含完整的 10 个菜单项（含图标 + 文字），信息密度更高
- 移除图标导航条后，节省 56px 垂直空间，内容区可显示更多内容

**视觉对比**：

| 版本 | 顶部布局 |
|------|---------|
| v2.12.2（四层） | 品牌栏(48) + 图标导航(56) + Tab栏(45) + 内容 = 149px |
| **v2.12.3（三层）** | **品牌栏(48) + Tab栏(45) + 内容 = 93px（节省 56px）** |

### 2.3 渲染策略

> ⚠️ **强制**：所有 Admin Web 页面必须基于同一布局（`_Layout.cshtml` / `_LayoutTab.cshtml`），页头与 Tab 不允许在单页面内重复绘制。

| 技术栈 | 推荐方案 |
|--------|---------|
| Razor Pages | 使用 `_Layout.cshtml` 内嵌 Tab 容器 + `@RenderBody()` 切换内容 |
| HTML 原型 | `04-HTML原型/_shared/` 提供 `layout.html` + `mock-data.js#renderLayout()` |
| 原型 Web 部署 | 同步采用 iframe + URL 切换，确保离线可访问 |

### 6.1 切换方式

| 方案 | 适用 | 实现 |
|------|------|------|
| **iframe** | 简单原型 / 老旧项目 | 每个 Tab 内嵌 `<iframe src="...">` |

- 顶距：`0`（紧贴 Tab 栏底边框）
- 左右内边距：`1.25rem`
- 上下内边距：`1rem`
- 背景：`#f5f7fa`
- 最小高度：`calc(100vh - 48px - 56px - 40px)` ≈ `100vh - 144px`

## 8. 无障碍（A11Y）

| 维度 | 规范 |
|------|------|
| **键盘导航** | `Tab` 顺序：品牌 → 用户胶囊 → 退出 → 图标导航 → Tab 列表 → 内容区 |
| **快捷键** | `Ctrl + 1~9` 切换对应 Tab；`Ctrl + W` 关闭当前 Tab；`Ctrl + Shift + T` 重新打开关闭的 Tab |
| **ARIA** | 图标按钮 `aria-label="打开宿舍管理"`；Tab 容器 `role="tablist"`；单个 Tab `role="tab" aria-selected="true/false"` |
| **对比度** | 文字与背景 ≥ 4.5:1（WCAG AA） |
| **焦点环** | `outline: 2px solid rgba(25,118,210,0.6); outline-offset: 2px` |
