# 金戈宿舍管理系统 — 统一 UI 设计规范 v2.0

> **版本**：v2.0  
> **生效日期**：2026-07-11  
> **适用范围**：所有 HTML 原型页面 + Razor 视图  
> **目的**：统一所有页面 UI 风格、菜单样式、组件设计，确保原型与生产代码的一致性

---

## 1. 设计理念

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **专业商务风格** | 现代企业级后台系统，简洁大气，注重信息层次 |
| **统一视觉语言** | 所有页面使用同一套设计规范，风格一致 |
| **高效信息呈现** | 数据优先，减少视觉噪音，突出关键信息 |
| **响应式适配** | 支持桌面端和移动端自适应 |

### 1.2 色彩体系

#### 主色调

| 用途 | 色值 | 十六进制 | 使用场景 |
|------|------|---------|---------|
| 主色 | 深蓝 | `#1976d2` | 按钮、链接、激活状态 |

| 成功 | 绿色 | `#2e7d32` | 成功状态、正向指标 |

## 12. 分页器规范

### 12.1 分页器组件（统一标准）

所有列表页面必须使用 `mock-data.js` 中的 `registerList()` 函数实现统一分页：

```javascript
const list = registerList({
    key: 'uniqueKey',           // 页面唯一标识
    footId: 'pager',            // 分页器容器 ID
    totalId: 'totalCount',      // 总记录数容器 ID（可选）
    getData: getFiltered,       // 获取过滤后数据的函数
    renderRows: (items, total, start) => {
        // 渲染表格行的回调函数
        // items: 当前页数据
        // total: 总记录数
        // start: 当前页起始序号
    }
});

function render() { list.reset(); }  // 重置到第一页并刷新
```

### 12.2 分页器 HTML 结构

```html
<div class="card">
    <div class="table-responsive">
        <table class="table table-hover mb-0">
            <!-- ... -->
        </table>
    </div>
    <div class="card-footer" id="pager"></div>  <!-- 分页器容器 -->
</div>
```

### 12.3 分页器样式定义

```css
.pagination {
    margin: 0;
    gap: 0.25rem;
}
.pagination .page-link {
    color: #1976d2;
    border: 1px solid #dee2e6;
    border-radius: 6px;
    padding: 0.4rem 0.75rem;
    font-size: 0.85rem;
}
.pagination .page-item.active .page-link {
    background-color: #1976d2;
    border-color: #1976d2;
}
.pagination .page-link:hover {
    background-color: #f8f9fa;
    border-color: #1976d2;
}
```

### 12.4 分页器显示效果

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    «  1  2  3  …  20  »                   共 121 条 · 第 1-20 条 · 共 7 页    每页 [20▼] 条    │
│              ←──────────────── 屏幕行中间居中 ─────────────────→           ←───── 同行右侧固定 ─────→        │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 12.5 分页器布局规范

| 元素 | 布局 | 说明 |
|------|------|------|
| 左侧占位 | 固定 | 空白占位，保持左侧对称 |
| 页码导航 | 中间居中 | « 上一页 · 页码 · … · 末页 » |
| 统计信息 | 右侧 | 共 X 条 · 第 X-X 条 · 共 X 页 |
| 每页条数 | 右侧 | 下拉选择：10/20/50/100 |

### 12.6 智能页码规则

| 条件 | 显示 |
|------|------|
| 总页数 ≤ 10 | 全部显示 |
| 总页数 > 10 | 只显示当前页 ±2 范围内页码，两端省略号 |
| 首页 | 无 « 按钮或禁用 |
| 末页 | 无 » 按钮或禁用 |

### 12.7 页面初始化流程

```javascript
// 1. 定义 getFiltered 函数（根据筛选条件返回过滤后数据）
function getFiltered() {
    const dept = document.getElementById('department').value;
    return PERSONNEL.filter(p => {
        if (dept && p.department !== dept) return false;
        return true;
    });
}

// 2. 使用 registerList 注册分页器
const list = registerList({
    key: 'personnel',
    footId: 'pager',
    totalId: 'totalCount',
```

### 20.6 冲突检测清单（开发前必读）

在编写页面 JavaScript 之前，请先检查以下清单：

| 检查项 | 操作 |
|--------|------|
| 1. 变量名是否以模块前缀开头？ | 如 `BK_`, `EMP_`, `DORM_` |
| 2. 是否避免了 `STATUS_MAP`, `STATUS_BADGE`？ | 改用 `EMP_STATUS_TEXT` |
| 3. 是否避免了 `BOOKING_STATUSES`, `BOOKING_STATUS_BADGE`？ | 改用 `BK_STATUS_TEXT`, `BK_STATUS_CLASS` |
| 4. 函数名是否避免与 mock-data.js 冲突？ | 如 `renderNav()`, `registerList()` |
| 5. 页面初始化是否等待数据加载完成？ | 使用 `initPage()` 模式延迟执行 |

### 20.7 常见错误与修复

| 错误信息 | 原因 | 修复方法 |
|---------|------|---------|
| `Identifier 'STATUS_MAP' has already been declared` | 与 mock-data.js 中的 `STATUS_MAP` 冲突 | 改用 `EMP_STATUS_TEXT` |
| `Identifier 'BOOKING_STATUS_BADGE' has already been declared` | 与 mock-data.js 中的 `BOOKING_STATUS_BADGE` 冲突 | 改用 `BK_STATUS_CLASS` |
| `BOOKINGS is not defined` | mock-data.js 未加载完成就执行 | 使用 `initPage()` 模式延迟执行 |
| `Cannot read property 'filter' of undefined` | 数据变量未定义 | 同上 |
