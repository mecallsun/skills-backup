# 软件注册授权通用开发文档（v2.13.94）

> **本文档定位**：通用 / 可复用 — 不依赖本项目，可独立用于其他 .NET 8 / WinForms / Web 项目的软件注册授权功能实现。

---

## 一、背景与目标

### 1.1 业务诉求

企业内部开发的 B/S 架构业务系统（如宿舍管理 / ERP / HR 等），需要：

- **机器码（SN, Serial Number）**：绑定物理设备（CPU + Disk + OS），作为软件授权的唯一标识
- **注册码（CDKEY）**：客户购买时，由"注册机"工具根据 SN + 公司名 + 到期日生成
- **公司/单位名称（LTDName）**：授权给哪个客户使用（多租户隔离）
- **注册有效期（RegDate）**：注册码可使用的截止日期，过期则锁定
- **试用期（UseTimes）**：未注册时给 30 次免费试用，超期必须注册

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **跨平台** | 算法分两层：TrayApp 端 WMI（Windows）+ Web 端降级（Linux/macOS 兼容）；两者通过共享文件 `machine.dat` + 环境变量 `DORM_MACHINE_SN` 通信 |
| **离线校验** | 客户端无网也能校验（注册信息本地存储 + 算法本地运行） |
| **存储三层降级** | HKLM 注册表 → HKCU 注册表 → 文件，三层任一成功即可 |
| **UI 多端一致** | Web 端（Razor Pages）+ WinForms 端（托盘程序）共用同一 RegisterSdk |
| **可独立复用** | 4 个文件（RegItem + RegisterSdk + LicenseForm + 注册机 Program.cs）即可独立发布 |

### 1.3 与原 NPGS.Register 项目的关系

| 对比项 | 原 NPGS.Register（WinForms .NET 4.8） | 当前项目 v2.13.94（.NET 8） |
|--------|-------------------------------|-------------------------------|
| UI | WinForms RegisterForm.cs | Razor Pages Settings/Index + WinForms LicenseForm.cs（托盘） |
| SDK | Public.Core.SDK.dll（闭源） | 自实现 RegisterSdk.cs（开源、跨平台） |
| 机器码 | WMI CPU + Disk（v2.13.94 修正） | `Win32_Processor.ProcessorId` (16 hex) + `VolumeSerialNumber` (8 hex) = 24 字符 |
| 注册表 | HKLM | HKLM → HKCU → 文件 三层降级 |
| 注册机 | 独立 EXE | tools/LicenseGenerator/（同算法） |
| 算法核心 | MD5 + 固定密钥 | **MD5 + 固定密钥（保持一致）** |

> **关键决策**：算法的核心（MD5 + 固定密钥 + 验证段格式）保持与原项目兼容，未来可由同一"注册机"为新老项目生成注册码。

## 三、核心算法详解

### 3.1 机器码算法（SN）— v2.13.94 完全对齐原 NPGS.Register

**v2.13.94 算法修正**：通过反编译 Public.Core.SDK.dll（Dotfuscator 混淆）的方法签名清单：
```
GetCpu()                     → WMI Win32_Processor.ProcessorId
GetDiskVolumeSerialNumber()  → Win32 LogicalDisk VolumeSerialNumber
GetDriveSerialNum()          → 派生格式（备用）
GetLtdSerialNum(String)      → 公司名 → 序列号（注册机用）
```

**真实算法（v2.13.94 起）**：
```
cpuId       = WMI("SELECT ProcessorId FROM Win32_Processor")        → 16 字符大写 hex
volSerial   = WMI("SELECT VolumeSerialNumber FROM Win32_LogicalDisk WHERE DeviceID='C:'")
                                                                    → 8 字符大写 hex（long → X8 格式）
raw         = (cpuId + volSerial).ToUpper()                         → 24 字符大写 hex
display     = FormatCDKeyStyle(raw)                                 → "XXXXX-XXXXX-XXXXX-XXXXX-XXXX"（5-5-5-5-4 = 28 字符 display）
```

**真实示例**（本机实测）：
```
BFEBFBFF000A06A4AA2E3B0E        ← 24 字符纯 hex（实际存储 / 计算用）
BFEBF-BFF00-0A06A-4AA2E-3B0E    ← 28 字符 display（UI 展示用，5-5-5-5-4 分组）
```

**v2.13.94 之前的错误实现（已废弃）**：
```
raw = "{MachineName}|{ProcessorCount}|{OSVersion.VersionString}|JINGE-DORM"
hash = MD5(raw)              → 16 字节
sn = hex.Substring(0, 25)    → 取前 25 位（错误：用 25 位 + MD5 哈希，不是真实硬件特征）
```

**为什么 v2.13.94 之前的算法错误？**
- ❌ 用 MD5(MachineName + ProcessorCount + OSVersion) 是「软件指纹」而非「硬件指纹」
- ❌ 重装系统或更换机器名后机器码会变，导致已注册用户被迫重新注册
- ❌ ProcessorCount 在虚拟机 / 容器中可变

**v2.13.94 三层降级架构（Web + TrayApp）**：
```
┌─ TrayApp 端（Windows net8.0-windows）─────────────────────┐
│  启动时 MachineCodeProvider.Initialize()                    │
│  ├─ WMI Win32_Processor.ProcessorId → 真实 16 hex          │
│  ├─ WMI Win32_LogicalDisk.VolumeSerialNumber → 真实 8 hex  │
│  ├─ RegisterSdk.WriteMachineSN(raw) → 写 machine.dat + ENV │
│  └─ 返回 28 字符 display SN                                  │
└─────────────────────────────────────────────────────────────┘
                              ↓ machine.dat + DORM_MACHINE_SN
┌─ Web Admin/Api 端（跨平台 .NET 8，无 WMI）─────────────────┐
│  RegisterSdk.GetSN() 三层降级：                              │
│  1) Environment.GetEnvironmentVariable("DORM_MACHINE_SN")   │
│  2) File.ReadAllText(machine.dat)                           │
│  3) Fallback：MD5(MachineName + ProcessorCount + OSVersion) │
│     取前 24 hex（精度低但位数一致）                          │
└─────────────────────────────────────────────────────────────┘
```

**为什么这样设计？**
- ✅ **真实性**：CPUID + VolumeSerialNumber 是硬件指纹，重装系统不变
- ✅ **跨平台**：Web 端无 WMI 也能工作（通过共享文件 / 环境变量通信）
- ✅ **可降级**：TrayApp 未运行时 Web 端仍有可用 SN（fallback 模式）
- ✅ **可扩展**：未来改用更精确硬件特征（如 SMBIOS UUID）只需替换 TrayApp 端实现

**关键代码位置**：
- SDK 核心：`DormManage.Shared/Register/RegisterSdk.cs::GetSN/WriteMachineSN/ComputeFallbackSN`
- TrayApp WMI：`DormManage.TrayApp/MachineCodeProvider.cs::GetCpuId/GetDiskVolumeSerialNumber`
- 启动调用：`DormManage.TrayApp/Program.cs::Main`（启动时 `MachineCodeProvider.Initialize()`）

### 3.2 注册码算法（CDKEY）

**CDKEY 结构**（共 29 位 = 5-5-5-5-5）：
```
┌─────────────── 20 位验证段 ───────────────┐┌── 5 位日期段 ──┐
│                                            ││                 │
MD5(SN|LTDName|SECRET_KEY) 的前 20 位 hex    ││ HEX(YYYY-MM-DD) │
│                                            ││                 │
└────────────────────────────────────────────┘└─────────────────┘
```

**日期段编码**（5 位 hex）：
```
YYYY-MM-DD → YYYY(2位hex) + (M-1)(1位hex) + DD(2位hex)
例：2027-12-31 → 1B + B + 1F → "1BB1F"（5 位）
```

**SECRET_KEY**（注册机与 SDK 共享的固定密钥）：
```csharp
private const string SECRET_KEY = "JINGE-DORM-MANAGE-2026-LICENSE";
```

> ⚠️ **生产环境必须替换为公司专属密钥**（增加逆向破解难度）。

**校验流程**（CheckRegCDKey）：
```csharp
1. cdkeyRaw = CDKEY.Replace("-","").ToUpperInvariant()   // 去掉分隔符
   if (cdkeyRaw.Length != 25) return RegInt=0;

2. dateStr = cdkeyRaw.Substring(20, 5)                    // 后 5 位日期段
   verifyStr = cdkeyRaw.Substring(0, 20)                  // 前 20 位验证段

3. expected = MD5(SN|LTDName|SECRET_KEY).Substring(0,20)  // 重算验证段
   if (verifyStr != expected) return RegInt=0;

4. 解码 dateStr → DateTime
   year  = 2000 + hex2int(dateStr[0:2])
   month = hex2int(dateStr[2:3]) + 1
   day   = hex2int(dateStr[3:5])
   regDate = new DateTime(year, month, day)

5. if (regDate < today) return RegInt=0; else return RegInt=1;
```

### 3.3 持久化策略

**三层降级**：
```
HKLM\Software\JINGE\DormManage\License\
    ├── CDKEY   = "XXXXX-XXXXX-XXXXX-XXXXX-XXXXX"
    ├── LTDName = "公司名称"
    ├── RegDate = "2027-12-31"
    ├── SN      = "XXXXX-XXXXX-XXXXX-XXXXX-XXXXX"
    └── UseTimes = 5
    ↓ (无权限) 回退
HKCU\Software\JINGE\DormManage\License\
    ├── (同上)
    ↓ (无权限) 回退
%ProgramData%\JINGE\DormManage\license.dat
    CDKEY=...
    LTDName=...
    RegDate=...
    SN=...
    UseTimes=5
```

**读取逻辑**（按 HKLM → HKCU → 文件 顺序，找到第一个非空值即返回）。

## 四、SDK 接口设计

### 4.1 RegItem DTO

```csharp
public class RegItem
{
    public string SN { get; set; } = "";            // 机器码
    public string CDKEY { get; set; } = "";          // 注册码
    public string LTDName { get; set; } = "";        // 公司名称
    public int RegInt { get; set; } = -1;            // -1=未注册 0=已过期 1=已注册
    public DateTime? RegDate { get; set; }           // 到期日
    public int UseTimes { get; set; }                // 试用次数
}
```

### 4.2 RegisterSdk 静态类

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `string GetSN()` | 25 位 hex | 生成机器码（基于机器特征） |
| `RegItem CheckReg()` | RegItem | 综合读取本地存储，返回当前状态 |
| `RegItem CheckRegCDKey(RegItem input)` | RegItem | 校验给定 CDKEY 是否有效 |
| `DateTime GetDateByRegCDKey(string cdkey)` | DateTime | 从 CDKEY 解码到期日 |
| `bool WriteRegItem(RegItem reg)` | bool | 写入注册信息（三层降级） |
| `bool DeleteRegItem()` | bool | 删除注册信息（保留 UseTimes） |
| `void DeleteRegAll()` | void | 清除所有注册信息（含 UseTimes） |
| `int IncrementUseTimes()` | int | 试用次数 +1 并返回新值 |

### 4.3 使用示例

```csharp
// 启动时检测
var reg = RegisterSdk.CheckReg();
switch (reg.RegInt)
{
    case 1:
        Console.WriteLine($"已注册，到期 {reg.RegDate:yyyy-MM-dd}");
        break;
    case 0:
        Console.WriteLine($"注册已过期（{reg.RegDate:yyyy-MM-dd}），请重新注册");
        break;
    default:
        var times = RegisterSdk.IncrementUseTimes();
        if (times > RegisterSdk.TRIAL_LIMIT)
        {
            Console.WriteLine($"试用 {times}/{RegisterSdk.TRIAL_LIMIT} 次，请注册！");
            Environment.Exit(1);  // 拦截
        }
        break;
}

// 用户提交注册
var check = RegisterSdk.CheckRegCDKey(new RegItem {
    CDKEY = "ABCDE-FGHIJ-KLMNO-PQRST-UVWXY",
    SN = reg.SN,
    LTDName = "客户公司名"
});
if (check.RegInt == 1 && check.RegDate > DateTime.Today)
{
    RegisterSdk.WriteRegItem(new RegItem {
        SN = reg.SN,
        CDKEY = check.CDKEY,
        LTDName = "客户公司名",
        RegDate = check.RegDate,
        RegInt = 1
    });
}
```

### 5.1 命令行用法


### 5.2 输出

```
===== v2.13.94 注册码生成 =====
SN:        ABCDE-FGHIJ-KLMNO-PQRST-UVWXY
公司名称:   金戈电子有限公司
到期日期:   2027-12-31
注册码:     1A2B3-C4D5E-6F7A8-9B0C1-D2E3F  (举例)
```

### 5.3 算法（必须与 RegisterSdk 一致）

```csharp
// 1) 计算验证段
var verifyRaw = $"{sn}|{ltdName.ToUpperInvariant()}|{SECRET_KEY}";
var hash = MD5(verifyRaw);
var verifyStr = hash.hex.Substring(0, 20);

// 2) 计算日期段
var yearHex  = (year - 2000).ToString("X2");
var monthHex = (month - 1).ToString("X1");
var dayHex   = day.ToString("X2");
var dateStr  = yearHex + monthHex + dayHex;

// 3) 拼接 CDKEY
var raw25 = verifyStr + dateStr;  // 25 位
var cdkey = format(5-5-5-5-5);   // 29 位
```

## 七、安全性考量

### 7.1 防护层级

| 层级 | 防护 | 说明 |
|------|------|------|
| L1 | SECRET_KEY 隐藏 | 算法核心密钥在 SDK 内嵌，逆向需破解 .NET 程序集 |
| L2 | SN 设备绑定 | 同一 CDKEY 不能在其他机器使用 |
| L3 | 公司名绑定 | 同一 CDKEY 不能给其他公司使用 |
| L4 | 日期编码混淆 | YYYY → hex(YYYY-2000)，增加人眼识别难度 |
| L5 | 验证段不可逆 | CDKEY 前 20 位 = MD5，无法逆推出 SN + LTDName |

### 7.2 已知局限性

- ❌ **无网络校验**：客户端离线校验，攻击者可修改本地时间绕过到期校验
- ❌ **无硬件绑定校验**：客户端时钟可改（但不建议走网络校验的复杂度）
- ❌ **SECRET_KEY 在 SDK 内可见**：.NET 反射可读取 const 字符串；高安全场景请用 DPAPI / 服务器签发

### 7.3 推荐增强（未来版本）

- 🔒 服务器签发 CDKEY（CDKEY 内含 RSA 签名，客户端 SDK 公钥验签）
- 🔒 定期心跳上报（每 N 天连服务器确认授权）
- 🔒 硬件指纹升级（CPU + Disk + BIOS UUID + MAC 多特征）

## 八、复用性迁移指南

### 8.1 最小迁移包（4 个文件）

要把这个注册授权功能集成到**另一个项目**，只需复制：

| 文件 | 来源 | 大小 |
|------|------|------|
| `RegItem.cs` | `DormManage.Shared/Register/RegItem.cs` | ~30 行 |
| `RegisterSdk.cs` | `DormManage.Shared/Register/RegisterSdk.cs` | ~200 行 |
| `LicenseForm.cs` | `DormManage.TrayApp/Forms/LicenseForm.cs`（如需 WinForms） | ~250 行 |
| `LicenseGenerator/` | `tools/LicenseGenerator/`（注册机工具） | ~80 行 |

### 8.2 迁移步骤

1. **复制 4 文件** 到新项目 `Register/` 目录
2. **修改 SECRET_KEY** 为新项目专属密钥（必须同步修改 SDK + 注册机两端）
3. **UI 集成**：
   - Web 项目：在「设置 / 关于」页面加注册表单 + handler（参考 Settings/Index.cshtml 模式）
   - WinForms 项目：在托盘菜单加「软件注册授权」入口 + LicenseForm.cs
4. **首次启动校验**：在 Main / Startup 调用 `RegisterSdk.IncrementUseTimes()` + `CheckReg()`，超 30 次拦截
5. **生成 CDKEY**：用 LicenseGenerator.exe 给客户生成注册码

### 8.3 命名空间调整

原项目命名空间：`DormManage.Shared.Register` / `DormManage.TrayApp.Forms`
迁移到新项目时建议改为：`<新项目>.Register` / `<新项目>.Forms`
