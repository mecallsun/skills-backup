## 1. 变更背景

原宿舍详情页面的"查看住宿历史"功能通过链接跳转到独立页面 `history.html`，用户体验不连贯。本次优化改为**开关式交互**：

1. **按钮文字切换**："查看住宿历史" ↔ "关闭历史"
2. **内联显示**：历史记录直接在当前页面列表下方展开
3. **无需跳转**：保持当前页面上下文，提升操作效率

### 2.4 数据筛选

- **数据源**：`dormHistory(code)`（来自 mock-data.js）
- **筛选条件**：`status !== 1`（排除当前在宿）
- **排序**：按入住日期倒序（由 dormHistory 函数处理）

### 2.5 数据关联

- 使用 `findEmployee(r.employeeId)` 获取员工详细信息
- 显示字段：姓名、工号、部门、入职日期
- 计算字段：住宿天数 = 当前日期 - 入住日期（或退宿日期 - 入住日期）

### 2.6 "员工类型"显示（v2.11.6 — 与 30 文档 §3.2.1 保持一致）

**强制规则**：历史记录区域**如显示**"员工类型"字段，其值必须按 **FK 关联引用**方式获取（数据源 = `SysEmployee.EmployeeTypeId` → `EmployeeType.Name`），不得使用任何冗余、缓存或硬编码数据。

详细规则参照 `30-宿舍详情页面调整-v2.11.4.md` §3.2.1。包括：

| # | 要求 | 说明 |
|---|------|------|
| 1 | 数据源唯一 | 仅从 `SysEmployee.EmployeeTypeId` → `EmployeeType` 取值 |
| 2 | 实时联动 | 当人员档案"员工类型"变更后，历史记录实时显示最新值 |
| 3 | 不冗余存储 | 不在 BOOKINGS/HISTORY 任何表中冗余"员工类型"字段 |
| 4 | 字典缺失处理 | 找不到 `EmployeeType` 显示 `-`（不显示原始 ID） |

> 💡 **当前实现说明**：本节原型历史时间线（`dorms/details.html` 中 `renderHistory()` 函数）当前**不展示**"员工类型"字段，仅展示姓名、工号、部门、状态、原因、日期。如下游需要展示"员工类型"，应严格按 30 §3.2.1 关联引用规则实现。

### 3.3 JavaScript 实现

```javascript
let historyVisible = false;

function toggleHistory() {
    historyVisible = !historyVisible;
    const section = document.getElementById('historySection');
    const btn = document.getElementById('btnToggleHistory');

    if (historyVisible) {
        section.style.display = 'block';
        btn.innerHTML = '<i class="bi bi-x-circle"></i> 关闭历史';
        btn.classList.remove('btn-outline-secondary');
        btn.classList.add('btn-secondary');
        renderHistory();
    } else {
        section.style.display = 'none';
        btn.innerHTML = '<i class="bi bi-clock-history"></i> 查看住宿历史';
        btn.classList.remove('btn-secondary');
        btn.classList.add('btn-outline-secondary');
    }
}

function renderHistory() {
    // 使用 dormHistory 函数获取该宿舍所有历史记录
    const history = dormHistory(code).filter(r => r.status !== 1);
    document.getElementById('historyCount').textContent = history.length;
    const timeline = document.getElementById('historyTimeline');

    if (history.length === 0) {
        timeline.innerHTML = '<div class="text-muted text-center py-4">暂无历史记录</div>';
        return;
    }

    timeline.innerHTML = history.map(r => {
        const emp = findEmployee(r.employeeId);
        const isActive = r.status === 1;
        const stayDays = r.leaveDate
            ? Math.floor((new Date(r.leaveDate) - new Date(r.checkInDate)) / (1000*60*60*24))
            : Math.floor((new Date() - new Date(r.checkInDate)) / (1000*60*60*24));

        return `
        <div class="timeline-item ${isActive ? '' : 'left'}">
            <div class="d-flex justify-content-between">
                <div>
                    <strong>${emp?.realName || '-'}</strong>
                    <small class="text-muted ms-2">${emp?.employeeCode || '-'} | ${emp?.department || '-'}</small>
                    ${isActive ? '<span class="badge bg-success ms-2">在宿</span>' : '<span class="badge bg-secondary ms-2">已退宿</span>'}
                </div>
                <small class="text-muted">${r.reason || ''}</small>
            </div>
            <div class="mt-1 text-muted small">
                <i class="bi bi-box-arrow-in-right"></i> 入住：${formatDate(r.checkInDate)}
                ${r.leaveDate ? '<i class="bi bi-box-arrow-right ms-3"></i> 退宿：' + formatDate(r.leaveDate) : '<i class="bi bi-hourglass-split ms-3"></i> 至今'}
                <i class="bi bi-clock ms-3"></i> 共 ${stayDays} 天
            </div>
        </div>`;
    }).join('');
}
```
