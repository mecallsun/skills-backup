## Context

### 用户报告

> 历史中已定义所有筛选区的筛选条件为"房号"输入框（当前占位较大导致超出屏幕）的最大宽度为该字段值的最长字符宽度+下拉列表按钮宽度；请深度理解与历史定义规则结合，全面梳理相关需求，处理筛选条件区域的字段占位过大导致超出屏幕的规则 UI 界面处理规范。

### 诊断

| 字段 | 类型 | 实际最长值 | 字符数 | 当前宽度 | 应该宽度 |
|------|------|----------|--------|----------|----------|
| 房号 (DormCode) | combobox | D-007 | 7 | ~166px | 110px |
| 日期 (date) | date | yyyy-MM-dd | 10 | 120px+ | 144px |
| 月份 (month) | month | yyyy-MM | 7 | 120px+ | 130px |
| 状态 (status) | select | 启用/停用 | 2-3 | 120px | 100px |
| 姓名/工号 | text | EMP-99999 | 9 | 120px | 120-180px |

**根因**：v2.13.175 文档定义的 `filter-item-dorm` 等字段宽度 CSS 类在 git 操作中丢失。通用 `.filter-item { min-width: 120px }` 应用于所有字段，导致：
- 房号 7 字符却占 166px（浪费 56px）
- 日期 10 字符只占 120px（不够）
- 月份、状态也有类似问题

## 历史定义（v2.13.175 规范）

来源：`00-方案文档/35-列表页面统一UI设计规范-v2.13.154.md` §3.5.1 字段宽度规范

### 核心公式

```
字段宽度 = 字符数 × 8.5px（中文字体宽度） + 26px（padding） + datalist 触发 20px（仅 combobox）
```

### 核心原则

| 原则 | 说明 |
|------|------|
| **自适应** | 字段宽度按**条件值最长长度**自动缩放 |
| **禁止固定** | ❌ 禁止 `style="width:200px"` 等内联硬编码 |
| **禁止 col-md** | ❌ 禁止 `col-md-2/3/4` 等 Bootstrap 固定列宽 |
| **不超屏** | 超出屏幕宽度时**横向滚动**（`overflow-x: auto`） |
| **单行排列** | 全部筛选项+按钮强制**单行排列**（`flex-nowrap`） |

### 1. 字段宽度速查表

| 字段类型 | 字符数 | 应有 min-width | 应有 max-width | flex |

| **房号 (DormCode)** | 7（D-007） | 96px | 130px | 0 0 110px |
| **姓名/工号** | 2-9 | 120px | 200px | 0 1 auto |
| **部门** | 3-4 | 120px | 160px | 0 1 auto |
| **员工类型** | 3 | 100px | 160px | 0 1 auto |
| **班组** | 2-3 | 108px | 120px | 0 0 auto |
| **日期 (date)** | 10 | 130px | 160px | 0 0 144px |
| **月份 (month)** | 7 | 120px | 150px | 0 0 130px |
| **状态 (status)** | 2-3 | 90px | 130px | 0 0 100px |
| **数字 (number)** | 1-5 | 90px | 140px | 0 0 100px |
| **统计** | 1-4 | 90px | 140px | 0 1 auto |

### 2. CSS 类命名规范

| 字段类型 | CSS 类 |
|---------|--------|
| 房号 | `filter-item-dorm` |
| 姓名/工号 | `filter-item-name` |
| 日期 | `filter-item-date` |
| 月份 | `filter-item-month` |
| 状态 | `filter-item-status` |

| 班组 | `filter-item-team` |

## 永久教训

1. **字段宽度不要固定为通用 120px**：每个字段按实际最长值 + 控件装饰（padding/datalist/箭头/图标）计算
2. **CSS 类命名按字段类型而非位置**：`.filter-item-dorm` 比 `.filter-item-first-column` 语义清晰
3. **公式统一便于推广**：`字符数 × 8.5 + 26 + 20` 适用于所有中文字体
4. **历史规范可能因 git 操作丢失**：v2.13.175 的 `filter-item-dorm` 丢失 → 必须定期回查规范文档

## 永久规则

| 规则 | 强制检查 |
|------|----------|
| 新增字段必须指定 class | `filter-item-{type}` |
| 字段宽度按公式计算 | 字符数 × 8.5 + 26 + 20 |
| 禁止固定像素宽度 | ❌ 禁止 `style="width:200px"` |
| 禁止 col-md-* | ❌ 禁止 Bootstrap 固定列宽 |
| 单一来源真理 | 字段宽度定义在 `_Layout.cshtml` |
