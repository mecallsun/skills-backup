### 2.2 OPT-4 筛选条件持久化（localStorage）

新增 **全局模块** `DormManage.Admin/wwwroot/js/filter-persistence.js`，提供 `FilterPersistence` 命名空间：

| API | 用途 |
|-----|------|
| `FilterPersistence.save(module, data)` | 保存筛选到 localStorage |
| `FilterPersistence.load(module)` | 从 localStorage 加载 |
| `FilterPersistence.reset(module)` | 清除指定模块 + 刷新页面 |
| `FilterPersistence.resetAll()` | 清除所有 jinge.filter.* 缓存 |
| `FilterPersistence.applyToForm(form, data)` | 把数据回填到表单 |
| `FilterPersistence.collectFromForm(form)` | 从表单收集当前值 |

**应用范围**（6 大列表模块 + 全局加载）：
- `Personnel/Index.cshtml`：`data-filter-form="personnel"`
- `Dorms/Index.cshtml`：`data-filter-form="dorms"`
- `Booking/Index.cshtml`：`data-filter-form="booking"`
- `Meter/Index.cshtml`：`data-filter-form="meter"`
- `DormBilling/Index.cshtml`：`data-filter-form="dormBilling"`
- `EmployeeBilling/Index.cshtml`：`data-filter-form="employeeBilling"`
- 所有页面 `<script src="~/js/filter-persistence.js"></script>` 由 `_Layout.cshtml` 全局注入

**UI 体现**：每个列表页筛选区增加红色"清除"按钮（图标 `bi-trash`），点击即清空 localStorage 中该模块的筛选缓存。
