# 需求规格说明书 — v2.11.3 增补 (q)：抄表状态筛选简化

> **范围**：抄表记录（meter/*）状态筛选选项调整
> **日期**：2026-07-11
> **关联需求**：`08-抄表记录需求-v2.11.md`、`22-抄表状态强化-v2.11.2.md`、`23-抄表记录全面强化-v2.11.3.md`
> **对应原型**：`04-HTML原型/meter/index.html`

---

## 1. 变更背景

v2.11.3 的状态筛选包含 5 个独立选项（全部/未抄表/未完成/正常/已修正/已作废），其中"未抄表"和"未完成"在实际业务中存在重叠：

- **未抄表 (status=0)**：三表全为 0，完全未抄表
- **未完成 (status=4)**：部分表项有值，部分为 0

为简化筛选逻辑，将"未抄表"合并到"未完成"选项中。

---

## 2. 详细变更

### 2.1 状态定义（最终版）

| Status | 含义 | Badge 颜色 | 说明 |
|--------|------|-------------|------|
| 0 | 未抄表 | 灰 `bg-light border` | 三表全为 0，完全未抄表 |
| 1 | 正常 | 绿 `bg-success` | 三表完整且读数正常 |
| 2 | 已修正 | 黄 `bg-warning` | 已修正过 |
| 3 | 已作废 | 深灰 `bg-secondary` | 已作废，不参与计费 |
| 4 | 未完成 | 蓝 `bg-info` | 部分表项有值，部分为 0 |

### 2.2 筛选选项变更

**修改前（v2.11.3）**：

```html
<select id="status" class="form-select">
    <option value="">全部（含所有状态）</option>
    <option value="0">未抄表</option>           ← 删除此选项
    <option value="4">未完成</option>
    <option value="1">正常</option>
    <option value="2">已修正</option>
    <option value="3">已作废</option>
</select>
```

**修改后（v2.11.3 增补 q）**：

```html
<select id="status" class="form-select">
    <option value="">全部（含所有状态）</option>
    <option value="4">未完成（部分/未抄）</option>  ← 更新描述
    <option value="1">正常</option>
    <option value="2">已修正</option>
    <option value="3">已作废</option>
</select>
```

### 2.3 筛选逻辑变更

**修改前**：

```javascript
// 每个状态单独筛选
if (st && m.status != st) return false;
```

**修改后**：

```javascript
// "未完成"选项同时包含 status=0 和 status=4
if (st && st !== '') {
    if (st === '4') {
        // 包含 未抄表(0) 和 部分未完成(4)
        if (m.status !== 0 && m.status !== 4) return false;
    } else if (m.status != st) return false;
}
```

### 2.4 覆盖进度显示

覆盖进度中的"未抄表"和"未完成"仍分开统计：

```javascript
// 覆盖进度统计（不变）
const read = 已抄(1/2) 计数;
const unfinished = 未完成(4) 计数;
const unread = 未抄表(0) 计数;
```

但筛选下拉中合并为"未完成（部分/未抄）"一个选项。
