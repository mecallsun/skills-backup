## 1. 问题描述

### 1.1 现状问题

原文档设计中存在以下不一致：

| 问题 | 现状描述 | 问题说明 |
|------|---------|---------|
| **存储值不一致** | SysEmployee.Department 存储 NVARCHAR(50) 部门名称 | 应该存储 DepartmentId (INT) 外键 |
| **存储值不一致** | SysEmployee.EmployeeType 存储 NVARCHAR(20) 类型名称 | 应该存储 EmployeeTypeId (INT) 外键 |
| **关联逻辑缺失** | mock-data.js 使用名称数组 | 业务表应存储 ID，渲染时通过 ID→名称映射 |
| **文档描述混乱** | 33-基础资料模块.md 中使用"编码" | 业务表存储应使用 **主键ID**，而非编码 |

### 1.2 修正原则

```
┌─────────────────────────────────────────────────────────────┐
│                    正确的数据关联关系                          │
├─────────────────────────────────────────────────────────────┤
│  业务表（如 Employee）                                       │
│    ├── DepartmentId (INT) → FK → Department.Id            │
│    ├── EmployeeTypeId (INT) → FK → EmployeeType.Id         │
│    ├── AttendanceTypeId (INT) → FK → AttendanceType.Id     │
│    └── EmploymentStatusId (INT) → FK → EmploymentStatus.Id │
│                                                             │
│  页面展示：                                                  │
│    - 存储的是 ID（外键）                                    │
│    - 显示的是 Name（通过 JOIN 或内存映射）                   │
└─────────────────────────────────────────────────────────────┘
```

## 4. 前端页面交互逻辑

### 4.1 下拉选项渲染

```javascript
// 从字典接口加载下拉选项
async function loadDictionaries() {
    const resp = await fetch('/api/dictionaries');
    const result = await resp.json();
    
    if (result.success) {
        const data = result.data;
        
        // 渲染部门下拉
        let deptHtml = '<option value="">全部</option>';
        data.departments.forEach(d => {
            deptHtml += `<option value="${d.id}">${d.name}</option>`;
        });
        document.getElementById('filterDepartment').innerHTML = deptHtml;
        
        // 渲染员工类型下拉
        let typeHtml = '<option value="">全部</option>';
        data.employeeTypes.forEach(t => {
            typeHtml += `<option value="${t.id}">${t.name}</option>`;
        });
        document.getElementById('filterEmployeeType').innerHTML = typeHtml;
    }
}
```

## 6. 关联查询示例（EF Core）

### 6.1 获取人员列表（带基础资料名称）

```csharp
public async Task<PagedResult<PersonnelDto>> GetPersonnelListAsync(PersonnelQueryDto query)
{
    var queryable = _db.SysEmployees
        .Include(e => e.Department)      // ✅ 导航属性
        .Include(e => e.EmployeeType)
        .Include(e => e.AttendanceType)
        .Include(e => e.EmploymentStatus)
        .AsQueryable();

    // 筛选条件（使用 ID）
    if (query.DepartmentId.HasValue)
        queryable = queryable.Where(e => e.DepartmentId == query.DepartmentId.Value);

    if (query.EmployeeTypeId.HasValue)
        queryable = queryable.Where(e => e.EmployeeTypeId == query.EmployeeTypeId.Value);

    if (query.EmploymentStatusId.HasValue)
        queryable = queryable.Where(e => e.EmploymentStatusId == query.EmploymentStatusId.Value);

    // 映射到 DTO（返回 ID + Name）
    var result = await queryable
        .OrderByDescending(e => e.HireDate)
        .Skip((query.Page - 1) * query.PageSize)
        .Take(query.PageSize)
        .Select(e => new PersonnelDto
        {
            Id = e.Id,
            EmployeeCode = e.EmployeeCode,
            RealName = e.RealName,
            DepartmentId = e.DepartmentId,
            DepartmentName = e.Department.Name,           // ✅ 关联查询名称
            EmployeeTypeId = e.EmployeeTypeId,
            EmployeeTypeName = e.EmployeeType.Name,        // ✅ 关联查询名称
            AttendanceTypeId = e.AttendanceTypeId,
            AttendanceTypeName = e.AttendanceType.Name,    // ✅ 关联查询名称
            EmploymentStatusId = e.EmploymentStatusId,
            EmploymentStatusName = e.EmploymentStatus.Name, // ✅ 关联查询名称
            Phone = e.Phone,
            HireDate = e.HireDate,
            DormCode = e.DormCode
        })
        .ToListAsync();

    var total = await queryable.CountAsync();

    return new PagedResult<PersonnelDto>
    {
        Items = result,
        TotalCount = total,
        PageIndex = query.Page,
        PageSize = query.PageSize
    };
}
```
