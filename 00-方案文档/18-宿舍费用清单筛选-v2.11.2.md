# 需求规格说明书 — v2.11.2 增补 (i)：宿舍费用清单增加 3 个筛选条件

> **范围**：宿舍费用清单（billing/dorm-bills.html）筛选区
> **日期**：2026-07-11
> **对应原型**：`04-HTML原型/billing/dorm-bills.html`

---

## 1. 变更背景

原宿舍费用清单筛选区仅有"**计费月份**"一个筛选条件，无法按房号、楼栋、楼层定位特定范围的账单。在大量数据（190 间启用宿舍 × 12 月 = 2280 条/年）场景下，缺少维度筛选导致查找效率低。

本次新增 3 个筛选条件：**房号**、**楼栋**、**楼层**，与原有"计费月份"组合形成 4 维度筛选。

---

## 2. 字段定义

| 字段 | 类型 | 数据源 | 取值 | 备注 |
|------|------|--------|------|------|
| 计费月份 | month input | DORM_BILLS.billingMonth | YYYY-MM | **原有** |
| 房号 | text + datalist | DORMS.dormCode | D-001 ~ D-200 | **新增**，200 项自动补全 |
| 楼栋 | select | DORMS.building | 1号楼 / 2号楼 / 3号楼 / 4号楼 / 5号楼 | **新增**，5 个选项 |
| 楼层 | select | DORMS.floor | 1 ~ 6 楼 | **新增**，6 个选项 |

### 3.3 字段实现方式

#### 房号

- **类型**：`<input list="dormList">` + `<datalist>` 自动补全
- **理由**：200 个 dormCode 用 select 太长，datalist 提供搜索式自动补全
- **匹配规则**：`b.dormCode.toLowerCase().includes(kw.toLowerCase())`（子串匹配）

```html
<input list="dormList" id="dormCodeKw" class="form-control form-control-sm" placeholder="如 D-001">
<datalist id="dormList">
    <option value="D-001">
    <option value="D-002">
    ...
</datalist>
```

#### 楼栋

- **类型**：`<select>` 下拉
- **选项**：从 `BUILDINGS` 字典动态填充（5 个）
- **匹配规则**：`b.building === selectedValue`（精确匹配）

```html
<select id="building">
    <option value="">全部</option>
    <option value="1号楼">1号楼</option>
    <option value="2号楼">2号楼</option>
    <option value="3号楼">3号楼</option>
    <option value="4号楼">4号楼</option>
    <option value="5号楼">5号楼</option>
</select>
```

#### 楼层

- **类型**：`<select>` 下拉
- **选项**：从 `DORMS` 提取唯一 floor 值（1~6）
- **匹配规则**：通过 dormCode 关联 DORMS 获取 floor，再精确匹配

```html
<select id="floor">
    <option value="">全部</option>
    <option value="1">1 楼</option>
    <option value="2">2 楼</option>
    <option value="3">3 楼</option>
    <option value="4">4 楼</option>
    <option value="5">5 楼</option>
    <option value="6">6 楼</option>
</select>
```

### 3.5 关联查询实现

`DORM_BILLS_202607` 表无 floor 字段，需要通过 dormCode 关联 `DORMS` 表获取：

```javascript
function getFloor(dormCode) {
    const dorm = DORMS.find(d => d.dormCode === dormCode);
    return dorm ? dorm.floor : null;
}
```

或直接使用 mock-data.js 中的 `findDorm()` 辅助函数：

```javascript
const dorm = findDorm(b.dormCode);
const floorText = dorm ? `${dorm.floor}楼` : '-';
```

## 4. 筛选逻辑

### 4.1 currentData() 实现

```javascript
function currentData() {
    const month = document.getElementById('billingMonth').value;
    const dormKw = document.getElementById('dormCodeKw').value.trim();
    const building = document.getElementById('building').value;
    const floor = document.getElementById('floor').value;
    return DORM_BILLS_202607
        .filter(b => b.billingMonth === month)
        .filter(b => !dormKw || b.dormCode.toLowerCase().includes(dormKw.toLowerCase()))
        .filter(b => !building || b.building === building)
        .filter(b => {
            if (!floor) return true;
            const dorm = findDorm(b.dormCode);
            return dorm && String(dorm.floor) === String(floor);
        });
}
```

### 4.2 筛选组合示例

| 条件 | 结果 |
|------|------|
| 月份=2026-07 + 楼栋=3号楼 | 36 间宿舍的账单 |
| 月份=2026-07 + 楼层=3 | 全部楼栋的 3 楼宿舍账单 |
| 月份=2026-07 + 房号=D-001 | 1 间宿舍的账单 |
| 月份=2026-07 + 房号=D + 楼栋=2号楼 | 2 号楼所有 D 开头的宿舍 |

## 5. 后端 SQL 实现（参考）

```sql
-- 关联 Dorms 表查询 floor
SELECT
    b.Id, b.DormCode, b.Building,
    d.Floor,
    b.ColdUsage, b.HotUsage, b.ElectricityUsage,
    b.ColdAmount, b.HotAmount, b.ElectricityAmount, b.TotalAmount
FROM DormBilling b
LEFT JOIN Dorm d ON b.DormCode = d.DormCode
WHERE b.BillingMonth = @Month
  AND (@DormCode IS NULL OR b.DormCode LIKE '%' + @DormCode + '%')
  AND (@Building IS NULL OR b.Building = @Building)
  AND (@Floor IS NULL OR d.Floor = @Floor)
ORDER BY b.DormCode;
```

**性能**：
- 现有索引 `DormBilling(BillingMonth)` 已能高效筛选月份
- 建议新增 `DormBilling(DormCode)` 索引支持房号筛选
- Dorms 表数据量小（200 行），关联查询开销可忽略
