### 2.2 4 态 Badge 渲染函数（`expiresAtBadgeHtml`）

```js
function expiresAtBadgeHtml(expiresAt) {
    if (!expiresAt) {
        return '<span class="badge bg-light text-dark border" title="NULL = 永久有效"><i class="bi bi-infinity"></i> 永久</span>';
    }
    const today = new Date(); today.setHours(0,0,0,0);
    const exp = new Date(expiresAt); exp.setHours(0,0,0,0);
    const days = Math.round((exp - today) / 86400000);
    const dateText = exp.toISOString().slice(0, 10);
    if (days < 0) {
        return `<span class="badge bg-danger" title="已过期 ${-days} 天">${dateText}</span>`;
    } else if (days <= 30) {
        return `<span class="badge bg-warning text-dark" title="剩 ${days} 天过期">${dateText}</span>`;
    } else {
        return `<span title="${days} 天后到期">${dateText}</span>`;
    }
}
```

| 状态 | 触发条件 | Badge |
|------|---------|-------|
| **永久** | `expiresAt IS NULL` | `bg-light text-dark border` + 无限符号 ∞ |
| **正常** | `days > 30` | 普通文本 + tooltip「X 天后到期」|
| **即将过期** | `0 ≤ days ≤ 30` | `bg-warning text-dark` + tooltip「剩 X 天过期」|
| **已过期** | `days < 0` | `bg-danger` + tooltip「已过期 X 天」|

## 四、关键决策

| 决策 | 理由 |
|------|------|
| **Badge 而非纯文本** | 4 态颜色分级（红/黄/灰/默认）一眼识别风险等级 |
| **NULL 显示「∞ 永久」** | 与英文「∞」无限符号 + 中文「永久」双标识 |
| **30 天黄灯阈值** | 业内通用：30 天内过期需要管理员关注 |
| **datetime-local 而非 date** | 与 Web `_UserPanel.cshtml` 保持完全一致（精度到分钟，避免时区歧义）|
| **Modal 留空 = 永久** | 不破坏现有数据：历史用户无 expiresAt 字段时显示永久，无需批量迁移 |
| **Mock 4 态分布** | admin=永久、finance01=正常、pda001/visitor01=即将过期、pda002/pda003=已过期 — 一次展示 4 种业务场景 |
