## 二、数据关系全景图

### 2.1 核心实体关系

```
┌─────────────┐     ┌──────────────┐     ┌─────────────────┐
│   Department │────<│  SysEmployee │────<│   DormBooking   │
│   (部门)     │     │   (员工档案) │     │   (办理登记)     │
└─────────────┘     └──────┬───────┘     └─────────────────┘
                            │
                            ├──> DormCode ────> Dorm (宿舍档案)
                            │
                            ├──> EmploymentStatusId ────> EmploymentStatus (在职状态)
                            │
                            ├──> ResidenceStatusId ────> ResidenceStatus (住宿状态)
                            │
                            ├──> EmployeeTypeId ────> EmployeeType (员工类型)
                            │
                            ├──> AttendanceTypeId ────> AttendanceType (考勤班次)
                            │
                            └──> TeamId ────> Team (班组)
```

### 2.2 费用与抄表关系

```
┌──────────────┐     ┌───────────────┐     ┌──────────────┐
│    Dorm      │<────│  MeterRecord  │────>│  MeterImage  │
│  (宿舍档案)   │     │   (抄表记录)   │     │   (图片附件)  │
└──────┬───────┘     └───────┬───────┘     └──────────────┘
       │                     │
       │ DormCode            │ ReadMonth
       │                     │
       ▼                     ▼

│         BillingStandard (费用标准)       │

       │
```

## 三、跨页面数据流转

### 3.1 入住办理流程

```
人员清单 (新增员工)
  │
  ├─ 填写员工信息（工号、姓名、部门、员工类型等）
  │
  ├─ 设置 DormCode = 空 → 未住宿
  │
  ▼
办理登记 → 入住办理 (CheckIn)
  │
  ├─ 选择员工 → 选择宿舍 → 选择床位
  │
  ├─ 校验：宿舍容量未满、性别一致
  │
  ├─ 创建 DormBooking 记录 (Type=1, Status=2)
  │
  ├─ 更新 SysEmployee.DormCode = 宿舍代码
  │
  ├─ 更新 SysEmployee.ResidenceStatusId = 1 (已住宿)
  │
  ▼
宿舍详情 → 入住人数 +1
```

### 3.2 退房办理流程

```
办理登记 → 退房办理 (CheckOut)
  │
  ├─ 选择员工 → 确认退房
  │
  ├─ 创建 DormBooking 记录 (Type=2, Status=3)
  │
  ├─ 更新 SysEmployee.DormCode = NULL
  │
  ├─ 更新 SysEmployee.ResidenceStatusId = 2 (未住宿)
  │
  ▼
宿舍详情 → 入住人数 -1, 入住率下降
```

### 3.3 抄表与费用计算流程

```
抄表记录 → 手动录入 / PDA 上传
  │
  ├─ 选择宿舍 → 选择月份
  │
  ├─ 录入冷水表、热水表、电表读数
  │
  ├─ 系统自动计算用量（本期读数 - 上期读数）
  │
  ├─ 校验：同宿舍同月唯一
  │
  ▼
费用标准 (HotWaterPrice / ColdWaterPrice / ElectricityPrice)
  │
  ├─ 计算宿舍总费用 = Σ(用量 × 单价)
  │
  ▼
宿舍账单 (DormBilling)
  │
  ├─ 按入住人数分摊
  │
  ▼
员工账单 (EmployeeBilling)
  │
  ├─ 显示每人应付金额
  │
  ▼
首页 KPI → 人均费用、本月费用合计
```

## 四、首页 KPI 数据源

| KPI | 数据源 | 计算公式 |
|-----|--------|---------|
| 入住人数 | `SysEmployee` | COUNT(DormCode IS NOT NULL) |
| 宿舍入住率 | `Dorm.Capacity` | 入住人数 / ΣCapacity × 100% |
| 预约人员 | `DormBooking` | COUNT(Status=1 且 BookingDate < Today) |
| 异常人员 | `SysEmployee` | (在职状态≠1 且 DormCode 非空) + (在职且未到入职日期) + (预约超期未办) |
| 本月抄表覆盖 | `MeterRecord` | COUNT(本月有记录) / COUNT(Dorm) |
| 人均费用 | `EmployeeBilling` | SUM(TotalShareAmount) / COUNT(账单) |
| 本月费用合计 | `DormBilling` | SUM(宿舍总费用) |
