## 2. 新增页面详细说明

### 2.1 Personnel/Import.cshtml（人员导入页面）

**原型来源**：`personnel/import.html`

**功能说明**：
- 三步导入向导：下载模板 → 上传文件 → 导入结果
- 模板包含字段：工号、姓名、部门、员工类型、考勤班次、手机号、入职日期、离职日期、房号、备注
- 导入结果展示：成功/失败/重复跳过统计 + 错误详情表格

**PageModel 特性**：
- `OnPostUploadAsync`：处理文件上传和校验
- `ImportResultDto`：导入结果数据传输对象
- `ImportErrorDto`：导入错误信息

### 2.2 DormBilling/Index.cshtml（宿舍账单页面）

**原型来源**：`billing/dorm-bills.html`

**功能说明**：
- 宿舍月度账单列表：房号、楼栋、楼层、三表用量/费用、合计、在住人数、状态
- 筛选条件：计费月份、房号、楼栋、楼层
- 操作按钮：生成、重生成、导出Excel
- 详情弹窗：费用组成 + 员工分摊明细（含部门、员工类型、考勤班次列）

**PageModel 特性**：
- `DormBillingDto`：宿舍账单数据传输对象
- 分页支持：`PagedResult<DormBillingDto>`
- 用量计算：冷水费 + 热水费 + 电费 = 合计

### 2.3 Dorms/History.cshtml（宿舍住宿历史页面）

**原型来源**：`dorms/history.html`

**功能说明**：
- 时间线式历史记录展示
- 左侧：宿舍信息卡片 + 累计住宿人次统计
- 右侧：入住/退宿时间线（在宿/已退宿 Badge）
- 每条记录：员工工号/姓名/部门 + 入住/退宿日期 + 居住天数

**PageModel 特性**：
- 路由参数：`{id:int}` 宿舍 ID
- 从 `DormBooking` 表查询历史记录
- `HistoryRecordDto`：历史记录数据传输对象

### 2.4 Meter/Entry.cshtml（手动补录抄表页面）

**原型来源**：`meter/entry.html`

**功能说明**：
- 宿舍 + 月份选择 → 三表读数录入 + 照片上传
- 用量实时预览（右侧面板）
- 上月读数参考（左侧面板）
- 覆盖模式：同月同房号已存在记录时覆盖更新

**PageModel 特性**：
- `OnPostAsync`：创建或覆盖抄表记录
- 自动判定状态：`MeterRecord.DetermineStatus(cold, hot, electric)`
- 已修正记录（status=2）不可再修改

### 2.5 Meter/Edit.cshtml（修正抄表读数页面）

**原型来源**：`meter/edit.html`

**功能说明**：
- 只读展示原始记录信息（宿舍、月份、抄表员、设备）
- 三表读数修改 + 照片重新上传
- 修正原因必填
- 用量变化对比表（原读数 vs 新读数 vs 变化）

**PageModel 特性**：
- 路由参数：`{id:int}` 记录 ID
- `OnPostAsync`：修正记录并标记 status=2（已修正）
- 修正后记录不可再修改或删除

### 2.6 Meter/Import.cshtml（批量导入抄表页面）

**原型来源**：`meter/import.html`

**功能说明**：
- 三步导入向导：下载模板 → 上传文件 → 导入结果
- 模板列：房号、抄表月份、冷水读数、热水读数、电表读数、抄表员、备注
- 校验规则：覆盖模式（status=0/4 可覆盖，status=1/2 需修正）
- 错误详情：行号、房号、月份、三表读数、错误信息

**PageModel 特性**：
- `OnPostUploadAsync`：文件上传和校验
- `OnPostImportAsync`：确认导入
- `ImportResultDto`：导入结果统计

### 2.7 Settings/Index.cshtml（系统设置页面）

**原型来源**：`settings/index.html`

**功能说明**：
- 7 个 Tab 页签：服务与端口、数据库连接、PDA App 版本、用户与角色、备份与恢复、系统集成、关于系统
- 服务与端口：PDA/Web 端口配置 + 启动/停止 + 域名 + 图片路径
- 数据库连接：服务器/端口/库名/账号/密码 + 8 步深度验证
- PDA App 版本：版本列表 + 发布新版本
- 用户与角色：用户管理 + 角色权限矩阵
- 备份与恢复：自动备份策略 + 手动备份列表
- 系统集成：HR/K3ERP 双系统配置 + 连接测试
- 关于系统：版本信息 + 技术栈 + 设计规模

**PageModel 特性**：
- 所有配置数据使用 DTO 模拟
- 8 步数据库深度验证（TCP → SQL 登录 → 库可见 → CREATE → INSERT → SELECT → UPDATE → DELETE）
