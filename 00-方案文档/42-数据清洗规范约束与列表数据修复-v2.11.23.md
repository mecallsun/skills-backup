## 2. v2.11.23 数据清洗规范

### 2.1 强制原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **FK 完整性** | 所有业务表的 FK 字段（如 employeeTypeId）必须引用有效 ID（基础资料字典范围内）|
| 2 | **数据归一化** | 所有 mock 数据必须经过 normalizeData IIFE 校正后才能被业务逻辑使用 |
| 3 | **派生属性分离** | 派生字段（如住宿状态）必须通过函数计算，不得作为冗余字段存储 |
| 4 | **字典一致性** | 业务表中所有枚举字段必须引用基础资料字典，不得使用硬编码字符串 |
| 5 | **审计日志** | normalizeData IIFE 必须输出控制台日志，便于审计数据修复情况 |

### 2.2 normalizeData IIFE 数据清洗规则

#### 规则 1：考勤班次补全
```javascript
// 旧 → 新：attendanceType（字符串）→ attendanceTypeId（FK）+ attendanceTypeName
PERSONNEL.forEach(p => {
    if ((p.attendanceTypeId === undefined || p.attendanceTypeId === null) && p.attendanceType) {
        const t = ATTENDANCE_TYPES.find(x => x.code === p.attendanceType);
        if (t) { p.attendanceTypeId = t.id; p.attendanceTypeName = t.name; }
    }
});
```

#### 规则 2：员工类型补全 + 校正
```javascript
// Step 2a: 旧字符串 → FK + Name
// Step 2b: employeeTypeId > 5（无效）→ 按部门语义映射回 1-5 范围
PERSONNEL.forEach(p => {
    if (p.employeeTypeId > 5) {
        const deptId = p.departmentId || 1;
        const map = { 1:1, 2:1, 3:4, 4:1, 5:3, 6:2, 7:3, 8:1 };
        p.employeeTypeId = map[deptId];
        // 同步修正 employeeTypeName
        const ct = EMPLOYEE_TYPES.find(t => t.id === p.employeeTypeId);
        if (ct) p.employeeTypeName = ct.name;
    }
});
```

#### 规则 3：部门补全
```javascript
PERSONNEL.forEach(p => {
    if (!p.departmentId && p.department) {
        const d = DEPARTMENTS.find(x => x.name === p.department || x.code === p.department);
        if (d) p.departmentId = d.id;
    }
});
```

#### 规则 4：在职状态补全
```javascript
PERSONNEL.forEach(p => {
    if (!p.employmentStatusId && p.status) {
        p.employmentStatusId = p.status;
        const s = EMPLOYMENT_STATUSES.find(x => x.id === p.status);
        if (s) p.employmentStatusName = s.name;
    }
});
```

#### 规则 5：EMPLOYEE_BILLS 字段重建（v2.11.23 新增）
```javascript
// v2.11.22 修订 + v2.11.23 强化：
// - 保留 employeeType 字段（v2.11.7 IIFE 误删）
// - 通过 employeeId 关联 PERSONNEL → employeeTypeId 重建
// - 同步重建 attendanceType（被 v2.11.7 §2.4.1 删除的字段）
EMPLOYEE_BILLS_202607.forEach(b => {
    if (b.employeeId) {
        const p = PERSONNEL.find(emp => emp.id === b.employeeId);
        if (p) {
            if (!b.employeeType) {
                b.employeeType = p.employeeTypeName || p.employeeType ||
                    (EMPLOYEE_TYPES.find(t => t.id === p.employeeTypeId)?.name);
            }
            if (!b.attendanceType && (p.attendanceTypeName || p.attendanceType)) {
                b.attendanceType = p.attendanceTypeName || p.attendanceType;
            }
        }
    }
});
```

#### 规则 6：BOOKINGS 关联 PERSONNEL.dormCode 同步（v2.11.18 规则）

// BOOKINGS 最后一条有效记录 → PERSONNEL.dormCode
