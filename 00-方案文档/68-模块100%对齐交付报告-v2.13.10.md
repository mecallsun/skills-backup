### Admin 部署特殊说明

DormManage.Admin 项目引用 DormManage.Api，导致 `dotnet publish` 报 NETSDK1152（多 appsettings.json 冲突）。**解决方案**：
```bash
# 用 dotnet build 生成 bin/Release/net8.0/win-x64 后整体拷贝
dotnet build DormManage.Admin/DormManage.Admin.csproj -c Release -r win-x64 --self-contained true
cp -r DormManage.Admin/bin/Release/net8.0/win-x64/* publish-final/Admin/
```
此方式输出包含 Admin + 嵌套 Api 的合并可执行环境，运行时 Admin 端口 5001、Api 端口 5100 由托盘通过 `DormManage_KESTREL_PORT` / `DormManage_DB_*` 环境变量注入。
