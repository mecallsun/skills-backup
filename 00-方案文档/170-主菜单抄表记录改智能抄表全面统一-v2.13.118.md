## 七、核心教训

### 7.1 派生 UI 标签容易遗漏

v2.13.96 主重命名只改了 4 类直接标签，但**派生 UI 标签**（_shared 资源、个人中心模块列表、侧边导航、sub-tab 标题）很容易遗漏。**完整重命名应 grep 3 类位置**：
1. **直接 UI**：页头、按钮、菜单项
2. **派生 UI**：共享 storage-keys、sub-tab、profile module list、verify scripts
3. **历史 changelog**：保留作为追溯，但需要追加 v2.13.118 增量说明

### 7.2 "全部统一" 原则 vs 历史保留

| 类型 | 处理 |
|------|------|
| 当前用户可见 UI 标签 | 必须改（用户感知）|
| 当前需求/规范文档章节描述 | 改（影响未来开发）|
| v2.11.x / v2.12.x 历史 changelog | 保留（不可篡改历史）|
| 技术字段注释（mock-data.js） | 保留（追溯性）|

**判断标准**：用户能否在当前页面/文档中看到 → 必改；用户只能在 git 历史中看到 → 保留。
