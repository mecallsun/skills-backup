## 二、v2.13.41 实施变更

### 2.1 P0-1 Detail 重大重构（52% → 100%）

**PageModel 改造**：`Meter/Detail.cshtml.cs`
- `MeterRecordDetailDto` 新增 6 字段：`DeviceSn` / `CreatedAt` / `ReadDate` / `CorrectionReason` / `CorrectedBy` / `CorrectedAt`
- `ComparisonInfo` 新增 `PreviousReadMonth`（对比月份显示）
- 新增 `DetailActions`（按 Status 决定 3 个操作按钮的可用性）

**View 改造**：`Meter/Detail.cshtml`
- **左右分栏布局**：左侧主信息+用量对比，右侧照片占位+操作说明（响应式：小屏自动堆叠）
- **基本信息新增 3 字段**：抄表时间（ReadDate 或 ServerCreatedAt）、PDA 设备、入库时间
- **三表读数卡片**：冷水/热水/电，每张卡片带颜色 border-left + icon + `reading-big` 样式（1.6rem + `tabular-nums`）
- **用量对比表改回原型结构**：表头「冷水(m³)/热水(m³)/电(kWh)」+ 行「上月/本月/用量」（数字全部 `tabular-nums`）
- **Remark 历史格式化**：自动识别 `[CorrectionReason]` 渲染为带 `bi-clock-history` 图标的修正记录块
- **照片占位**：黑色 200px + watermark 显示 `DormCode | ReadMonth` + 存储路径说明 `/uploads/YYYYMM/房号/`
- **3 个操作按钮（按状态动态显示）**：
  - 补录 → `/Meter/Entry?dormCode=&month=`（占位/取消状态）
  - 修正读数 → `/Meter/Edit?id=`（正常/已修正状态）
  - 删除记录 → DELETE `/api/v1/meter/{id}`（草稿/取消状态）
- **操作说明卡片**：4 状态卡片（草稿/正常/已修正/已取消）按 Status 动态渲染

### 2.2 P0-2 Entry onReadingInput 业务逻辑补全

**View 改造**：`Meter/Entry.cshtml`
- form 加 4 个 data-* 属性：`data-prev-cold` / `data-prev-hot` / `data-prev-electric` / `data-has-prev`
- 完全重写 `onReadingInput()` JS 函数：

| # | 改造点 | 描述 |
|---|--------|------|
| 1 | 用量真正计算 | 用量 = 当前读数 - 上月读数（之前 BUG：直接当读数） |
| 2 | 红色错误校验 | 当前读数 < 上月读数 → `text-danger` + `bi-x-circle-fill` 错误提示 |
| 3 | 首次抄表提示 | 无 LastRecord → `text-info` + `bi-info-circle` 显示「首次抄表」 |
| 4 | 正常用量展示 | 读数 ≥ 上月 → `text-success` + `bi-check-circle` 显示「+ X.XX」 |
| 5 | 提交按钮联动 | 读数 < 上月 → 禁用提交按钮 |
| 6 | DOMContentLoaded 初始化 | 页面加载自动调用一次，刷新用量预览 |

### 2.3 P0-3 Index coverage alert（进度可视化）

**PageModel 改造**：`Meter/Index.cshtml.cs`
- 新增 `CoverageDto` 属性：`TargetMonth` / `TotalDorms` / `ReadDorms` / `UnfinishedDorms` / `UncoveredDorms` / `Percentage`
- 在 `OnGetAsync` 末尾计算覆盖率（按当前筛选月份 + 启用住宿总数）

**View 改造**：`Meter/Index.cshtml`
- 在 PageHeader 后、filter-card 前加 `alert` 进度条
- 三色动态（≥90% success / ≥60% warning / 否则 danger）
- 显示「已抄 N / M 间（X%）· 未完成 X 间 · 未覆盖 Y 间」+ 200px 进度条

### 2.4 未改造页面说明

- **Edit 85%**：保留现有实现，diff 计算属于 JS 重写（次要，本版本保留 Razor 现有"原/新/变化"3 列结构）
- **Import 72%**：保留现有 4 张统计卡片 + 7 列错误表，"加载示例数据"按钮属于 demo 增强（次要）
