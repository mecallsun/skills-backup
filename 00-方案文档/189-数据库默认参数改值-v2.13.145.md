## 三、SQL Server `user` 关键字转义说明

### 3.1 关键字列表（部分）
- `user` 是 T-SQL 保留字（用于 `CURRENT_USER`、`USER_NAME()` 等系统函数）
- 其他常见关键字：`table`、`select`、`from`、`where`、`order`、`group`...

### 3.2 三种上下文的处理

| 上下文 | `user` 是否需要转义 | 示例 |
|--------|---------------------|------|
| **连接串** | ❌ 不需要 | `UID=user;PWD=1234` |
| **DDL (`CREATE LOGIN` / `CREATE USER`)** | ✅ 必须 | `CREATE LOGIN [user] WITH PASSWORD = N'1234'` |
| **DDL (`ALTER ROLE ... ADD MEMBER`)** | ✅ 必须 | `ALTER ROLE [db_owner] ADD MEMBER [user]` |
| **查询 (`SELECT ... FROM ...`)** | ✅ 必须 | `SELECT * FROM [user]` |
| **T-SQL 函数** | ❌ 不需要 | `SELECT USER_NAME()` |

### 3.3 v2.13.145 DDL 改写完整对比

**修改前**（v2.13.144）：
```sql
CREATE LOGIN [__DB_USER__]
WITH PASSWORD = N'__DB_PASSWORD__',
     DEFAULT_DATABASE = [WaterMeterDB],

CREATE USER [__DB_USER__] FOR LOGIN [__DB_USER__];

ALTER ROLE [db_owner] ADD MEMBER [__DB_USER__];
```

**修改后**（v2.13.145）：
```sql
CREATE LOGIN [user]
WITH PASSWORD = N'1234',
     DEFAULT_DATABASE = [WaterMeterDB],

CREATE USER [user] FOR LOGIN [user];

ALTER ROLE [db_owner] ADD MEMBER [user];
```

### 5.2 现有部署升级

- **如果生产库已经连接 `192.168.1.237/__DB_USER__/__DB_PASSWORD__`**：
  - 选项 A：保持现有连接不变（仅源代码默认值变化，不影响运行）
  - 选项 B：在 SSMS 重命名 login 为 `user`，修改密码为 `1234`，并更新应用层 appsettings.json 的连接串
- **如果首次部署到 `172.16.0.100`**：直接使用新默认值

### 5.3 客户端必读

- ⚠️ **密码 `1234` 是默认值，生产部署前必须修改**：
  ```json
  {
    "ConnectionStrings": {
      "Default": "Server=172.16.0.100;Database=WaterMeterDB;UID=user;PWD=<你的强密码>;TrustServerCertificate=True;"
    }
  }
  ```
- 通过托盘「数据库连接」页或 Web「系统设置 → 数据库连接」修改即可（写入 db_setting.json）

## 六、4 条永久教训

### 6.1 「默认值一致性」必须用 grep 全文搜

单文件改动不算改完——本次实际改了 32 个文件（生产代码 14 + SQL 工具脚本 18）。**只改 appsettings.json 会留 BUG**：DbConfigController 的 GetConfig 默认值仍是 `192.168.1.237`，导致 API fallback 路径错误。**默认值必须用 grep 全仓库搜**。

### 6.2 SQL Server 保留关键字必须方括号转义

`user`、`table`、`select` 等 T-SQL 关键字在 DDL 中必须 `[user]`，但连接串中 `UID=user` 不需要。**两类场景必须分别处理**。

### 6.3 DDL 脚本改值要 head + body 一起改

DDL 脚本不只是改 SQL 语句本身，**头部注释 + 末尾 banner + 下一步提示** 都要同步改。用户最容易遗忘 banner 和 "下一步" 提示。

### 6.4 Tools 工具程序也是默认值的一部分

`DormManage.Tools.GenderBackfill/Program.cs:51` 这种一次性 DBA 脚本也含连接串，容易遗忘但会被 DBA 直接执行。**默认值 grep 必须覆盖所有 .cs 项目**（不只是 DormManage.sln 含的 4 个）。
