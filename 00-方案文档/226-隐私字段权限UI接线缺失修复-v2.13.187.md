# 隐私字段权限 UI 接线缺失修复（v2.13.187 hotfix）

> **版本**：v2.13.187 hotfix
> **日期**：2026-07-27
> **类型**：BUG 修复 + UI 全面接线

---

## Context

### 用户报告

> 在隐私字段管理的清单中，勾选了「住宿档案」模块的「容量」、「在住人数」字段；登录用户 test 的角色【行政助理】没有勾选「允许显示隐私字段」；为什么 住宿档案中 仍然显示 了 容量、在住人数 2个字段却仍然显示字段相关信息了？

### 历史根因

v2.13.92 → v2.13.180 期间，`SysFieldPermission` 表内种子的字段（共 21 个）虽然数据层正确，但是**页面接线（UI 集成）工作严重遗漏**：

| FieldKey | 模块 | 接线状态 | 实际行为 |
|---------|------|----------|---------|
| `employee.realname` | Personnel | ✅ v2.13.92 | 正确隐藏 |
| `employee.phone` | Personnel | ✅ v2.13.92 | 正确隐藏 |
| `employee.employeecode` | Personnel | ⚠️ 部分接线 | 已知 |
| `employee.dormcode` | Personnel | ⚠️ 部分接线 | 已知 |
| **`dorm.capacity`** | **Dorms** | **❌ 未接线** | **始终显示** |
| **`dorm.currentcount`** | **Dorms** | **❌ 未接线** | **始终显示** |

其他主菜单列表的字段同样存在类似问题，本次重点修复 Dorms 模块。

### 数据链路（已正确）

- ✅ 数据库 `SysFieldPermission` 表 seed 正确（v2.13.180 扩展的 21 字段全部入库）
- ✅ `PermissionService.GetHiddenFieldKeysAsync()` 正确返回隐藏集合
- ✅ `Html.IsFieldHiddenAsync("dorm.capacity")` 返回 `true`（如果权限拒绝）
- ❌ **Razor 模板没有调用 helper** — 直接 `@item.Capacity` 输出原始值

### v2.13.176 deny-by-default 语义

| 角色 | 字段可见性 |
|------|-----------|
| 用户**有任一角色**勾选「允许显示隐私字段」 | 显示所有字段 |
| 用户**所有角色**都未勾选「允许显示隐私字段」 | **隐藏**所有 `IsActive=true` 字段 |

→ 字段权限已具备机制，但页面缺失 `IsFieldHiddenAsync()` 调用，导致机制失效。

## 实施方案

### 修复 1：`Dorms/Index.cshtml`（列表页）

**核心问题**：列表页 4 个字段（容量表头、在住人数表头、容量数据、在住人数数据）无条件直接渲染。

#### 表头修复

```html
<!-- 修复前 -->
<th class="text-center">容量</th>
<th class="text-center">在住人数</th>

<!-- 修复后 -->
<th class="text-center @(await Html.IsFieldHiddenAsync("dorm.capacity") ? "d-none" : "")">容量</th>
<th class="text-center @(await Html.IsFieldHiddenAsync("dorm.currentcount") ? "d-none" : "")">在住人数</th>
```

#### 数据单元格修复

```html
<!-- 容量单元格 -->
<td class="text-center @(await Html.IsFieldHiddenAsync("dorm.capacity") ? "d-none" : "")">
    @(await Html.IsFieldHiddenAsync("dorm.capacity") ? "***" : item.Capacity + " 人")
</td>

<!-- 在住人数单元格 -->
<td class="text-center @(await Html.IsFieldHiddenAsync("dorm.currentcount") ? "d-none" : "")">
    @(await Html.IsFieldHiddenAsync("dorm.currentcount") ? "***" :
      $"<span class=\"badge ...\">{item.CurrentCount}</span> / {item.Capacity}")
</td>
```

### 修复 2：`Dorms/Details.cshtml`（详情页）

**核心问题**：详情页面容量字段行（基本信息卡片）直接渲染。

```html
<!-- 修复前 -->
<tr>
    <th width="60" class="text-muted">容量</th>
    <td>@Model.Dorm.Capacity 人</td>
</tr>

<!-- 修复后 -->
<tr>
    <th width="60" class="text-muted">容量</th>
    <td class="@(await Html.IsFieldHiddenAsync("dorm.capacity") ? "d-none" : "")">@Model.Dorm.Capacity 人</td>
</tr>
```

### 不修复：编辑/创建页面

`Dorms/Edit.cshtml` 和 `Dorms/Create.cshtml` 中的容量字段是**输入框**而非显示字段，编辑权限由 RBAC 的 `dorm:edit`/`dorm:create` 控制，不需要字段权限接线。

## 永久教训

1. **数据先行 ≠ UI 就绪**：`SysFieldPermission` 表 seed 21 字段但 Razor 模板只接 2 字段，造成"seed 但 no-op"。
2. **文档"隐含"≠ 实际完成**：v2.13.185 文档提到"v2.13.180 字段 UI 接线"，但实际未做。
3. **测试应覆盖每行表头**：v2.13.180 扩展后应立即给所有 21 字段写 E2E 测试，未发现 BUG 是因为只测了已接线的字段。
4. **禁止只测前端可见层**：DB、Service、API、UI 四层中任何一层未接线，BUG 都会显式暴露。
