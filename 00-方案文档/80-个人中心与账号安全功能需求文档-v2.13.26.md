## 第二部分：数据库 Schema 变更（v2.13.26）

### 2.1 SysUser 表扩展

```sql
ALTER TABLE [dbo].[SysUser] ADD
    [WeChatOpenId]               NVARCHAR(64)  NULL,   -- 微信 OpenID
    [WeChatBindAt]               DATETIME      NULL,   -- 绑定时间
    [PasswordResetToken]         NVARCHAR(128) NULL,   -- 密码找回令牌
    [PasswordResetTokenExpiry]   DATETIME      NULL,   -- 令牌过期时间
    [PasswordResetFailedCount]   INT           NOT NULL DEFAULT ((0)),
    [PasswordResetLockedUntil]   DATETIME      NULL;

CREATE UNIQUE INDEX [IX_SysUser_WeChatOpenId]
    ON [dbo].[SysUser]([WeChatOpenId]) WHERE [WeChatOpenId] IS NOT NULL;
```

### 2.2 新表 SysUserSecurityQuestion

```sql
CREATE TABLE [dbo].[SysUserSecurityQuestion] (
    [Id]            INT            IDENTITY(1,1) NOT NULL,
    [UserId]        INT            NOT NULL,
    [QuestionIndex] INT            NOT NULL,
    [Question]      NVARCHAR(200)  NOT NULL,
    [AnswerHash]    NVARCHAR(500)  NOT NULL,
    [CreatedAt]     DATETIME       NOT NULL DEFAULT (GETDATE()),
    [UpdatedAt]     DATETIME       NULL,
    CONSTRAINT [PK_SysUserSecurityQuestion] PRIMARY KEY ([Id]),
    CONSTRAINT [UQ_SQ_User_Index] UNIQUE ([UserId], [QuestionIndex]),
    CONSTRAINT [FK_SQ_User] FOREIGN KEY ([UserId]) REFERENCES [dbo].[SysUser]([UserId]) ON DELETE CASCADE
);
CREATE INDEX [IX_SQ_User] ON [dbo].[SysUserSecurityQuestion]([UserId]);
```

**字段说明**：
- `UserId`：所属用户 FK，级联删除
- `QuestionIndex`：1 或 2，每用户唯一
- `Question`：问题文本
- `AnswerHash`：答案密文（AES-256 加密 + 小写标准化）

## 第五部分：安全措施（5 大维度）

### 5.1 密码强度校验

```csharp
private static string ValidatePasswordStrength(string pwd) {
    if (string.IsNullOrEmpty(pwd) || pwd.Length < 8)
        return "密码长度至少 8 位";
    if (pwd.Length > 64)
        return "密码长度不能超过 64 位";
    if (!pwd.Any(char.IsLetter))
        return "密码必须包含字母";
    if (!pwd.Any(char.IsDigit))
        return "密码必须包含数字";
    return "";
}
```

### 5.2 暴力破解防护

- **密码找回**：连续 3 次答案错误 → 锁定 15 分钟（写 `SysUser.PasswordResetLockedUntil`）
- **公开端点延迟**：用户不存在时 `Task.Delay(800)` 模拟延迟，防枚举
- **公开端点**：同一令牌 30 分钟过期，单次有效

### 5.3 答案标准化

- 存储前：`AesEncryptor.Encrypt(answer.Trim().ToLowerInvariant())`
- 验证时：相同标准化后比对，防止大小写绕过
- AES-256-CBC 加密，复用现有 `AesEncryptor`

### 5.4 二次验证

- 修改个人资料、修改安全问题、绑定/解绑微信 → 全部要求"当前密码"二次验证
- 验证失败：`return ApiResponse.Fail("INVALID_PASSWORD", "当前密码不正确")`

### 5.5 审计日志（写入 SysOpLog）

- 密码修改（成功/失败）
- 安全问题设置
- 微信绑定/解绑
- 密码重置（公开端点 + 管理端）
