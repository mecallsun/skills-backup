## 五、首页 KPI 数据联动验证

| KPI | 数据来源 | 联动页面 |
|-----|---------|---------|
| 入住人数 | `SysEmployee WHERE DormCode IS NOT NULL` | 人员清单、住宿详情 |
| 住宿入住率 | `入住人数 / ΣCapacity` | 住宿管理、首页入住率排名 |
| 预约人员 | `DormBooking WHERE Status=1 AND BookingDate < Today` | 办理登记 |
| 异常人员 | `在职≠1 且 DormCode 非空` + `预约超期` | 人员清单、办理登记 |
| 本月抄表覆盖 | `MeterRecord WHERE ReadMonth=本月` | 抄表记录 |
| 人均费用 | `SUM(EmployeeBilling.TotalShareAmount) / COUNT` | 员工账单 |
| 本月费用合计 | `SUM(DormBilling.TotalAmount)` | 住宿账单 |

## 七、启动流程

1. 运行 `DormManage.TrayApp.exe`
2. 托盘程序自动启动：
   - `DormManage.Admin.exe`（Web 管理端，端口 5001）
   - `DormManage.Api.exe`（PDA 接口服务，端口 5100）
3. 托盘菜单"打开管理后台"自动启动浏览器访问 `http://localhost:5001`
4. PDA 终端通过 `http://<服务器IP>:5100` 访问抄表接口
