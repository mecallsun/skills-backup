# 需求规格说明书 — v2.11.2 增补 (j)：数据看板月度选择

> **范围**：首页数据看板（index.html）
> **日期**：2026-07-11
> **对应原型**：`04-HTML原型/index.html`

---

## 1. 变更背景

原首页数据看板固定显示当前月份（2026-07）的数据，无法查看历史月份的经营指标。

本次新增"**月度选择**"控件，允许管理员查看任意月份的 KPI 和图表数据，便于：
- **历史趋势分析**：对比不同月份的入住率、费用
- **数据复盘**：回顾特定月份的经营状况
- **下钻分析**：从月度趋势图下钻到具体月份

---

## 2. 月度选择控件

### 2.1 位置

数据看板标题区域（顶部"数据看板 2026-07" badge 处）。

### 2.2 UI 组件

| 组件 | 类型 | 说明 |
|------|------|------|
| **月份选择器** | `<input type="month">` | 显示/选择具体月份（YYYY-MM） |
| **上个月按钮** | `<button>` | 快捷跳转到上月 |
| **下个月按钮** | `<button>` | 快捷跳转到下月 |
| **当前月按钮** | `<button>` | 快速回到当前月 |

### 2.3 默认值

- **默认选中**：当前月份（演示数据：`2026-07`，实际生产：`DateTime.Today.ToString("yyyy-MM")`）
- **可选范围**：2025-08 至 2026-07（演示数据 12 个月范围）

### 2.4 视觉布局


## 3. KPI 重新计算规则

切换月份后，4 张 KPI 按月份重新计算：

| KPI | 计算源 | 是否随月份变化 |
|-----|--------|--------------|
| **入住人数** | PERSONNEL 中 dormCode 非空计数（v2.11.6 修复） | ❌ 不变（系统级人员数据） |
| **宿舍入住率** | 入住人数 / DORMS Capacity 总和（v2.11.6 修复） | ❌ 不变（系统级人员数据） |
| **预约人员** | BOOKINGS 中 status=1 且 bookingDate 在选中月份 | ✅ 变 |
| **异常人员** | A+B+C（涉及 hireDate/bookingDate 与 today 比较） | ✅ 变（today 固定，bookingDate 变动） |
| **本月抄表覆盖** | METER_RECORDS 中对应月份的已抄/未抄 | ✅ 变 |
| **本月费用合计** | DORM_BILLS 对应月份合计 | ✅ 变 |

> **注**：演示数据 mock-data.js 当前仅包含 2026-07 的抄表/账单/分摊明细，历史月份使用 `MONTHLY_COST_TREND` 提供总费用，`MONTHLY_MOVE_STATS` 提供入住退房人数。

### 5.2 JS 核心函数

```javascript
let currentDashboardMonth = '2026-07';

function shiftMonth(delta) {
    const [y, m] = currentDashboardMonth.split('-').map(Number);
    const d = new Date(y, m - 1 + delta, 1);
    const ny = d.getFullYear();
    const nm = String(d.getMonth() + 1).padStart(2, '0');
    renderDashboard(`${ny}-${nm}`);
}

function goCurrentMonth() {
    renderDashboard('2026-07');  // 演示数据固定当前月
}

function renderDashboard(month) {
    currentDashboardMonth = month;
    document.getElementById('dashboardMonth').value = month;
    document.getElementById('dashboardMonthBadge').textContent = month;
    
    // 1. 重新计算 KPI
    renderKpis(month);
    
    // 2. 重新渲染图表（高亮/数据切换）
    renderCharts(month);
}
```

```javascript
function renderKpis(month) {
    // 1. 预约人员：BOOKINGS.status=1 && bookingDate 月份匹配
    const bookingCount = BOOKINGS.filter(b => 
        b.status === 1 && b.bookingDate.startsWith(month)
    ).length;
    
    // 2. 异常人员：hireDate 和 bookingDate 涉及 today
    const today = new Date();
    const abnormalCount =
        PERSONNEL.filter(p => p.status === 2 && p.dormCode !== null).length +
        PERSONNEL.filter(p => p.status === 1 && p.dormCode !== null && 
                              new Date(p.hireDate) > today).length +
        BOOKINGS.filter(b => b.status === 1 && 
                              new Date(b.bookingDate) < today &&
                              b.bookingDate.startsWith(month)).length;
    
    // 3. 抄表覆盖：METER_RECORDS 中对应月份
    const cov = meterCoverage(month);
```

## 6. 后端实现（参考）

### 6.1 月度看板数据 API

```csharp
[ApiController]
[Route("api/v1/dashboard")]
public class DashboardController : ControllerBase
{
    [HttpGet("monthly")]
    public async Task<DashboardDto> GetMonthly([FromQuery] string month)
    {
        return new DashboardDto {
            Month = month,
            Kpis = await _dashboardService.GetKpisAsync(month),
            Charts = await _dashboardService.GetChartsAsync(month)
        };
    }
}
```

### 6.2 SQL 查询示例

```sql
-- 本月费用合计
SELECT SUM(TotalAmount) 
FROM DormBilling 
WHERE BillingMonth = @Month;

-- 本月抄表覆盖
SELECT 
    COUNT(DISTINCT DormCode) AS ReadCount,
    (SELECT COUNT(*) FROM Dorm WHERE IsActive = 1) AS TotalCount
FROM MeterRecord 
WHERE ReadMonth = @Month AND Status != 3;

-- 本月预约人员
SELECT COUNT(*) 
FROM Booking 
WHERE Status = 1 AND BookingDate LIKE @Month + '%';
```
