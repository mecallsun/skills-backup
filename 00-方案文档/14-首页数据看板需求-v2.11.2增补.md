# 需求规格说明书 — v2.11.2 增补（首页看板新增 2 个 KPI） + v2.11.6 数据逻辑修复

> **范围**：在 v2.11 的 4 张 KPI 基础上，于"宿舍入住率"与"本月抄表覆盖"之间新增 2 张 KPI 卡片
> **日期**：2026-07-11
> **最新调整**：2026-07-13（v2.11.6 异常人员 A 项 status 修正：2→3；KPI 1 入住人数改用 dormCode 非空计数）
> **角色视角**：前端开发 + 数据统计
> **对应原型**：`04-HTML原型/index.html`

## 1. 变更背景

v2.11 看板仅有 4 张 KPI，遗漏了"**预约人员**"和"**异常人员**"两个对日常运营非常重要的统计：
- **预约人员**：反映未来一段时间的入住压力
- **异常人员**：反映数据质量问题（已离职仍住 / 提前入住 / 超期未办）

为提升管理员对**入住生命周期**的掌握，本增补在 4 张 KPI 中间插入 2 张 KPI，扩展为 **6 张 KPI**。

| 字段 | 内容 |
|------|------|
| **指标名称** | 预约人员 |

### 2.3 KPI 4：异常人员数量（三种情况之和）

**计算公式**：

```
异常人员数 = A + B + C
```

| 分项 | 含义 | 数据源 | 统计规则 |
|------|------|--------|---------|
| **A** | 已离职但仍入住 | `PERSONNEL` | `status === 3 && dormCode !== null`（EmployeeStatus.Left = 3） |
| **B** | 未到入职日期提前入住 | `PERSONNEL` | `status === 1 && dormCode !== null && hireDate > today` |
| **C** | 超期未按时办理入住/退房 | `BOOKINGS` | `status === 1 && bookingDate < today` |

> ⚠️ **v2.11.6 修复**：A 项原逻辑使用 `status === 2`（待入职），已修正为 `status === 3`（已离职）。EmployeeStatus 枚举定义：1=Active(在职)、2=Onboarding(待入职)、3=Left(已离职)。

> **today** 为当前服务器日期（前端用 `new Date()`，生产用 `DateTime.Today`）。

**字段说明**：

| 字段 | 内容 |
|------|------|
| **指标名称** | 异常人员 |
| **主数值** | 整数（异常总数 A+B+C） |
| **副文** | "需处理" |
| **基础色** | 深绿 `#008300` |

**显示规则**：

| 条件 | 主数值显示 | 副文 | 颜色 |
|------|----------|------|------|
| 数量 > 0 | 整数 N（如 `3`） | "需处理" | **红 `#e53935`**，字号 1.6rem，加粗 |
| 数量 = 0 | 文本 "正常" | "无异常" | **绿 `#0ca30c`**，字号 **1.8rem**，**加粗** |

**示例**：
- 3 个异常 → `3` / 需处理 / 红色
- 0 个异常 → `正常` / 无异常 / 绿色大号

## 3. 实现要点

### 3.1 前端计算（HTML 原型）

**KPI 3 计算代码**（在 `index.html` 的 KPI 渲染脚本中）：

```javascript
// 预约人员数量：BOOKINGS 中 status=1 的数量
const bookingCount = BOOKINGS.filter(b => b.status === 1).length;
const kpiBooking = document.getElementById('kpiBooking');
const kpiBookingSub = document.getElementById('kpiBookingSub');
if (bookingCount > 0) {
    kpiBooking.textContent = bookingCount;
    kpiBooking.style.color = '#eda100';
    kpiBooking.style.fontSize = '1.6rem';
    kpiBooking.style.fontWeight = 'bold';
    kpiBookingSub.textContent = '人待入住';
} else {
    kpiBooking.textContent = '正常';
    kpiBooking.style.color = '#0ca30c';
    kpiBooking.style.fontSize = '1.8rem';
    kpiBooking.style.fontWeight = 'bold';
    kpiBookingSub.textContent = '无预约';
}
```

**KPI 4 计算代码**：

```javascript
// 异常人员 = 已离职仍住 + 未到入职提前住 + 超期未办理入住/退房
const today = new Date();
const abnormalCount =
    PERSONNEL.filter(p => p.status === 3 && p.dormCode !== null).length +  // A: 已离职仍住（v2.11.6 修复：status=3）
    PERSONNEL.filter(p => p.status === 1 && p.dormCode !== null && new Date(p.hireDate) > today).length +  // B: 未到入职提前住
    BOOKINGS.filter(b => b.status === 1 && new Date(b.bookingDate) < today).length;  // C: 超期未办理

// 后端 SQL（v2.11.6 修复）
// A 项：SELECT COUNT(*) FROM Personnel WHERE Status = 3 AND DormCode IS NOT NULL

const kpiAbnormal = document.getElementById('kpiAbnormal');
const kpiAbnormalSub = document.getElementById('kpiAbnormalSub');
if (abnormalCount > 0) {
    kpiAbnormal.textContent = abnormalCount;
    kpiAbnormal.style.color = '#e53935';
    kpiAbnormal.style.fontSize = '1.6rem';
    kpiAbnormal.style.fontWeight = 'bold';
    kpiAbnormalSub.textContent = '需处理';
} else {
    kpiAbnormal.textContent = '正常';
    kpiAbnormal.style.color = '#0ca30c';
    kpiAbnormal.style.fontSize = '1.8rem';
    kpiAbnormal.style.fontWeight = 'bold';
    kpiAbnormalSub.textContent = '无异常';
}
```

### 3.2 后端实现（生产环境 .NET）

对应 SQL（可在 EF Core LINQ 中翻译）：

```sql
-- 异常人员总数（v2.11.6 修复：A 项 Status=3 已离职）
SELECT
    (SELECT COUNT(*) FROM Personnel WHERE Status = 3 AND DormCode IS NOT NULL) +  -- A: 已离职仍住
    (SELECT COUNT(*) FROM Personnel WHERE Status = 1 AND DormCode IS NOT NULL AND HireDate > CAST(GETDATE() AS DATE)) +  -- B: 提前入住
    (SELECT COUNT(*) FROM Booking WHERE Status = 1 AND BookingDate < CAST(GETDATE() AS DATE))  -- C: 超期未办理
    AS AbnormalCount;

-- 预约人员数量
SELECT COUNT(*) FROM Booking WHERE Status = 1;
```

**性能**：
- 列表规模 500 入住 + 600 人员 + 580 预约，三次单表 COUNT 在 PersonnelStatus/DormCode 索引下 < 50ms
- 可合并为单次查询（UNION ALL + COUNT）
