# 当前入住人员新增性别列 + 床号简化（v2.13.188）

> **版本**：v2.13.188
> **日期**：2026-07-27
> **类型**：新功能 + UI 简化

---

## Context

### 用户需求

> 在 当前入住人员 页面的列表中，增加 一列为：性别，在姓名之后显示，以记录的 员工id 关联 的 性别 显示；
> 另将 床号列的 记录值 删除 "床位" 只显示床号 数字。

### 影响范围

- **页面**：`/Dorms/Details`（宿舍详情页 → 当前入住人员卡片）
- **后端**：`DormDbContext` → `DormBookings` → JOIN `SysEmployee` → 读 `SysEmployee.Gender`
- **文件**：2 个文件改动

---

## 实施方案

### 修复 1：后端 DTO 添加 Gender 字段

**文件**：`DormManage.Admin/Pages/Dorms/Details.cshtml.cs`

#### 1.1 `BookingRecordDto` 新增 Gender 属性

```csharp
public class BookingRecordDto
{
    public long Id { get; set; }
    public int EmployeeId { get; set; }
    // ... 其他既有字段 ...

    /// v2.13.188：员工性别（按 EmployeeId 关联 SysEmployee.Gender）
    /// 1=男 2=女 0=未知；前端渲染 Badge 显示
    public int Gender { get; set; } = 0;
}
```

#### 1.2 `OnGetAsync` 赋值 Gender

```csharp
CurrentResidents = currentBookings.Select(b => new BookingRecordDto
{
    // ... 其他赋值 ...
    // v2.13.188：按 EmployeeId 关联 empDict[b.EmployeeId].Gender
    Gender = empDict.ContainsKey(b.EmployeeId) ? empDict[b.EmployeeId].Gender : 0
}).ToList();
```

## 颜色语义映射（性别 Badge）

| 性别 | 类名 | 颜色 | 图标 |
|------|------|------|------|
| 男 | `bg-primary` | 蓝色 | `bi-gender-male` |
| 女 | `bg-danger` | 红色（粉） | `bi-gender-female` |
| 未知/未填 | `text-muted` | 灰色 | `-` |

颜色选择与项目内其他性别显示保持一致（参考 Personnel/Index.cshtml 第196-210 行）。

## 数据模型

`SysEmployee.Gender`：

| 列 | 类型 | 默认 | 含义 |
|----|------|------|------|
| Gender | int | 1 | 1=男 / 2=女 / 0=未知（理论不应出现）|

数据来源：基础资料-在职员工表的 `Gender` 字段，由 HR 系统初始化或手工录入。

## 永久教训

1. **数据层字段在前端可显示未必已接线**：`SysEmployee.Gender` 字段已存在但宿舍详情页未显示，需要像 v2.13.187 一样按 `EmployeeId` JOIN 关联。
2. **Badge 颜色语义必须全局一致**：男=primary（蓝）、女=danger（粉）与 Personnel 列表一致，避免不同页面色彩冲突。
3. **移除冗余前缀信息**：「床位 3」中「床位」是冗余修饰词，表头已说明「床号」列，单元格仅显示数字更清爽。
4. **DTO 字段放置应靠近相关字段**：`Gender` 与 `EmployeeTypeId`/`TeamId` 同处于 SysEmployee 维度，归类清晰。
