## 1. 整体架构

采用 **双层导航** 布局：

```
┌─────────────────────────────────────────────────────────┐
│  Tier 1: 顶部品牌栏 (top-bar)                             │
│  [Logo + 品牌名]                    [用户信息 + 退出]     │
├─────────────────────────────────────────────────────────┤
│  Tier 2: 菜单导航栏 (menu-bar)                            │
│  [首页][记录] | [宿舍] [人员] | [费用标准][费用清单][分摊] │
│  | [旧员工][用户][角色] | [系统设置]                      │
└─────────────────────────────────────────────────────────┘
```

- **Tier 1** 固定顶部 (`sticky top:0`)，包含品牌标识和用户操作
- **Tier 2** 紧随其下，包含所有功能菜单，横向滚动自适应
- 两层之间有 `1px` 分隔线，整体视觉层次清晰

## 4. 交互行为

### 4.1 菜单项状态

| 状态 | 表现 |
|------|------|
| 默认 | 灰色文字 `#5f6368`，无边框 |
| Hover | 背景淡蓝 `rgba(25,118,210,0.04)`，图标放大 1.12x |
| 激活 | 类别色文字 + `3px` 底部色条 + 淡色背景 |

### 4.2 退出按钮

| 状态 | 表现 |
|------|------|
| 默认 | 灰色边框 `#e0e0e0`，灰色文字 |
| Hover | 红色边框 `#e53935`，红色文字，淡红背景 |

### 4.3 自动高亮

JavaScript 根据当前 URL pathname 自动匹配菜单项并添加 `active` 类：

```javascript
var currentPath = window.location.pathname.replace(/\/$/, '');
document.querySelectorAll('.menu-item').forEach(function(link) {
    var href = link.getAttribute('href');
    if (href && (currentPath === href || currentPath.startsWith(href))) {
        link.classList.add('active');
    }
});
```

## 7. 与设计系统的对齐

本导航设计遵循 dataviz 技能的设计原则：

- **色彩职责固定**：每个类别使用固定色，过滤/排序不改变颜色分配
- **单一坐标轴**：无双重编码，颜色仅表示类别身份
- **文字使用文字色**：数值/标签使用中性墨色，彩色图标承载身份
- **Thin marks**：菜单项边框仅 3px 底部色条，不喧宾夺主
- **无障碍**：颜色 + 图标 + 文字三重编码，不依赖单一颜色传达信息
