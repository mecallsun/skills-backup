## 1. 变更背景

### 1.1 变更原因

v2.11.3 版本的抄表记录模块存在以下问题需要解决：

| 问题 | 现状 | 需求 |
|------|------|------|
| **占位记录依赖人工** | 每月需手动检查未抄表宿舍并生成占位记录 | 每日0点自动检查并生成占位记录 |
| **覆盖逻辑不完整** | 部分场景可新增、部分场景覆盖，逻辑混乱 | 统一为"更新覆盖"模式，不新增 |
| **已作废状态冗余** | status=3（已作废）状态及其相关功能增加复杂度 | 删除所有"已作废"相关选项/数据/功能 |
| **无法物理删除** | 仅支持作废（软删除），无法彻底删除记录 | 新增物理删除功能和权限控制 |

### 1.2 变更目标

1. **自动化**：每日0点自动生成占位记录，确保每月每房号必有记录
2. **统一覆盖**：PAD/新增/导入均为更新覆盖，记录历史快照
3. **简化状态**：删除已作废状态，仅保留3个状态（未完成/正常/已修正）
4. **支持删除**：新增物理删除功能及权限控制

## 2. 核心业务规则

### 2.1 状态定义（v2.11.4 最终版）

| Status | 含义 | 数据完整性 | Badge 颜色 | 参与计费 | 可修正 | 可删除 |
|--------|------|----------|-----------|:---:|:---:|:---:|
| **0** | **未完成（占位记录）** | 三表全 0 或部分为 0 | 灰 `bg-light text-dark border` | ❌ | ❌ | ✅ |
| 1 | **正常** | 三表完整且读数递增 | 绿 `bg-success` | ✅ | ✅ | ❌ |
| 2 | **已修正** | 三表完整（已修正过） | 黄 `bg-warning text-dark` | ✅ | ❌ | ❌ |

> **说明**：所有占位记录默认 status=0，无需区分"未抄表"和"未完成"，统一用 0 表示。

### 2.2 定时自动生成占位记录（R-METER-AUTO-01 ~ R-METER-AUTO-06）

| 规则 | 说明 |
|------|------|
| R-METER-AUTO-01 | **每日0点（00:00）**系统自动执行定时任务 |
| R-METER-AUTO-02 | 检查当月（当前年月 YYYY-MM）的所有启用宿舍（Dorm.IsActive=true） |
| R-METER-AUTO-03 | 若某启用宿舍当月**无任何抄表记录**，自动生成一条 status=0 的占位记录 |
| R-METER-AUTO-04 | 占位记录三表读数均为 0，Operator="系统自动生成"，Remark="自动生成占位记录" |
| R-METER-AUTO-05 | 宿舍停用后不再为其生成占位记录 |
| R-METER-AUTO-06 | 手动删除占位记录后，系统在下一次定时任务时重新生成 |

**定时任务设计**：

```
┌─────────────────────────────────────────────────────────────┐
│                    每日 00:00 执行                           │
├─────────────────────────────────────────────────────────────┤
│ 1. 获取当前年月 readMonth = DateTime.Now.ToString("yyyy-MM") │
│ 2. 获取所有启用宿舍列表 dormList                              │
│ 3. 获取当月已有记录的宿舍列表 hasRecords                      │
│ 4. 差集：missingDorms = dormList - hasRecords                │
│ 5. 对 missingDorms 中每个宿舍：                               │
│    - 检查是否已存在 status=0 占位记录                         │
│    - 不存在则创建新占位记录（status=0，三表=0）                │
│ 6. 记录执行日志（生成数量、跳过数量）                          │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 统一覆盖逻辑（R-METER-OVERWRITE-01 ~ R-METER-OVERWRITE-06）

| 规则 | 说明 |
|------|------|
| R-METER-OVERWRITE-01 | **所有数据操作均为更新覆盖**：PDA上传、后台手动补录、批量导入均采用覆盖模式 |
| R-METER-OVERWRITE-02 | **禁止新增**：同月同房号已存在记录时，直接覆盖，不创建新记录 |
| R-METER-OVERWRITE-03 | **覆盖时记录历史**：被覆盖的旧数据快照追加到新记录的 Remark 字段 |
| R-METER-OVERWRITE-04 | **历史记录格式**：`[YYYY-MM-DD HH:mm 覆盖前数据] cold=X, hot=Y, electric=Z, status=S, operator=O` |
| R-METER-OVERWRITE-05 | **多次覆盖保留完整历史**：每次覆盖都在 Remark 末尾追加新的历史条目 |
| R-METER-OVERWRITE-06 | **已修正记录需走修正流程**：覆盖 status=2（已修正）记录时，提示"已定稿，需走修正流程" |

**覆盖场景矩阵**：

| 场景 | 旧记录状态 | 处理方式 |
|------|----------|---------|
| PDA 上传/补录/导入 | status=0（未完成） | 覆盖，旧数据追加备注 |
| PDA 上传/补录/导入 | status=1（正常） | 覆盖，旧数据追加备注 |
| PDA 上传/补录/导入 | status=2（已修正） | **拦截**：提示"已定稿，需走修正流程" |
| 手动删除 | status=0（未完成） | 物理删除（需权限），删除后重建占位记录 |

**覆盖后状态自动判定**：

```csharp
byte DetermineStatus(decimal cold, decimal hot, decimal electric)
{
    int nonZeroCount = 0;
    if (cold > 0) nonZeroCount++;
    if (hot > 0) nonZeroCount++;
    if (electric > 0) nonZeroCount++;
    
    if (nonZeroCount == 0) return 0;  // 未完成（占位记录）
    if (nonZeroCount == 3) return 1;  // 正常
    return 0;  // 未完成（部分表项有值也归为未完成）
}
```

## 3. 状态机完整定义（v2.11.4 最终版）

### 3.1 状态定义

```
[未完成(0)]    -- PDA 上传/后台补录/覆盖 --> [正常(1)]
[正常(1)]      -- 后台修正读数 --> [已修正(2)]
[未完成(0)]    -- PDA 上传/后台补录/覆盖 --> [正常(1)]
```

### 3.2 状态转换规则

| 来源状态 | 目标状态 | 触发条件 | 说明 |
|---------|---------|---------|------|
| 0 → 1 | 正常 | PDA 上传三表完整数据 / 后台手动补录三表完整 | 覆盖旧数据追加备注 |
| 0 → 1 | 正常 | 后台新增/导入覆盖 status=0 记录 | 覆盖旧数据追加备注 |
| 1 → 2 | 已修正 | 后台修正读数（填写修正原因） | 已修正后不可再修正/删除 |
| 0 → 0 | 未完成 | PDA 上传部分表项（1-2个表有值，其余为0） | 部分上传场景 |
| 0 → 无 | 删除 | 管理员物理删除 | 删除后重建占位记录 |

```csharp
/// <summary>
/// 抄表记录状态
/// </summary>
public enum MeterRecordStatus
{
    /// <summary>未抄表（三表全0）</summary>
    Unread = 0,
    
    /// <summary>正常（三表完整）</summary>
    Normal = 1,
    
    /// <summary>已修正（三表完整，已修正过）</summary>
    Corrected = 2,
    
    /// <summary>未完成（部分表项有值）</summary>
    Incomplete = 4
}

public class MeterRecord
{
    public long Id { get; set; }
    public int DormId { get; set; }
    public string DormCode { get; set; } = "";
    public string ReadMonth { get; set; } = "";
    public decimal ColdMeter { get; set; } = 0;
    public decimal HotMeter { get; set; } = 0;
    public decimal ElectricMeter { get; set; } = 0;
    public string Operator { get; set; } = "";
    public string? DeviceSn { get; set; }
    public string? ClientRecordId { get; set; }
    public DateTime? ClientCreatedAt { get; set; }
    public DateTime ServerCreatedAt { get; set; } = DateTime.Now;
    public DateTime? UpdatedAt { get; set; }
    
    /// <summary>
    /// 状态：0=未抄表 1=正常 2=已修正 4=未完成
    /// </summary>
    public byte Status { get; set; } = 0;
    
    /// <summary>
    /// 备注（包含历史覆盖快照）
    /// </summary>
    public string? Remark { get; set; }
    
    // 导航属性
    public Dorm? Dorm { get; set; }
    public ICollection<MeterImage> Images { get; set; } = new List<MeterImage>();
    
    /// <summary>
    /// 判断是否为未完成状态（部分表项有值）
    /// </summary>
    [NotMapped]
    public bool IsIncomplete
    {
        get
        {
            int nonZeroCount = 0;
            if (ColdMeter > 0) nonZeroCount++;
            if (HotMeter > 0) nonZeroCount++;
            if (ElectricMeter > 0) nonZeroCount++;
            return nonZeroCount > 0 && nonZeroCount < 3;
        }
    }
    
    /// <summary>
    /// 自动判定状态
    /// </summary>
    public static byte DetermineStatus(decimal cold, decimal hot, decimal electric)
    {
        int nonZeroCount = 0;
        if (cold > 0) nonZeroCount++;
        if (hot > 0) nonZeroCount++;
        if (electric > 0) nonZeroCount++;
        
        if (nonZeroCount == 0) return 0;  // 未抄表
        if (nonZeroCount == 3) return 1;  // 正常
        return 4;  // 未完成
    }
}
```

## 5. API 端点更新

### 5.1 新增接口：定时任务（每日0点执行）

```csharp
/// <summary>
/// 每日0点自动生成占位记录
/// </summary>
[HttpPost("meter/generate-placeholder")]
[RequirePermission("System:AutoTask")]  // 系统任务权限
public async Task<ApiResponse<GeneratePlaceholderResult>> GeneratePlaceholder()
{
    // 1. 获取当前年月
    var currentMonth = DateTime.Now.ToString("yyyy-MM");
    
    // 2. 获取所有启用宿舍
    var activeDorms = await _db.Dorms
        .Where(d => d.IsActive)
        .Select(d => d.DormCode)
        .ToListAsync();
    
    // 3. 获取当月已有记录的宿舍
    var hasRecords = await _db.MeterRecords
        .Where(r => r.ReadMonth == currentMonth)
        .Select(r => r.DormCode)
        .Distinct()
        .ToListAsync();
    
    // 4. 计算差集
    var missingDorms = activeDorms.Except(hasRecords).ToList();
    
    // 5. 批量生成占位记录
    int generated = 0;
    foreach (var dormCode in missingDorms)
    {
        var dorm = await _db.Dorms.FirstOrDefaultAsync(d => d.DormCode == dormCode);
        if (dorm == null) continue;
        
        var exists = await _db.MeterRecords
            .AnyAsync(r => r.DormCode == dormCode && r.ReadMonth == currentMonth && r.Status == 0);
        if (exists) continue;
        
        _db.MeterRecords.Add(new MeterRecord
        {
            DormId = dorm.DormId,
            DormCode = dormCode,
            ReadMonth = currentMonth,
            ColdMeter = 0,
            HotMeter = 0,
            ElectricMeter = 0,
            Operator = "系统自动生成",
            DeviceSn = "AUTO",
            Status = 0,
            Remark = $"[{DateTime.Now:yyyy-MM-dd HH:mm} 自动生成占位记录]",
            ServerCreatedAt = DateTime.Now
        });
        generated++;
    }
    
    await _db.SaveChangesAsync();
    
    return ApiResponse<GeneratePlaceholderResult>.Ok(new GeneratePlaceholderResult
    {
        Month = currentMonth,
        TotalActiveDorms = activeDorms.Count,
        HasRecordsCount = hasRecords.Count,
        GeneratedCount = generated,
        Message = $"已为 {currentMonth} 月生成 {generated} 条占位记录"
    });
}
```

### 5.3 新增接口：删除记录（DELETE /api/meter/records/{id}）

```csharp
/// <summary>
/// 删除抄表记录
/// </summary>
[HttpDelete("meter/records/{id:long}")]
[RequirePermission("Meter:Delete")]
public async Task<ApiResponse> DeleteRecord(long id)
{
    var record = await _db.MeterRecords
        .Include(r => r.Images)
        .FirstOrDefaultAsync(r => r.Id == id);
    
    if (record == null)
        return ApiResponse.Error(404, "记录不存在");
    
    // 仅 status=0 可直接删除
    if (record.Status != 0)
    {
        return ApiResponse.Error(400, "仅未抄表状态的记录可删除");
    }
    
    // 检查是否有关联账单
    var hasBilling = await _db.DormBillings
        .AnyAsync(b => b.DormCode == record.DormCode && b.BillingMonth == record.ReadMonth);
    if (hasBilling)
    {
        return ApiResponse.Error(400, "该记录已生成账单，无法删除");
    }
    
    // 删除关联图片
    if (record.Images.Any())
    {
        foreach (var img in record.Images)
        {
            var filePath = Path.Combine(_uploadPath, img.RelativePath);
            if (File.Exists(filePath))
                File.Delete(filePath);
        }
    }
    
    // 记录删除日志
    _logger.LogInformation("删除抄表记录: Id={Id}, DormCode={DormCode}, ReadMonth={Month}, Operator={Operator}", 
        record.Id, record.DormCode, record.ReadMonth, _currentUser);
    
    // 物理删除
    _db.MeterRecords.Remove(record);
    await _db.SaveChangesAsync();
    
    // 删除后重建占位记录（如需要）
    await RebuildPlaceholderIfNeeded(record.DormCode, record.ReadMonth);
    
    return ApiResponse.Ok("删除成功");
}

/// <summary>
/// 删除后重建占位记录
/// </summary>
private async Task RebuildPlaceholderIfNeeded(string dormCode, string readMonth)
{
    var hasRecord = await _db.MeterRecords
        .AnyAsync(r => r.DormCode == dormCode && r.ReadMonth == readMonth);
    
    if (!hasRecord)
    {
        var dorm = await _db.Dorms.FirstOrDefaultAsync(d => d.DormCode == dormCode && d.IsActive);
        if (dorm != null)
        {
            _db.MeterRecords.Add(new MeterRecord
            {
                DormId = dorm.DormId,
                DormCode = dormCode,
                ReadMonth = readMonth,
                ColdMeter = 0,
                HotMeter = 0,
                ElectricMeter = 0,
                Operator = "系统自动生成",
                DeviceSn = "AUTO",
                Status = 0,
                Remark = $"[{DateTime.Now:yyyy-MM-dd HH:mm} 删除后重建占位记录]",
                ServerCreatedAt = DateTime.Now
            });
            await _db.SaveChangesAsync();
        }
    }
}
```

```csharp
/// <summary>
/// 获取抄表记录列表
/// </summary>
[HttpGet("meter/records")]
public async Task<ApiResponse<PagedResult<MeterRecordDto>>> GetRecords(
    string? dormCode,
    string? readMonth,
    byte? status,       // 0=未抄表 1=正常 2=已修正 4=未完成（删除3已作废）
    int page = 1,
    int pageSize = 20)
{
    var query = _db.MeterRecords
        .Include(r => r.Dorm)
        .AsQueryable();
    
    if (!string.IsNullOrEmpty(dormCode))
        query = query.Where(r => r.DormCode.Contains(dormCode));
    
    if (!string.IsNullOrEmpty(readMonth))
        query = query.Where(r => r.ReadMonth == readMonth);
    
    if (status.HasValue)
        query = query.Where(r => r.Status == status.Value);
    
    var total = await query.CountAsync();
    var items = await query
        .OrderByDescending(r => r.ReadMonth)
        .ThenBy(r => r.DormCode)
        .Skip((page - 1) * pageSize)
        .Take(pageSize)
        .Select(r => new MeterRecordDto
        {
            Id = r.Id,
            DormCode = r.DormCode,
            ReadMonth = r.ReadMonth,
            ColdMeter = r.ColdMeter,
            HotMeter = r.HotMeter,
            ElectricMeter = r.ElectricMeter,
            Operator = r.Operator,
            Status = r.Status,
            StatusName = r.Status switch
            {
                0 => "未抄表",
                1 => "正常",
                2 => "已修正",
                4 => "未完成",
                _ => "未知"
            },
            ServerCreatedAt = r.ServerCreatedAt
        })
        .ToListAsync();
    
    return ApiResponse<PagedResult<MeterRecordDto>>.Ok(new PagedResult<MeterRecordDto>
    {
        Total = total,
        Page = page,
        PageSize = pageSize,
        Items = items
    });
}
```

## 6. 数据迁移方案

### 6.1 status=3 记录迁移

对于已存在的 status=3（已作废）记录，执行以下迁移：

```sql
-- 1. 查询已作废记录数量
SELECT COUNT(*) FROM dbo.MeterRecord WHERE Status = 3;

-- 2. 备份已作废记录到临时表
SELECT * INTO dbo._MeterRecord_Voided_Backup_20260711 
FROM dbo.MeterRecord WHERE Status = 3;

-- 3. 删除已作废记录
DELETE FROM dbo.MeterRecord WHERE Status = 3;

-- 4. 为被删除记录的宿舍重新生成占位记录（当月）
INSERT INTO dbo.MeterRecord (DormId, DormCode, ReadMonth, ColdMeter, HotMeter, ElectricMeter, Operator, DeviceSn, Status, Remark, ServerCreatedAt)
SELECT DISTINCT d.DormId, d.DormCode, mr.ReadMonth, 0, 0, 0, '系统迁移', 'MIGRATION', 0, '由已作废记录迁移生成', GETDATE()
FROM dbo._MeterRecord_Voided_Backup_20260711 mr
INNER JOIN dbo.Dorm d ON d.DormCode = mr.DormCode AND d.IsActive = 1
WHERE NOT EXISTS (
    SELECT 1 FROM dbo.MeterRecord r 
    WHERE r.DormCode = mr.DormCode AND r.ReadMonth = mr.ReadMonth
);
```

### 9.2 TrayApp 内置定时任务（备选方案）

```csharp
// 在 TrayApp 中实现定时任务
public class PlaceholderGeneratorTask : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            var now = DateTime.Now;
            var nextRun = now.Date.AddDays(1);  // 次日0点
            var delay = nextRun - now;
            
            await Task.Delay(delay, stoppingToken);
            
            if (!stoppingToken.IsCancellationRequested)
            {
                await GeneratePlaceholderAsync();
            }
        }
    }
    
    private async Task GeneratePlaceholderAsync()
    {
        try
        {
            using var client = new HttpClient();
            var response = await client.PostAsync("http://localhost:5000/api/meter/generate-placeholder", null);
            var result = await response.Content.ReadAsStringAsync();
            _logger.LogInformation("占位记录生成任务执行结果: {Result}", result);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "占位记录生成任务执行失败");
        }
    }
}
```
