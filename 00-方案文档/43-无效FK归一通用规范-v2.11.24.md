## 1. 背景与动机

历史 mock 数据中 197 条 `SysEmployee.EmployeeTypeId` 是无效值 6/7/8（对应硬编码的「顾问/技师/保安」），而基础资料-员工类型字典 `EmployeeType` 仅定义 5 种（ID 1-5，合同工/临时工/外包/实习生/驻场）。v2.11.23 §2.2 规则 2b 采用「部门语义映射」兜底：

```javascript
// v2.11.23 已废规则
const map = { 1:1, 2:1, 3:4, 4:1, 5:3, 6:2, 7:3, 8:1 };
p.employeeTypeId = map[deptId];
```

该规则存在三大缺陷：

| # | 缺陷 | 影响 |
|---|------|------|
| 1 | **业务语义混淆** | 员工类型不应当由部门推导（合同工可能在行政部门，临时工可能在生产部门）|
| 2 | **字典扩展需手工维护** | 每次新增部门都要改 `map` 表，否则归一失效 |
| 3 | **无法复用到其它 FK** | attendanceTypeId / departmentId / employmentStatusId / residenceStatusId 都无法套用同一规则 |

**v2.11.24 统一规则**：**任何不在字典范围内的 FK 值 → 归一为该字典最后一项的 ID**。该规则已在前端 `mock-data.js:51662-51708` 实现（`getLastDictId()` + `normalizeFK()`），但缺正式文档；本规范即为其文档化版本。

---

## 2. 规则定义

### 2.1 适用范围（首期）

| FK 字段 | 实体 | 字典来源 | 末项 ID（当前）|
|---------|------|---------|----------------|
| `SysEmployee.EmployeeTypeId` | 员工档案 | `EmployeeType`（ID 1-5）| **5**（ONSITE 驻场）|
| `SysEmployee.AttendanceTypeId` | 员工档案 | `AttendanceType`（ID 1-6）| 6（NIGHT 夜班）|
| `SysEmployee.DepartmentId` | 员工档案 | `Department`（ID 1-8）| 8 |
| `SysEmployee.EmploymentStatusId` | 员工档案 | `EmploymentStatus`（ID 1-3）| 3（LEFT 已离职）|
| `SysEmployee.ResidenceStatusId` | 员工档案 | `ResidenceStatus`（ID 1-4）| 4 【预留，等 ResidenceStatus 实体接入启用】|

### 2.2 不适用范围

- 业务实体 ID（如 `SysEmployee.Id`、`Dorm.Id`、`BookingRecord.Id`）：不是字典范畴，**不归一**，由 EF Core 主键约束保证。
- 软迁移字符串字段（如 v2.11.22 之前的 `string EmployeeType`）：走「字符串→FK」补全路径（v2.11.7 IIFE §2 / §2a），不是 v2.11.24 规则。
- 多值字典字段（如 `BillingStandard.ApplicableEmployeeTypes`）：走二期扩展，本期不处理。

### 2.3 JS 实现（与 `mock-data.js:51662-51708` 完全等价）

```javascript
/**
 * 通用字典归一工具（v2.11.24）
 * @param {string} dictName 全局字典数组名（如 'EMPLOYEE_TYPES'）
 * @returns {number|null} 字典最后一项的 ID
 */
function getLastDictId(dictName) {
    var d = (typeof window !== 'undefined' ? window : globalThis)[dictName];
    return (Array.isArray(d) && d.length > 0) ? d[d.length - 1].id : null;
}

/**
 * 通用归一函数（v2.11.24）
 * @param {Array} items 待归一的对象数组
 * @param {string} fkField 外键字段名（如 'employeeTypeId'）
 * @param {string} dictName 字典数组名
 * @param {string} [nameField] 名称冗余字段（同步修正，如 'employeeTypeName'）
 * @returns {number} 修复条目数
 */
function normalizeFK(items, fkField, dictName, nameField) {
    var lastId = getLastDictId(dictName);
    if (lastId === null) return 0;
    var dict = (typeof window !== 'undefined' ? window : globalThis)[dictName];
    var lastObj = dict.find(function (x) { return x.id === lastId; });
    var lastName = lastObj ? (lastObj.name || '') : '';
    var validIds = dict.map(function (x) { return x.id; });
    var fixed = 0;
    items.forEach(function (it) {
        var v = it[fkField];
        if (v === undefined || v === null || validIds.indexOf(v) === -1) {
            it[fkField] = lastId;
            if (nameField) it[nameField] = lastName;
            fixed++;
        }
    });
    return fixed;
}

// 应用：employeeTypeId 归一（首期）
PERSONNEL.forEach(p => {
    if (p.employeeTypeId == null || p.employeeTypeId > EMPLOYEE_TYPES.length) {
        normalizeFK([p], 'employeeTypeId', 'EMPLOYEE_TYPES', 'employeeTypeName');
    }
});
```

### 2.4 C# 等价实现（`DictionaryFallbackService.cs`）

```csharp
namespace DormManage.Shared.Services;

/// <summary>
/// 通用字典兜底归一服务（v2.11.24）
/// </summary>
public static class DictionaryFallbackService
{
    /// <summary>员工类型归一（无效/缺失 → 末项 ID）</summary>
    public static async Task<int> NormalizeEmployeeTypeIdAsync(int? currentId, DormDbContext db)
    {
        var validIds = await db.EmployeeTypes.Select(e => e.Id).ToListAsync();
        if (currentId.HasValue && validIds.Contains(currentId.Value)) return currentId.Value;
        return await db.EmployeeTypes.OrderByDescending(e => e.Id).Select(e => e.Id).FirstAsync();
    }

    // NormalizeAttendanceTypeIdAsync / NormalizeDepartmentIdAsync / NormalizeEmploymentStatusIdAsync 同结构
    // NormalizeResidenceStatusIdAsync 占位（db.ResidenceStatuses 实体待就绪）
}
```

详细实现见 `DormManage.Shared/Services/DictionaryFallbackService.cs`。
