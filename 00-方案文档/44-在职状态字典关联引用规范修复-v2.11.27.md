## 1. 修复背景

### 1.1 v2.11.19 规范要求

> 所有页面必须从此字典（`EMPLOYMENT_STATUSES`）读取在职状态名称，**禁止使用任何硬编码或不一致的映射**。

字典结构（修复前）：
```javascript
const EMPLOYMENT_STATUSES = [
    { id: 1, code: "ACTIVE",     name: "在职",   remark: "当前在职" },
    { id: 2, code: "ONBOARDING", name: "待入职", remark: "已录取未入职" },
    { id: 3, code: "LEFT",       name: "已离职", remark: "已办理离职" }
];
```

**缺失字段**：`color`（Badge 颜色），其他字典（`BOOKING_STATUS_DICT`、`RESIDENCE_STATUS`、`EMPLOYEE_BILL_SEGMENT_TYPE`）均含 `color` 字段，字典结构不统一。

### 1.2 问题诊断

| # | 文件 | 问题 |
|---|------|------|
| 1 | `personnel/list.html` | `employmentBadgeHtml()` 硬编码 id→Badge 映射，违反 v2.11.19 规范 |
| 2 | `personnel/list.html` | `fStatus` 筛选下拉硬编码 3 个 option，不随字典变化 |
| 3 | `billing/employee-bills.html` | 缺少"在职状态"列，无法识别账单所属员工的在职状态 |
| 4 | `mock-data.js` | `EMPLOYMENT_STATUSES` 字典缺少 `color` 字段 |

## 2. 修复方案

### 2.1 mock-data.js — 字典补全 color 字段

**修复前**：
```javascript
const EMPLOYMENT_STATUSES = [
    { id: 1, code: "ACTIVE",     name: "在职",   remark: "当前在职" },
    { id: 2, code: "ONBOARDING", name: "待入职", remark: "已录取未入职" },
    { id: 3, code: "LEFT",       name: "已离职", remark: "已办理离职" }
];
```

**修复后**：
```javascript
const EMPLOYMENT_STATUSES = [
    { id: 1, code: "ACTIVE",     name: "在职",   color: "bg-success",          remark: "当前在职" },
    { id: 2, code: "ONBOARDING", name: "待入职", color: "bg-warning text-dark", remark: "已录取未入职" },
    { id: 3, code: "LEFT",       name: "已离职", color: "bg-secondary",        remark: "已办理离职" }
];
```

### 2.2 personnel/list.html — Badge 渲染函数字典化

**修复前**：
```javascript
function employmentBadgeHtml(id) {
    if (id === 1) return '<span class="badge bg-success">在职</span>';
    if (id === 2) return '<span class="badge bg-warning text-dark">待入职</span>';
    if (id === 3) return '<span class="badge bg-secondary">已离职</span>';
    return '<span class="text-muted">-</span>';
}
```

**修复后**：
```javascript
// v2.11.27 修订：关联引用 EMPLOYMENT_STATUSES 字典（基础资料-在职状态表）
function employmentBadgeHtml(id) {
    if (typeof EMPLOYMENT_STATUSES === 'undefined') {
        // 兜底：mock-data.js 未加载时使用旧映射
        ...
    }
    var s = null;
    for (var i = 0; i < EMPLOYMENT_STATUSES.length; i++) {
        if (EMPLOYMENT_STATUSES[i].id === id) { s = EMPLOYMENT_STATUSES[i]; break; }
    }
    if (!s) return '<span class="text-muted">-</span>';
    return '<span class="badge ' + s.color + '">' + s.name + '</span>';
}
```

### 2.3 personnel/list.html — 筛选下拉字典化

**修复前**（HTML 硬编码）：
```html
<select id="fStatus" class="form-select">
    <option value="">全部</option>
    <option value="1">在职</option>
    <option value="2">待入职</option>
    <option value="3">已离职</option>
</select>
```

**修复后**（动态生成）：
```html
<select id="fStatus" class="form-select">
    <option value="">全部</option>
</select>
```

`initSelects()` 中追加：
```javascript
if (fStatus && typeof EMPLOYMENT_STATUSES !== 'undefined') {
    for (var s = 0; s < EMPLOYMENT_STATUSES.length; s++) {
        var optStatus = document.createElement('option');
        optStatus.value = EMPLOYMENT_STATUSES[s].id;
        optStatus.textContent = EMPLOYMENT_STATUSES[s].name;
        fStatus.appendChild(optStatus);
    }
}
```

## 5. 规范要求（v2.11.27 强化）

### 5.1 基础资料字典结构统一规范

所有基础资料字典必须包含以下标准字段：
- `id`：INT PK（主键）
- `code`：NVARCHAR（代码）
- `name`：NVARCHAR（显示名称）
- `color`：NVARCHAR（Bootstrap Badge class，可选但推荐）
- `remark`：NVARCHAR（备注，可选）

### 5.2 字典关联引用规范

任何页面引用基础资料字典时，必须遵循：

| 规则 | 说明 |
|------|------|
| R-DICT-01 | 字典访问必须使用 `typeof X !== 'undefined'` 守卫，避免加载顺序问题 |
| R-DICT-02 | 字典渲染（Badge/下拉）必须遍历字典数组，禁止硬编码 id→value 映射 |
| R-DICT-03 | 字典字段使用 `.find()` 或 `.forEach()` 提取，禁止 `X[id]` 直接索引（防止字典为空时崩溃） |
| R-DICT-04 | 字典修改必须同步更新所有引用页面（关联文档检查） |
| R-DICT-05 | 新增字典项必须同步更新所有引用页面的初始化逻辑 |
