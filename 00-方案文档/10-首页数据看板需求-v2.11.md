## 3. 设计规范（dataviz）

- **先选图形，配色最后**：量级用柱、部分-整体用环、随时间用（分组）柱。
- **配色按职责固定**：分类色按固定顺序取用不循环；语义三表色（冷=蓝/热=红/电=黄）跨图一致。
- **色板经校验**：分类色板通过 CVD 分离校验（最差相邻 ΔE ≥ 12）；低对比色（黄/青）以**图例 + 直接数值**作为二次编码补偿。
- **单一坐标轴**：不使用双 Y 轴；不同量纲（如水 m³ 与电 度）不混入同一数值轴（费用统一为元后方可同图）。
- **标注与交互**：≥2 序列必有图例；柱/环均提供 hover tooltip（数值 + 占比/单位）；网格线用发丝灰、刻度用弱化墨色。
- **文字用文字色**：数值/标签不使用序列色，图标承载identity。

### 6.7 v2.11.2 增补 (g)：住宿费用 TOP10 图形高度按区域拉伸（2026-07-11）

#### 问题

原 CSS `.viz-card canvas { max-height: 150px; }` 强制限制所有 canvas 最大高度 150px，导致住宿费用 TOP10 即使位于 col-lg-6 大区域，仍只能渲染 150px 高度，未充分占用右侧区域。

#### 解决方案

通过 CSS Flexbox 让 viz-card 容器能够完整填充父区域高度，再让 #chartDormCost canvas 拉伸至 100%：

```css
/* viz-card 改为 Flex 布局，让卡片能完整填充父容器 */
.viz-card {
    display: flex;
    flex-direction: column;
}
.viz-card .card-header { flex-shrink: 0; }  /* header 不收缩 */
.viz-card .card-body {
    flex: 1;
    min-height: 0;        /* 关键：允许 flex 子项收缩 */
    position: relative;
    display: flex;
    flex-direction: column;
}
/* 默认其他 canvas 仍受 max-height: 150px 限制 */
.viz-card canvas { max-height: 150px; }

/* 特殊：chartDormCost 完全填充父容器 */
#chartDormCost {
    max-height: none !important;
    width: 100% !important;
    height: 100% !important;
    flex: 1;
}
```

#### 实现要点

1. **viz-card flex 布局**：`display: flex; flex-direction: column` 让卡片内容纵向排列
2. **card-body flex: 1**：占据 header 之外的剩余高度
3. **min-height: 0**：解决 flex 子项默认 `min-height: auto` 导致无法收缩的问题
4. **canvas height: 100%**：在 Chart.js `responsive: true; maintainAspectRatio: false` 配合下完全填充父容器
5. **其他 canvas 保持 max-height: 150px**：不破坏现有图表显示效果
