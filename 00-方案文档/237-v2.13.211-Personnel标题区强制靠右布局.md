## 3. v2.13.211 设计方案（方案 B - flex-start + ms-auto）

### 3.1 核心改动（2 处 CSS + 1 处 HTML class）

**改动 1：`_Layout.cshtml:165` 修改 `.page-header` 主样式**

```css
.page-header {
    display: flex;
    justify-content: flex-start;        /* v2.13.211 改动：space-between → flex-start */
    align-items: center;
    margin-bottom: 0.75rem;
}
```

**改动 2：`Default.cshtml:38` 给按钮组加 `ms-auto`**

```html
<!-- 改动前 -->
<div class="d-flex align-items-center gap-2 page-header-actions flex-nowrap">

<!-- 改动后 -->
<div class="d-flex align-items-center gap-2 page-header-actions flex-nowrap ms-auto">
```

**改动 3：`Personnel/Index.cshtml` 无需改动**（PageHeader 组件统一接管）

### 3.2 工作原理

| 阶段 | 行为 |
|------|------|
| 父容器 `justify-content:flex-start` | h2 与按钮组都从左对齐开始 |
| 按钮组 `margin-left:auto` | 按钮组被推到右边缘，吸收所有剩余水平空间 |
| 按钮组内部 `flex-wrap:nowrap` | 按钮不换行 |
| 窗口缩放 | 按钮组始终贴右，h2 始终贴左，**两者间距 = 剩余空间**（自动伸缩） |
| h2 过长 | h2 自身 `flex-shrink:1 + min-width:0` 压缩显示省略号；按钮组位置**不受影响** |

### 3.3 与 v2.13.210 对比

| 维度 | v2.13.210（space-between） | v2.13.211（flex-start + ms-auto） |
|------|--------------------------|----------------------------------|
| `.page-header` justify-content | `space-between` | **`flex-start`** |
| `.page-header-actions` 是否有 margin-left:auto | ❌ | **`ms-auto`** |
| 按钮组与视口右边距 | `1.25rem`（page-content padding） | **0**（贴 page-header 右边缘） |
| 窗口缩放时按钮组跟随 | ❌（受 h2 长度影响） | ✅ |
| h2 过长时挤压按钮 | ✅（会出现） | ❌（按钮位置独立） |

## 6. 永久教训（v2.13.211+ 强制沉淀）

### 6.1 `ms-auto` > `space-between`

要让 flex 子元素强制靠右，使用 `margin-left:auto`（Bootstrap `ms-auto`）比 `justify-content:space-between` 更稳健——后者依赖父容器只有 2 个子元素的假设，前者独立、稳健。

### 6.2 h2 过长时不影响按钮组

v2.13.211 之前，h2 长内容会把按钮组推向中间甚至左侧；新版 `.page-header` 用 `flex-start` + 按钮组 `ms-auto`，h2 与按钮组位置完全独立。

### 6.3 全局共享样式 = 唯一权威源

仅 2 处 CSS 改动（_Layout + PageHeader 组件），全站 8 个列表页同步生效，禁止页面内覆盖。

### 6.4 HTML 原型与程序必须像素级对齐

`_shared/layout-tab.css` 同步更新 + 8 个原型页面同步修改，确保 prototype 与 Razor 渲染后视觉一致。
