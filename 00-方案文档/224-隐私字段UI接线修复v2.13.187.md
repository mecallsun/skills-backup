## Context

### 用户报告

> 在隐私字段管理的清单中，勾选了「手机号」、「入职日期」、「离职日期」；登录用户 test 的角色【行政助理】没有勾选「允许显示隐私字段」；为什么只有「手机号」能控制不显示，而「入职日期」、「离职日期」2个字段却仍然显示字段相关信息了？

### 根因诊断

**v2.13.92 → v2.13.180 期间的历史遗留 BUG**：v2.13.180 扩展新增的 16 个隐私字段（hiredate / leavedate / employeecode / dormcode / remark / idnumber / employeetype 等）**从未在 Razor 页面中实际接线** `IsFieldHiddenAsync()` helper。

| FieldKey | UI 接线状态 | 实际行为 |
|---------|------------|---------|
| `employee.realname` | ✅ v2.13.92 接线 | 正确隐藏 |
| `employee.phone` | ✅ v2.13.92 接线 | 正确隐藏 |
| `employee.hiredate` | ❌ **未接线** | 始终显示 |
| `employee.leavedate` | ❌ **未接线** | 始终显示 |
| `employee.employeecode` | ❌ 未接线 | 始终显示 |
| `employee.dormcode` | ❌ 未接线 | 始终显示 |
| `employee.remark` | ❌ 未接线 | 始终显示 |
| `employee.idnumber` | ❌ 未接线 | 始终显示 |
| `employee.employeetype` | ❌ 未接线 | 始终显示 |

### 数据链路（已正确）

- ✅ 数据库 `SysFieldPermission` 表 seed 正确（v2.13.180 扩展的 21 字段全部入库）
- ✅ `PermissionService.GetHiddenFieldKeysAsync()` 正确返回隐藏集合
- ✅ `Html.IsFieldHiddenAsync("employee.hiredate")` 返回 `true`（如果权限拒绝）
- ❌ **Razor 模板没有调用 helper** — 直接 `@item.HireDate` 输出原始值

### 为什么「手机号」生效而「入职/离职日期」不生效

- **手机号**：`v2.13.92 引入字段权限时的第一版接线`（Personnel/Index.cshtml line 139/208），完整包裹 `IsFieldHiddenAsync`
- **入职/离职日期**：`v2.13.180 扩展的新字段`，**从未接线**，硬编码显示原始值

### 这是 v2.13.185 文档遗漏的项

v2.13.185 的新文档 `221-隐私字段显示规则v2.13.185.md §四` 提到"v2.13.180 新增 16 字段 UI 接线（v2.13.185 隐含）"，但**实际接线工作从未完成**。

## 实施方案（v2.13.187 hotfix）

### 1. 修复 `Personnel/Index.cshtml` UI 接线

**文件**：`DormManage.Admin/Pages/Personnel/Index.cshtml`

#### 1.1 thead 接线（line 130-149）

**修复前**（硬编码显示，无隐私字段接线）：

```html
<th>工号</th>
<th class="@(await Html.IsFieldHiddenAsync("employee.realname") ? "d-none" : "")">姓名</th>
<th>员工类型</th>
<th>入职日期</th>
<th>离职日期</th>
```

**修复后**（8 个字段全部接入 `IsFieldHiddenAsync`）：

```html

<th class="@(await Html.IsFieldHiddenAsync("employee.employeecode") ? "d-none" : "")">工号</th>
<th class="@(await Html.IsFieldHiddenAsync("employee.realname") ? "d-none" : "")">姓名</th>
<th class="@(await Html.IsFieldHiddenAsync("employee.employeetype") ? "d-none" : "")">员工类型</th>
<th class="@(await Html.IsFieldHiddenAsync("employee.hiredate") ? "d-none" : "")">入职日期</th>

<th class="@(await Html.IsFieldHiddenAsync("employee.dormcode") ? "d-none" : "")">房号</th>
```

#### 1.2 tbody 接线（line 183-249）

**修复前**（硬编码 `@item.HireDate` 等）：

```html
<td><strong>@item.EmployeeCode</strong></td>
...
<td>@item.HireDate</td>
...
<td>@item.LeaveDate</td>
...
<td>@item.DormCode</td>
```

```html

...
<td class="@(await Html.IsFieldHiddenAsync("employee.hiredate") ? "d-none" : "")">@item.HireDate</td>
```

## v2.13.187 hotfix 永久教训

1. **数据先行 ≠ UI 就绪**：`SysFieldPermission` 表 seed 21 字段（数据层）但 Razor 模板只接 2 字段（UI 层），存在"seed 但 no-op"问题。
2. **文档"隐含"≠ 实际完成**：v2.13.185 文档提到"v2.13.180 字段 UI 接线"用"隐含"措辞，没有明确追踪责任 → 实际未完成。
3. **测试应覆盖每行表头**：v2.13.180 扩展后应立即给所有 21 字段写 E2E 测试（模拟用户角色 + 勾选/不勾选 + 检查 21 字段的可见性），而非仅检查已接线的 2 字段。
4. **发现 BUG → 立即修复 + 添加测试 + 文档更新**：本 BUG 实际存在 3+ 版本（v2.13.180 → v2.13.185 → v2.13.186 → v2.13.187），如果在 v2.13.180 刚引入时立即补全接线，不会埋雷到今天。
