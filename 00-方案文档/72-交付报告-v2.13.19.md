## 二、实现要点

### 2.1 双 UI 写入路径

```
托盘 SettingsForm
    → AppConfigManager.Instance.SaveConfigurationAsync()
        → db_setting.json（AES 密文）
        → SysParameter 表（AES 密文）
        → OnDatabaseConfigUpdated 事件

Web 后台 /Settings
    → POST /api/v1/system/dbconfig/save
        → DbConfigController
            → AppConfigManager.Instance.SaveConfigurationAsync()
                → 同上
```

### 2.2 安全设计

- 保存前必须执行连通性测试，测试失败禁止写入。
- 密码使用 AES-256-CBC 加密后落盘。
- API 返回时密码脱敏为 `******`。
- 解密失败返回空字符串，兼容历史明文密码。

### 2.3 配置传递

- 托盘启动时通过 `AppConfigManager.LoadAsync()` 读取配置。
- 解密后通过环境变量 `DormManage_DB_CONN` 注入子进程。
- Admin/Api 子进程 `Program.cs` 读取环境变量覆盖本地 `appsettings.json`。

## v2.13.109 备注：SQLite Provider 彻底移除

自 v2.13.109 起，DormManage 运行时仅支持 SQL Server。SQLite 代码路径、EF Core SQLite Provider、SQLite 备份恢复逻辑均已移除。历史配置中的 SqlitePath 字段仅为旧配置反序列化兼容，不代表运行时继续支持 SQLite。
