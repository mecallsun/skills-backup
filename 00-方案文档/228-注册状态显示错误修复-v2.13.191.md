> **日期**：2026-07-27
> **类型**：BUG 修复 + v2.13.169 RegStatus 拆分收尾

## Context

### 用户报告

> 在托盘 已注册 校验成功，但是 Web 端 的 关于系统 页面 显示的是 试用模式，存在重大错误！托盘程序 的注册状态（注册校验通过 = 全功能）；之前的版本是能正常的同步 注册状态与运行模式的对齐一致性，为什么当前版本出现错误？

### 根本原因（深挖诊断）

v2.13.169 设计中「拆 RegStatus 枚举」是关键设计变更，但**代码不完整**。三处缺失：

| 元素 | 设计位置 | 实际状态 |
|------|---------|---------|
| `ServiceIpc.RegStateDto.RegStatus` 字段 | v2.13.169 文档 §3.1 | ❌ **DTO 无此字段**（只有 RegInt） |
| `LicenseGuard.GetLicenseBanner()` 方法 | v2.13.169 文档 §3.3 | ❌ **方法未实现** |
| `LicenseStatusController` 编译 | v2.13.169 新增端点 | ⚠️ 文件 untracked，引用不存在的成员 |

### 错误链路

```
RegStateDto.RegStatus (不存在)
        ↑
LicenseStatusController.cs (untracked, 编译失败)
        ↑
LicenseStatusController.dll (在 v2.13.190 发布包中被临时禁用)
        ↑
/api/v1/system/license-status (404 → 前端 badge 异常)
        ↑
license-status-badge.js (前端 JS 显示「试用模式」或保留初始 loading 状态)
```

由于 `RegStatus` 字段在 DTO 中不存在，托盘端传递 `RegInt=1`（已注册），但前端期望的 `status=1`（已注册） 无法可靠传到，影响所有依赖 `status` 字段的显示逻辑。

### 关键文件位置

| 文件 | 行号 | 问题 |
|------|------|------|
| `DormManage.Shared/Services/ServiceIpc.cs` | 52-74 | DTO 缺少 RegStatus |
| `DormManage.Shared/Security/LicenseGuard.cs` | - | 缺少 GetLicenseBanner() 方法 |
| `DormManage.Api/Controllers/System/LicenseStatusController.cs` | 29, 46 | 调用了不存在的成员 |
| `DormManage.TrayApp/TrayAppContext.cs` | 480-488 | HandleGetRegState 未填充 RegStatus |

### 修复 2：`LicenseGuard` 实现 `GetLicenseBanner()`

**文件**：`DormManage.Shared/Security/LicenseGuard.cs`

```csharp
public static class RegStatusEnum
{
    public const int Unregistered = -1;
    public const int Valid = 1;
    public const int Expired = 2;
    public const int Invalid = 3;
}

public static (string Code, string Message, string Level) GetLicenseBanner()
{
    var state = GetCachedState();

    if (state is null)
    {
        return ("授权不可用", "无法连接到托盘程序的 IPC 服务（127.0.0.1:5099）。请检查托盘程序是否运行。", "danger");
    }

    return state.RegStatus switch
    {
        RegStatusEnum.Valid       => ("已注册",   $"✅ 软件已正式注册：{state.LTDName}，有效期至 {state.RegDate:yyyy-MM-dd}...", "success"),
        RegStatusEnum.Unregistered => ("试用模式", "🟦 试用模式：剩余 N 次使用机会，正式注册请联系信息科。", "info"),
        RegStatusEnum.Expired     => ("已过期",   "⚠ 注册码已过期，软件进入只读模式。请联系信息科进行续期。", "warning"),
        RegStatusEnum.Invalid     => ("校验失败", "⚠ 注册码校验失败（机器码/公司名不匹配）。软件进入只读模式。", "danger"),
        _ => ("未知状态", $"未识别的注册状态码：{state.RegStatus}。", "info"),
    };
}

public static int ConvertRegIntToRegStatus(int regInt)
{
    return regInt switch
    {
        1 => RegStatusEnum.Valid,
        0 => RegStatusEnum.Expired,
        -1 => RegStatusEnum.Unregistered,
        _ => RegStatusEnum.Invalid,
    };
}
```

### 修复 3：托盘端同步填充 RegStatus

**文件**：`DormManage.TrayApp/TrayAppContext.cs`

```csharp
private void HandleGetRegState(Action<ServiceIpc.IpcResponse> respond)
{
    try
    {
        var reg = RegisterSdk.CheckReg();
        var regStatus = LicenseGuard.ConvertRegIntToRegStatus(reg.RegInt);

        var state = new ServiceIpc.RegStateDto
        {
            RegInt = reg.RegInt,
            RegStatus = regStatus,  // ← 新增
            SN = reg.SN,
            CDKEY = reg.CDKEY ?? "",
            LTDName = reg.LTDName ?? "",
            RegDate = reg.RegDate,
            UseTimes = reg.UseTimes,
            DetectedAtUtc = DateTime.UtcNow
        };

        _log.Info($"[IPC getregstate] RegInt={reg.RegInt} RegStatus={regStatus} LTD={reg.LTDName} Exp={reg.RegDate:yyyy-MM-dd}");

        respond(new ServiceIpc.IpcResponse { Success = true, Message = "ok", Data = state });
    }
    catch (Exception ex)
    {
        // 错误处理
    }
}
```

## 注册状态 4 态与运行模式映射

| 注册状态枚举 | RegStatus | 中间件行为 | 模式显示 |
|------------|-----------|-----------|---------|
| Unregistered 未注册 | -1 | 放行 GET + 3 模块 POST 限记录数 | 🟦 试用模式 |
| Valid 已注册 | 1 | 全功能放行 | ✅ 已注册 |
| Expired 已过期 | 2 | 拦截全部 POST → 403 | ⚠ 已过期(只读) |
| Invalid 校验失败 | 3 | 拦截全部 POST → 403 | ⚠ 校验失败(只读) |
| IPC 不可用 | null | 拒绝启动（v2.13.184） | ⚠ 授权服务不可用 |

### 与 LicenseReadOnlyMiddleware 协同

```csharp
// LicenseReadOnlyMiddleware - 已注册则放行
if (!isReadOnly) {
    await _next(context);
    return;
}
// 仅 GET/HEAD 与白名单路径放行，其余 POST/PUT/DELETE 返回 403
```

注意：`LicenseGuard.IsReadOnly()` 与 `LicenseStatusController.GetLicenseStatus` 都基于 `GetCachedState()` 同步 30s 缓存，确保三端状态一致。

## 永久教训

1. **v2.13.169「拆 RegStatus」是核心设计变更但代码不完整**：文档先于实现，导致多处编译失败需要绕道
2. **临时禁用编译（.disabled）发布 = 隐藏 BUG**：v2.13.190 发布包丢失 LicenseStatusController，前端 API 调用 404
3. **untracked 文件是「设计断点」**：v2.13.169 的 `LicenseStatusController.cs` 是 untracked 状态，说明文档设计但代码未完全合入
4. **DTO 字段必须 v.s. 端点期望**：当 license-status-badge.js 期望 `status` 字段（RegStatus）而 DTO 只有 `RegInt`（字符串表示），前后端契约不匹配
5. **IPC 链路 30s 缓存 + RegStatus 字段**：确保 Web/Api/Tracy 三端状态同步（这是 v2.13.137 反向依赖 + v2.13.169 RegStatus 拆分的核心价值）
6. **永远 0 error 编译是硬指标**：v2.13.169 后续必须严格遵守，禁用任何 untracked 文件的隐藏 BUG 路径
