### 2.1 数据库连接配置

```json
{
  "Database": {
    "Provider": "SqlServer"  // 或 "Sqlite"
  },
  "ConnectionStrings": {
    "Default": "Server=IP;Database=WaterMeterDB;UID=username;PWD=password;TrustServerCertificate=True;"
  }
}
```

### 2.2 数据库向下兼容说明

- **SqlClient 版本**：使用 Microsoft.Data.SqlClient 4.0+（支持 SQL Server 2014+）
- **T-SQL 兼容**：所有 DDL/DML 已规避 SQL Server 2014 不支持的语法（如 `STRING_AGG WITH GROUP`）
- **数据类型兼容**：避免使用 SQL Server 2016+ 引入的新类型

## 9. 系统启动顺序与运行期控制（v2.12.43 新增）

> **本节是部署上线后的运行时规范**，详细规范请参考 `01-技术架构与系统开发方案.md` §3.6.10，本节列出部署环境层面的硬性要求。

### 9.1 启动顺序总览

| 顺序 | 阶段 | 执行者 | 失败行为 |
|:---:|------|--------|---------|
| 1 | **托盘程序启动** | `DormManage.TrayApp.exe`（开机自启 / 手动） | 配置缺失时弹出系统配置窗口 |
| 2 | **Web 服务启动** | 托盘拉起 `DormManage.Admin.exe` | **数据库连接失败 ⇒ 立即停止**（进程 Kill + 托盘图标变红 + 弹窗） |
| 3 | **PDA 服务启动** | 托盘拉起 `DormManage.Api.exe` | **数据库连接失败 ⇒ 立即停止**（同上） |
| 4 | 数据库参数修改 | 托盘菜单 → 系统配置 → 测试 → 保存 | 测试不通过禁止保存 |
| 5 | 系统重连 | 托盘重启 Web/PDA | 失败则保持 Error 等待下次配置 |
| 6 | 守护监测 | 托盘 `GuardianTimer`（2s）+ `HealthCheckTimer`（10s） | 进程消失自动拉起 + 端点连续 3 次失败标记 Error |

### 9.2 数据库连接串本地加密（Windows DPAPI）

| 项目 | 规范 |
|------|------|
| 加密算法 | **Windows DPAPI**（`System.Security.Cryptography.ProtectedData`） |
| 作用范围 | `DataProtectionScope.CurrentUser`（仅当前 Windows 用户可解） |
| 存储位置 | `%LOCALAPPDATA%\DormManage\config\{Api\|Admin}\appsettings.json`（**密文**） |
| 持久化格式 | Base64 编码的 DPAPI 密文 |
| 托盘 → 子进程 | 进程环境变量 `DormManage_DB_CONN`（明文，进程内） |
| 子进程回写 | **不回写**磁盘（内存中替换） |
| 跨用户 / 跨机器 | **不可移植**（安全特性）— 需重新配置 |

**为什么不用 MD5 / SHA 系列**：

> MD5 / SHA-1 / SHA-256 均为**单向哈希**（不可逆），无法满足"下次启动自动解密"的需求。本系统需可逆加密以解密连接串供运行时使用，故采用 **Windows DPAPI**——零密钥管理、与现有 §4.8.2 密码字段、§11.2 JWT Secret 加密体系一致。

### 9.3 日志目录规范

| 日志类型 | 路径 | 文件名格式 | 滚动策略 |
|---------|------|----------|---------|
| 托盘守护主日志 | `%LOCALAPPDATA%\DormManage\Log\` | `YYYYMMDD_log.txt` | 按天新建，保留 30 天 |
| Guardian 审计日志 | `%LOCALAPPDATA%\DormManage\guardian\` | `guardian-YYYYMMDD.log` | 按天新建，保留 30 天 |
| API 应用日志 | `%LOCALAPPDATA%\DormManage\logs\` | `api-YYYYMMDD.log` | Serilog 按天滚动 |
| Admin 应用日志 | `%LOCALAPPDATA%\DormManage\logs\` | `admin-YYYYMMDD.log` | Serilog 按天滚动 |

> **目录命名区分**：`Log/`（托盘主日志，首字母大写）vs `logs/`（Serilog 应用日志）vs `guardian/`（审计专用）。**三者并存不可合并**。

### 9.4 停止与退出

| 操作 | 行为 | 适用场景 |
|------|------|---------|
| 停止 PDA 服务 | `StopService("Api")` → 优雅关闭（≤ 10s）→ Kill | 临时维护 |
| 停止 Web 服务 | `StopService("Admin")` → 优雅关闭 → Kill | 临时维护 |
| 退出系统 | 二次确认 → 停止 Api → 停止 Admin → 关闭托盘 | 服务器关机 / 重大升级 |

## v2.13.109 备注：SQLite Provider 彻底移除

自 v2.13.109 起，DormManage 运行时仅支持 SQL Server。SQLite 代码路径、EF Core SQLite Provider、SQLite 备份恢复逻辑均已移除。历史配置中的 SqlitePath 字段仅为旧配置反序列化兼容，不代表运行时继续支持 SQLite。
