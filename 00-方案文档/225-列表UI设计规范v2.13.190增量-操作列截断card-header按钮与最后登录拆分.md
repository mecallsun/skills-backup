## 1. 本次增量要点

v2.13.190 在 v2.13.154 规范基础上，新增「**操作列按钮文字化**」「**字段溢出截断**」「**Card-header 操作按钮**」三项核心规范，覆盖 `DormManage.Admin/Pages/Settings/_UserPanel.cshtml` 等页面的样式统一。

### 1.1 三大变更背景

| 问题 | 原因 | 规范 |
|------|------|------|
| 「操作」列使用带 icon 的彩色按钮（`btn btn-sm btn-outline-*`），导致列宽不可控、按钮间拥挤 | v2.12.x 历史遗留样式，未统一收口 | **强制纯文字样式（`.op-btn`）** |
| 字段值过长时表格变形（横向滚动 + 列宽被撑大） | 表格内容超出列宽 | **强制 `.text-truncate` + `title` 属性** |
| 「新增」按钮位置不统一（有的页面在 card-header、有的在 table 上方） | 视觉割裂 | **强制位于 card-header 右侧**（与 PageHeader 组件一致） |

## 2. 操作列按钮文字化规范

### 2.1 标准样式（`.op-btn`）

```html
<td class="text-center op-cell">
    <button class="op-btn" data-bs-toggle="modal" data-bs-target="#editModal">编辑</button>
    <span class="op-btn-sep"> </span>
    <button class="op-btn op-btn-warning" onclick="disable()">停用</button>
    <span class="op-btn-sep"> </span>
    <button class="op-btn op-btn-danger" onclick="del()">删除</button>
</td>
```

### 2.2 样式约束

| 项目 | 要求 | 反例 |
|------|------|------|
| **基础类** | 必须使用 `op-btn` | `btn btn-sm btn-outline-primary` ❌ |
| **按钮间分隔** | 必须使用 `<span class="op-btn-sep"> </span>` 空格分隔 | 直接堆叠 ❌ |
| **单元格类** | 必须使用 `class="text-center op-cell"` | `class=""` 或 `class="text-center"` ❌ |
| **图标** | **禁止**使用 `<i class="bi bi-...">` 图标前缀 | `<i class="bi bi-pencil"></i> 编辑` ❌ |
| **颜色类** | 通过 `.op-btn-warning` / `.op-btn-success` / `.op-btn-danger` 区分语义 | 通过 button 组件颜色 ❌ |
| **强制单行** | `white-space: nowrap`（由 `.op-cell` 类自动生效） | 多行显示 ❌ |

### 2.3 颜色语义映射

| 操作类型 | 类名 | 颜色 | 典型场景 |
|---------|------|------|---------|
| 编辑/详情 | `op-btn` | 蓝色（默认） | 信息查看/修改 |
| 启用/激活 | `op-btn op-btn-success` | 绿色 | 启用账号、激活记录 |
| 警告/暂停 | `op-btn op-btn-warning` | 橙色 | 停用、暂停、重置密码 |
| 删除/危险 | `op-btn op-btn-danger` | 红色 | 删除、撤销 |

### 2.4 列宽建议

| 操作数量 | 建议列宽 |
|---------|---------|
| 2-3 个按钮 | `width="180"` |
| 4 个按钮 | `width="240"` |
| 5+ 个按钮 | `width="280"` |

## 3. 字段溢出截断规范

### 3.1 标准样式（`.text-truncate`）

```html
<!-- 表头 -->
<th class="text-truncate">用户名</th>

<!-- 数据行 -->
<td class="text-truncate" title="@u.UserName">@u.UserName</td>
```

### 3.2 必备 3 件套

| 项目 | 要求 |
|------|------|
| **CSS 类** | `class="text-truncate"`（Bootstrap 内置 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`） |
| **title 属性** | `title="@完整内容"`（鼠标悬停显示完整值） |
| **小尺寸** | 长字段可加 `class="text-truncate small"` |

### 3.3 应用场景（必加）

| 字段类型 | 示例 | 原因 |
|---------|------|------|
| 自由文本（用户名/姓名/备注） | 用户管理、宿舍档案 | 中英文混杂，长度不可预测 |
| 联系方式（邮箱/手机） | 用户管理 | 邮箱可达 50+ 字符 |
| 角色名称 | 用户管理 | 多角色时可能 >30 字符 |
| 描述类 | 角色管理 | 说明字段经常 >50 字符 |
| IP 地址 | 用户管理 | IPv6 可达 39 字符 |

### 3.4 表格布局建议

```html
<table class="table table-hover mb-0 align-middle" style="table-layout: fixed; width: 100%;">
```

加上 `table-layout: fixed` 后，列宽由表头 `width` 决定，数据内容溢出按 `.text-truncate` 截断。

## 4. Card-header 操作按钮规范

### 4.1 标准样式

```html
<div class="card">
    <div class="card-header bg-light d-flex justify-content-between align-items-center">
        <strong><i class="bi bi-icon"></i> 模块标题</strong>
        <div class="d-flex align-items-center gap-2">
            <span class="text-muted small">共 <strong>@N</strong> 项</span>
            <button class="btn btn-primary btn-sm" data-bs-toggle="modal" data-bs-target="#createModal">
                <i class="bi bi-plus-lg"></i> 新增xxx
            </button>
        </div>
    </div>
    <div class="card-body pb-0">
        <!-- 筛选区 -->
    </div>
</div>
```

### 4.2 强制约束

| 位置 | 强制要求 |
|------|---------|
| **新增/主操作按钮** | 必须位于 card-header 右侧 |
| **图标 + 文字按钮** | `btn btn-primary btn-sm` + `bi-plus-lg` + 文字 |
| **统计/计数显示** | 与按钮并列显示时，必须在按钮**左侧** |
| **删除/独立新增按钮 div** | **禁止**在 table 上方独立放置 |
| **页面 PageHeader** | 如果使用 `@Component.InvokeAsync("PageHeader")`，按钮放 PageHeader；否则放 card-header |

### 4.3 反例

```html
<!-- ❌ 错误：按钮在表格上方 -->
<div class="card-body pb-0">
    <div class="d-flex justify-content-end mb-2">
        <button>新增用户</button>
    </div>
    <table>...</table>
</div>
```

```html
<!-- ✅ 正确：按钮在 card-header -->
<div class="card-header ...">
    <strong>标题</strong>
    <div class="d-flex gap-2">
        <span>共 N 人</span>
        <button>新增用户</button>
    </div>
</div>
```

## 5. 「最后登录」列拆分规范（v2.13.186 修订）

### 5.1 拆分背景

| 维度 | 旧版（合并列） | 新版（拆分两列） |
|------|--------------|----------------|
| 列名 | 最后登录 | 最后时间 + 登录IP |
| 列数 | 1 | 2 |
| 空值占位 | 「从未登录」合并显示 | 「最后时间」列独立显示 |

### 5.2 表头规范

```html
<th class="text-truncate">最后时间</th>
<th class="text-truncate">登录IP</th>
```

### 5.3 数据行规范

```html
<td class="small text-muted text-truncate" title="@(u.LastLoginTime.HasValue ? u.LastLoginTime.Value.ToString("yyyy-MM-dd HH:mm") : "从未登录")">
    @if (u.LastLoginTime.HasValue) {
        @u.LastLoginTime.Value.ToString("yyyy-MM-dd HH:mm")
    } else {
        <span class="text-muted">从未登录</span>
    }
</td>
<td class="small text-truncate" title="@(string.IsNullOrEmpty(u.LastLoginIp) ? "—" : u.LastLoginIp)">
    @if (!string.IsNullOrEmpty(u.LastLoginIp)) {
        <code>@u.LastLoginIp</code>
    } else {
        <span class="text-muted">—</span>
    }
</td>
```

## 7. 配套 CSS 入口

所有规范共用以下 CSS 类（在 `DormManage.Admin/Pages/Shared/_Layout.cshtml` 全局定义）：

| 类名 | 作用 | 定义位置 |
|------|------|---------|
| `.op-btn` | 操作按钮文字化基础类 | `_Layout.cshtml` `.op-btn { display: inline-block; padding: 0; margin: 0; font-size: 0.875rem; color: #1976d2; background: transparent; border: none; cursor: pointer; }` |
| `.op-btn-warning` | 警告（橙色） | `.op-btn-warning { color: #e65100; }` |
| `.op-btn-danger` | 危险（红色） | `.op-btn-danger { color: #c62828; }` |
| `.op-btn-success` | 成功（绿色） | `.op-btn-success { color: #2e7d32; }` |
| `.op-btn-sep` | 按钮间分隔（灰色） | `.op-btn-sep { margin: 0 4px; color: #c0c4ca; user-select: none; }` |

| `.text-truncate` | Bootstrap 文本截断 | Bootstrap 内置（含 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`）|

## 8. 永久教训

1. **禁止在 `<table>` 上方独立放置操作按钮**——必须位于 card-header 右侧或 PageHeader 组件内
2. **禁止使用 `btn btn-sm btn-outline-*` 做行内操作按钮**——必须使用 `op-btn` 纯文字样式
3. **禁止 table 内单元格 icon + 文字混排**——icon 占宽度不可控，会导致行高不一
4. **长字段必须 `text-truncate` + `title`**——缺一不可，否则用户看不到完整内容
5. **`table-layout: fixed` 是 text-truncate 生效的前提**——若使用 `auto`，列宽会被内容撑开，截断失效
6. **`lastlogin` 必须拆分为两列**——单独的列有明确的语义（时间/IP），合并列难以扩展
