### 5.5 办理登记状态（DormBooking.Status）

```csharp
public static class BookingStatus
{
    public const int Reserved = 1;      // 预约
    public const int Staying = 2;       // 在宿
    public const int CheckedOut = 3;    // 已退房
    public const int Cancelled = 4;     // 已取消
}
```

**操作按钮规则**：
- 修改：仅 status=1 预约
- 撤销退房：BookingDate=今天 && status=3 已退房
- 入住：Type=1 && status=1
- 退房：status=2 在宿 或 (Type=2 && status=1 预约)
- 撤销在宿：Type=1 && status=2 && BookingDate=今天
- 撤销预约：status=1
- **删除（v2.13.24 新增）**：status=1 预约 或 status=4 已取消
