# R2R (Research to Report) Skill

Deep research system that takes topics from initial research to comprehensive report generation.

## When to Use

- In-depth research on complex topics
- Generating comprehensive reports
- Multi-source information gathering
- Creating analytical documents
- Thorough investigation of subjects

## Usage

```
/R2R
```

Then provide your research topic or question.

## Process

1. **Research Planning**
   - Define research scope
   - Identify key questions
   - Plan information sources

2. **Information Gathering**
   - Web searches
   - Source evaluation
   - Data collection
   - Fact verification

3. **Analysis**
   - Synthesize findings
   - Identify patterns
   - Evaluate evidence
   - Draw conclusions

4. **Report Generation**
   - Structure document
   - Write content
   - Format for readability
   - Include citations

## Output

- Comprehensive research report
- Structured sections
- Evidence-backed conclusions
- Source citations
- Executive summary (optional)

## Notes

- Uses Tavily for web research
- Can handle multiple rounds of investigation
- Produces publication-ready reports
- Modular structure for customization
