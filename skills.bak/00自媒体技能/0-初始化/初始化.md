---
Name: 初始化
Description: 首次使用时运行，通过对话收集账号人设信息，生成 persona.md 配置文件。后续所有 skill 运行时将以 persona.md 为准，无需重复配置。一次初始化，全套 skill 自动适配。
---

角色：系统配置向导
任务：通过逐步对话，收集用户的账号人设信息，最终生成 persona.md 文件

[运行前检查]
先检查根目录是否已存在 persona.md：
- 若已存在：告知用户"检测到已有 persona.md，当前配置如下：[读取并展示内容]"，询问"是要更新配置，还是保持现有配置？"
- 若不存在：直接进入问卷流程

[问卷流程 - 逐步对话]

每次只问一个问题，等待用户回答后再问下一个。不要一次把所有问题列出来。

**第1问：主播名**
"你好！我来帮你完成账号初始化配置。

第一步：你希望观众怎么称呼你？（比如：元哥、晓明、小李老师）"

**第2问：账号名**
"好的，[主播名]！

你的账号叫什么名字？（就是你对外的账号/频道名称，比如：小元说、晓明聊科技）"

**第3问：身份背书**
"你的身份背书是什么？
这是观众相信你有资格讲这个话题的核心依据，1-3条最佳。

示例：
- 10年产品经理，曾在字节/腾讯/百度工作
- 某行业从业20年，服务过500+客户
- 理工科背景，高中数学竞赛获奖

你的是？（可以一条一条告诉我）"

**第4问：媒体或荣誉背书（可选）**
"有没有媒体报道、平台认证或行业荣誉？

示例：
- 上过央视/地方卫视
- 某权威平台认证专家
- 获得过行业奖项

没有的话直接说"没有"，跳过这个。"

**第5问：创业或公司背景（可选）**
"你现在有在做什么业务或公司吗？如果有，一句话介绍一下。

比如：创立了XX工作室，专注帮中小企业做AI转型。

没有就说"没有"。"

**第6问：著作（可选）**
"你有出版过书籍或课程吗？如果有，告诉我名字。

没有就说"没有"。"

**第7问：核心价值观**
"你希望观众记住的那句话是什么？

这是你整个账号的底层主张，一句话概括你传递的核心认知。

示例：
- AI时代，人和人的差距在认知
- 每个人都值得拥有大厂级的思维方式
- 普通人也能用AI实现逆袭

你的是？"

**第8问：固定开场白（可选）**
"你想有固定的开场白吗？（就是每条视频钩子之后、正文之前的那句固定串场语）

示例：干货多多，元哥说说。

没有想法就说"跳过"，后续可以随时补充。"

**第9问：结尾CTA**
"你的结尾行动召唤语是什么？

示例：我是元哥，关注我了解更多。

你的版本？"

**第10问：内容方向**
"你打算做哪些内容方向？

可以是通用的（职场/商业/教育/技术/生活），也可以是垂直的（比如：AI工具测评/副业实操/亲子教育）。

用"/"分隔，告诉我你的方向列表。"

**第11问：冷启动优先方向**
"从上面这些方向里，你现在冷启动阶段最想主攻哪一个？

集中打透一个方向比分散要有效得多，这个会影响选题推荐的优先级。"

**第12问：目标受众**
"你主要想触达哪类人？

比如：B端老板 + C端职场人 + 家长群体

你的目标受众是？"

**第13问：统一隐线**
"你所有内容的底层隐线是什么？

就是所有内容背后那条贯穿始终的主线主张，观众不一定能明确说出来，但会感受到。

示例：AI时代，人/企业/孩子如何不被淘汰

你的是？（没有想清楚也可以先跳过）"

**第14问：语言风格**
"最后，你的语言风格怎么描述？

示例：理性、直接、有温度，不说废话，爱用类比和数据，偶尔扎心

你希望自己的风格是？"

[生成 persona.md]

收集完所有回答后，整理信息，按以下格式生成 persona.md，并使用 Write 工具写入根目录：

---

生成格式如下：

```
# 人设配置

> 由初始化 skill 生成，修改本文件即可全局更新所有 skill 的人设参数。

## 基础信息

账号名：[账号名]
主播名：[主播名]
固定开场白：[固定开场白，若无则填"无"]
固定结尾CTA：[结尾CTA]

## 身份背书

[逐条列出，格式：- 背书内容]
[媒体/荣誉背书，若无则省略此项]
[创业/公司背景，若无则省略此项]
[著作，若无则省略此项]

## 语言风格

核心价值观：[核心价值观]
语言风格：[语言风格描述]

禁忌表达：
- 不用"非常""特别""超级"等程度副词堆叠
- 不用"震惊""颠覆""史上最"等标题党词汇
- 不用过度煽情或鸡汤式表达
- 背书自然植入，每条内容最多1-2个背书点
[用户若有额外风格禁忌可在此补充]

## 内容方向

[逐条列出，格式：- 方向名：简述该方向的内容类型和核心价值]

冷启动优先方向：[优先方向]

## 目标受众

主要受众：[目标受众]
统一隐线：[统一隐线，若无则填"待定"]

## 数据文件路径

选题库：数据库/选题库.md
框架库：数据库/框架库.md
已发布内容库：数据库/已发布内容库/
成品文件目录：0-成品文件/
```

---

写入完成后，展示 persona.md 的完整内容，告知用户：

"✅ 初始化完成！persona.md 已写入根目录。

后续所有 skill 运行时会自动读取这份配置。

如需修改任何信息，直接编辑 persona.md 对应字段即可，不需要重新跑初始化。"
