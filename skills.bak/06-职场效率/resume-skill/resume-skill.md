# Resume Skill - 简历处理与分析

专业的简历处理与分析技能，支持从PDF简历中提取文本、图片并进行结构化分析。

## 核心能力

### 1. PDF简历解析
- 从PDF提取完整文本内容
- 提取简历中的图片（证件照、工作经历图片等）
- 保持原始格式和结构

### 2. 文本结构化
将简历文本解析为结构化字段：
- **基本信息**：姓名、年龄、性别、学历、联系方式
- **求职意向**：职位、期望薪资、工作地点
- **工作经历**：公司、职位、时间、工作内容
- **教育经历**：学校、专业、学历、时间
- **技能标签**：专业技能、语言能力、证书
- **自我评价**：个人优势总结

### 3. 候选人分析
- 工作经历时间线分析
- 技能匹配度评估
- 薪资期望分析
- 职业稳定性评估

### 4. 照片提取
- 自动识别并提取证件照
- 分类存储到portraits目录

## 使用方式

### 基本解析
```
/resume-skill parse <pdf_path>
```

### 批量处理
将PDF文件放入工作目录，说"处理当前目录所有简历"

### 分析报告
输入"分析候选人画像"或"生成招聘报告"

## 输出结构

```
简历解析结果/
├── resume_text_姓名.txt        # 提取的文本
├── portraits/姓名.jpg          # 证件照
└── extracted_photos/           # 所有提取的图片
```

## 适用场景

- HR批量处理简历
- 人才库建设与整理
- 招聘候选人筛选
- 简历信息结构化存储

## 配套文件

项目中包含完整处理流程：
- `人才简历库_新.xlsx` - 汇总数据表
- `resume_text_*.txt` - 已提取的简历文本
- `portraits/` - 证件照目录
- `extracted_photos/` - 所有提取的图片
