# DCF 估值方法论

> 基于 Anthropic Financial Services Plugins 的投行级 DCF 框架，适配 A股/港股/美股市场。

## 概述

DCF（折现现金流）是绝对估值的核心方法。通过预测未来自由现金流并折现到当前，计算公司内在价值。本方法论遵循投行标准（高盛、摩根士丹利、中金格式）。

## 核心流程

```
历史分析 → 收入预测 → 费用建模 → FCF计算 → WACC计算 → 折现 → 终值 → 企业价值 → 股权价值 → 敏感性分析
```

---

## Step 1: 历史分析（3-5年）

分析并记录以下指标趋势：

| 指标 | 说明 | 关注点 |
|------|------|--------|
| 营收增长 | CAGR，识别驱动因素 | 增速是否放缓？|
| 毛利率 | 产品/服务定价能力 | 趋势是扩张还是压缩？|
| EBIT利润率 | 经营效率 | 管理费用是否随规模下降？|
| 资本密度 | D&A 和 CapEx 占营收比 | 资本开支是维护性还是扩张性？|
| 营运资本效率 | NWC变动占营收增长比 | 应收/存货周转是否恶化？|
| 回报指标 | ROIC, ROE 趋势 | 是否高于WACC？|

**历史指标汇总模板：**

```

```

## Step 2: 收入预测

### 三情景法（Bear/Base/Bull）

| 情景 | 说明 | 典型增速 |
|------|------|---------|
| **悲观（Bear）** | 保守增长，行业下行 | 历史低端 |
| **基准（Base）** | 最可能情景，管理层指引 | 历史中位 |
| **乐观（Bull）** | 市场份额扩张，新业务放量 | 历史高端 |

### 增长率框架

- **Year 1-2**: 近期可见度高，增速较快
- **Year 3-4**: 逐步向行业均值回归
- **Year 5+**: 接近终端增长率

### 公式

```
Revenue(Year N) = Revenue(Year N-1) × (1 + 增长率)
增长率(Year N) = Revenue(Year N) / Revenue(Year N-1) - 1
```

## Step 3: 经营费用建模

### 固定/可变成本分析

| 费用项 | 占营收比（典型范围）| 规模效应 |
|--------|-------------------|---------|
| 销售费用 | 5-30% | 品牌公司随规模递减 |
| 研发费用 | 3-25%（科技公司更高）| 相对稳定 |
| 管理费用 | 3-10% | 随规模显著递减 |

**关键原则：**
- 所有百分比基于 **营收**，不是毛利
- 建模应体现经营杠杆（费用率随营收增长递减）
- 保持各费用项独立（销售、研发、管理分开）

### 利润率扩张框架

```
当前状态 → 目标状态(Year 5)
毛利率: X% → Y% (基于规模/效率提升)
EBIT利润率: X% → Y% (营收增长 + 费用杠杆)
```

## Step 4: 自由现金流计算

### UFCF（无杠杆自由现金流）

```
EBIT
(-) 税收 (EBIT × 税率)
= NOPAT（税后净营业利润）
(+) D&A（非现金费用）
(-) CapEx（资本开支）
(-) Δ NWC（营运资本变动）
= 无杠杆自由现金流 (UFCF)
```

### 各项参数指引

| 项目 | 典型范围 | 说明 |
|------|---------|------|
| D&A/营收 | 2-8% | 轻资产公司较低 |
| CapEx/营收 | 3-10% | 维护性 2-3% + 扩张性 2-5% |
| ΔNWC/Δ营收 | -2% ~ +2% | 负数=现金释放，正数=现金占用 |

### 税率参考

| 市场 | 标准税率 | 说明 |
|------|---------|------|
| A股 | 25% | 高新技术企业 15% |
| 港股 | 16.5% | 境外收入可能更低 |
| 美股 | 21% | 联邦税率，州税另计 |

## Step 5: 资本成本（WACC）

### CAPM 计算权益成本

```
权益成本 = 无风险利率 + Beta × 股权风险溢价

其中：
- 无风险利率 = 对应市场的政府债券收益率
- Beta = 5年月度股票Beta vs 市场指数
- 股权风险溢价 (ERP) = 市场特定
```

### 各市场参数参考

| 参数 | A股 | 港股 | 美股 |
|------|-----|------|------|
| 无风险利率 | 10年期国债 (~2.0-2.8%) | 10年期美债 (~4.0-4.5%) | 10年期美债 (~4.0-4.5%) |
| ERP | 6.0-8.0% | 5.5-7.0% | 5.0-6.0% |
| 典型 Beta | 0.8-1.5 | 0.8-1.3 | 0.8-1.5 |
| **权益成本范围** | **8-15%** | **9-14%** | **8-13%** |

### 债务成本

```
税后债务成本 = 税前债务成本 × (1 - 税率)

税前债务成本来源：
- 信用评级（如有）
- 公司债券当前收益率
- 利息支出 / 有息负债
```

### 资本结构权重

```
股权市值 = 当前股价 × 流通股数
净负债 = 有息负债 - 现金及等价物
企业价值 = 股权市值 + 净负债

股权权重 = 股权市值 / 企业价值
债权权重 = 净负债 / 企业价值

WACC = (权益成本 × 股权权重) + (税后债务成本 × 债权权重)
```

### 特殊情况

- **净现金头寸**：现金 > 负债时，净负债为负数，WACC 需相应调整
- **零负债**：WACC = 权益成本
- **高杠杆**：债权权重大，WACC 受债务成本影响更大

### WACC 典型范围

| 公司类型 | WACC范围 |
|---------|---------|
| 大盘蓝筹 | 7-9% |
| 成长型公司 | 9-12% |
| 高成长/高风险 | 12-15% |

## Step 6: 折现（5-10年预测期）

### 年中惯例

- 假设现金流发生在年中
- 折现期: 0.5, 1.5, 2.5, 3.5, 4.5...
- 折现因子 = 1 / (1 + WACC)^期数

### 现值计算

```
每年:
PV of FCF = UFCF × 折现因子

示例 (Year 1):
FCF = 10亿
WACC = 10%
期数 = 0.5
折现因子 = 1 / (1.10)^0.5 = 0.9535
PV = 10 × 0.9535 = 9.54亿
```

### 预测期选择

| 预测年限 | 适用场景 |
|---------|---------|
| 3年 | 成熟稳定企业 |
| 5年 | 标准分析（最常用）|
| 7-10年 | 高增长企业，长期增长跑道 |

---

## Step 7: 终值计算

### 方法一：永续增长法（首选）

```
终端 FCF = 最后一年 FCF × (1 + 永续增长率)
终值 = 终端 FCF / (WACC - 永续增长率)

关键约束: 永续增长率 < WACC（否则价值无穷大）
```

### 永续增长率选择

| 水平 | 范围 | 适用 |
|------|------|------|
| 保守 | 2.0-2.5% | 成熟行业 |
| 中性 | 2.5-3.5% | 大多数公司 |
| 激进 | 3.5-5.0% | 仅限行业龙头 |

> A股/港股公司可参考中国名义GDP增长率（4-6%），但永续增长率不应超过长期GDP增长。

### 方法二：退出倍数法

```
终值 = 最后一年 EBITDA × 退出倍数

退出倍数来源：
- 行业可比公司交易倍数
- 先例交易倍数
- 典型范围: 8-15x EBITDA
```

### 终值现值

```
PV(终值) = 终值 / (1 + WACC)^最后期数

5年模型+年中惯例: 期数 = 4.5
```

### 终值健康检查

| 终值占EV比重 | 判断 |
|-------------|------|
| < 40% | 终值假设可能过于保守 |
| 50-70% | 合理范围 |
| > 75% | 模型过度依赖终值假设，需审视 |

---

## Step 8: 企业价值到股权价值

```
(+) 预测期FCF现值之和
(+) 终值现值
= 企业价值 (EV)

(-) 净负债 [或 + 净现金]
(-) 少数股东权益（如有）
(-) 养老金负债（如有）
= 股权价值

÷ 稀释后股数
= 每股内在价值

vs 当前股价
= 隐含回报
```

## 行业特定调整

### 高增长科技公司
- 更长预测期（7-10年）
- 更高初始增长率（20-30%）
- 显著的利润率扩张
- 更高WACC（12-15%）
- 建模单位经济（用户数、ARPU等）

### 成熟/稳定企业
- 较短预测期（3-5年）
- 温和增长（GDP +1-3%）
- 稳定利润率
- 较低WACC（7-9%）
- 关注现金生成和资本配置

### 周期性企业
- 建模完整经济周期
- 使用中周期利润率正常化
- 考虑波峰和波谷情景
- 调整Beta以反映周期性

### 多业务板块
- 各业务分别DCF
- 不同增长率和利润率
- 分部加总估值（SOTP）
- 考虑协同效应

## 质量检查清单

- [ ] 数据来源是否明确标注？
- [ ] 净负债/净现金是否正确计算？
- [ ] 稀释后股数是否准确？（注意回购/增发）
- [ ] 历史利润率是否与商业模式一致？
- [ ] 营收增长率是否与行业基准交叉验证？
- [ ] 税率是否合理？
- [ ] 营业费用基于营收（非毛利）？
- [ ] 终值占EV比重在50-70%？
- [ ] 永续增长率 < WACC？
- [ ] 三情景假设是否有充分理由？
- [ ] 敏感性分析是否覆盖关键假设？
- [ ] WACC各参数是否合理？

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 终端增长率 > WACC | 永续增长率必须 < WACC |
| 营业费用基于毛利 | 所有费用率基于营收 |
| 账面价值做资本结构权重 | 用市场价值 |
| 忽略净现金/净负债方向 | 明确区分净负债 vs 净现金 |
| 预测增长率与历史脱节 | 增长率应基于历史趋势和行业约束 |
| 利润率扩张无理由 | 需要经营杠杆或效率提升的论据 |
| 终值占比 >80% | 检查预测期假设是否过于保守 |
