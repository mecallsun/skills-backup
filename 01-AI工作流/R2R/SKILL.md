# /R2R Skill - 从研究到报告的深度研究系统

## 1. 概念与愿景

/R2R 是一个专业的深度研究到报告生成系统。它将复杂的研究课题分解为多个子主题，通过MCP网络搜索服务进行深度研究，最终生成结构化、专业化的Word格式研究报告。系统以金字塔原理组织内容，确保报告逻辑清晰、层次分明、结论先行。

## 2. 工作流程

```
用户输入复杂课题
       ↓
AI分析诊断需求 → 拆解为多个深度研究主题
       ↓
并行深度研究 → 每个主题 >4000字 (MCP搜索)
       ↓
研究成果汇聚 → 整合所有研究成果
       ↓
金字塔原理汇总 → 生成3000字+报告
       ↓
Word文件输出 → 结构化排版
```

## 3. 核心模块

### 3.1 需求分析与主题拆解
- 诊断用户输入的复杂问题/课题
- 识别问题的核心维度
- 拆解为3-6个深度研究主题
- 每个主题明确研究范围和目标

### 3.2 深度研究引擎
- 对每个主题启动独立研究流程
- 使用 mcp__tavily-1__tavily_research 进行深度研究
- 研究深度模式: 全面、透彻、多角度
- 每个主题生成 >4000字 研究内容
- 研究成果自动保存到文件

### 3.3 研究成果管理
- 每个主题的研究成果保存为独立文件
- 文件命名: `研究_[序号]_[主题名].md`
- 研究成果包含: 主题定义、研究发现、关键洞察、数据支撑

### 3.4 报告聚合与生成
- 汇聚所有研究成果
- 应用金字塔原理进行内容组织
  - 核心结论先行
  - 分论点支撑
  - 详细论据底层
- 生成3000字以上汇总报告

### 3.5 Word文档生成
- 标题: 引人思考、有格局的包装
- 副标题: 明确研究范围
- 字体: 微软雅黑
- 最小字号: 11pt
- 结构化排版:
  - 多级标题层级
  - 要点列表
  - 关键数据高亮

## 4. 输出规格

### Word文档格式
- 文件名: `深度研究报告_[课题名]_[日期].docx`
- 标题样式: 居中、加粗、有格局
- 副标题: 课题范围说明
- 正文: 微软雅黑 11pt
- 标题层级: 一级/二级/三级标题
- 段落间距: 1.5倍行高

### 报告结构（金字塔原理）
1. **执行摘要** - 核心发现和结论
2. **研究背景** - 问题背景和研究目的
3. **主题研究汇总** - 各主题研究发现
4. **关键洞察** - 跨主题综合洞察
5. **结论与建议** - 最终结论和行动建议
6. **附录** - 研究方法说明

## 5. 技术实现

- 使用python-docx库生成Word文档
- 研究成果保存为Markdown格式
- 最终报告保存为Word格式

## 6. 使用方式

```
/R2R [复杂课题描述]
```

系统将自动完成从研究到报告的完整流程。
