[指令]
针对 [研究主题]，进行竞争博弈与用户需求分析，要求涵盖：

1. **竞争格局 (Competition Landscape)**：
   - **波特五力量化**：不要只说“强/弱”，要给出理由（例如：供应商议价能力强，是因为核心原材料由 3 家寡头垄断）。
   - **集中度判断**：结合 CR5 (Top 5 市场份额) 数据，判断是“原子型竞争”、“垄断竞争”还是“寡头垄断”。

2. **用户洞察 (User Insights)**：
   - **高颗粒度画像**：
     - **B端**：绘制决策链条（User -> Influencer -> Decider -> Buyer），指出谁拥有“一票否决权”。

   - **KANO 需求分层**：
     - **基本型 (Must-have)**：缺失即淘汰的功能。
     - **期望型 (Performance)**：线性增益功能（如续航里程）。
     - **兴奋型 (Delighters)**：差异化溢价点（如全自动泊车）。

[可视化执行清单]
在报告的对应章节中，使用 Python 插入以下 3 类图表：
1.  **竞争格局矩阵 (Gartner 风格象限图)**：
    - X轴：现有市场份额 (Market Share)
    - Y轴：前瞻性/技术创新力 (Vision/Innovation)
    - **关键动作**：将 3-5 个主要竞品投射在象限中，并用 `plt.text` 标注公司名。
2.  **波特五力雷达图 (Radar Chart)**：
    - 维度：供应商议价、买家议价、新进入者、替代品、同业竞争。
    - 数值：0-10 分（10分代表该项压力极大，利润被严重侵蚀）。
3.  **用户痛点与 KANO 优先级图 (Horizontal Bar Chart)**：
    - Y轴：具体的细分需求（如：续航 > 800km）。
    - X轴：用户关注度/提及率 (%)。
    - 颜色区分：用不同颜色标记 Basic, Performance, Delighter 三类需求。
