[信息检索协议 - 必须执行]
1. **Search First**: 在回答任何具体市场数据、竞争对手动态或技术参数前，必须先启动联网搜索。
2. **Source Quality**: 优先检索以下信源：
   - 上市公司财报 (SEC Filings, Annual Reports)
   - 顶级咨询机构公开摘要 (McKinsey, Bain, Deloitte, Gartner, IDC)
   - 行业垂直媒体 (如 TechCrunch, 36Kr, 行业协会官网)
3. **Citation**: 任何具体数据（如“市场规模200亿”），必须在括号内标注来源和年份。
4. **No Hallucination**: 如果搜索不到确切数据，请使用费米估算（Fermi Estimate）并明确声明“这是基于逻辑的估算”，严禁编造虚假引用。
5. 数据必须在3年内，最多不能超过5年。

[指令]
针对 [研究主题]，生成深度市场分析报告，要求涵盖：

1. **PESTEL 宏观扫描**：
   - **P (Policy)**：列举核心红利政策或合规限制（需引用具体文件名）。
   - **E (Economy)**：分析资本热度、供需变化、成本结构。
   - **S (Society)**：人口结构变化（如少子化、银发经济）对需求的影响。
   - **T (Technology)**：关键技术拐点（如 LLM、边缘计算）。

2. **市场规模测算 (Market Sizing)**：
   - **拒绝黑盒数据**：必须展示推算逻辑（Fermi Problem 费米估算）。
   - **漏斗模型**：
     - TAM (潜在市场总额)：理论上的天花板。
     - SAM (可服务市场)：当前商业模式可触达的范围。
     - SOM (可获得市场)：考虑竞争后的实际份额。
   - **CAGR 预测**：给出未来 3-5 年的增长率预测及理由。

[可视化执行清单]
在报告的对应章节中，使用 Python 插入以下 3 类图表：
1.  **TAM/SAM/SOM 漏斗图**：在“市场规模测算”部分展示，直观体现市场分层。
2.  **市场增长趋势组合图**：在“CAGR 预测”部分展示，使用**双轴图**（柱状图表示市场规模，折线图表示同比增速）。
3.  **驱动力/份额分析图**：在 PESTEL 或竞争分析部分展示，使用饼图（市场份额）或雷达图（各项宏观因子得分）。
