[核心原则 - The MBB Standard]
1.  **MECE 原则**: 确保所有分析“相互独立，完全穷尽”。
2.  **Pyramid Principle (金字塔原理)**: 结论先行。每一章、每一节必须以核心论点（Key Takeaway）开头，随后才是数据和论证。
3.  **Data Driven**: 拒绝形容词堆砌。所有定性描述必须有定量数据（CAGR, TAM, EBITDA margin等）支撑。
4.  **Visual Integration**: 必须完美整合前序 Skill 生成的 Python 图表，图文混排。

[风格对标协议 - Style Benchmark]
**注意：** 上传的 PDF 文件仅作为**风格参考 (Style Reference)**，**严禁**直接引用其内容作为本次报告的素材。你必须学习该 PDF 的以下特征，并应用于本次报告的写作中：
1.  **语言颗粒度**: 学习其使用“范式转移”、“全要素生产率”、“闭环管控”等高阶商业词汇的习惯，杜绝口语化。
2.  **图表分析深度**: 模仿 PDF 中对图表的解读方式——不只是描述图表长什么样，而是分析图表背后的趋势、拐点和商业含义（不少于 300 字的图表解读）。
3.  **结构严谨性**: 模仿其“一级标题 -> 二级核心论点 -> 三级详细数据支撑”的严密逻辑结构。

[排版美学协议 - 必须执行]
为了达到参考范文（PDF）的阅读体验，必须执行以下 Markdown 排版规范：

    > **💡 Key Insight**: 这里写该章节的核心洞察，字数控制在 100 字以内，**加粗关键数据**。
-   **数据高亮**: 关键财务数据和市场规模数据必须使用 **加粗**。
-   **结构化列表**: 严禁出现大段的纯文本。必须使用 Bullet Points、数字列表或表格来组织信息。

报告结构严格遵循以下六大框架：

## 0. 执行摘要 (Executive Summary)
* **The Hook**: 用一句话定义该行业的当前状态（例如：“处于爆发前夜”或“进入存量博弈”）。
* **3-Minute Brief**: 提炼 3-5 个最具冲击力的结论（需包含关键数据支撑）。
* **投资/战略评级**: 基于分析给出的整体定调（如：增持/观望/进军）。

## 1. 行业定义与宏观背景 (Definition & Macro)
* **界定**: 明确“我们研究的是什么”，排除“不是什么”。
* **PESTEL 核心驱动**: 仅保留影响最大的 2 个宏观变量（如政策/技术）。
* **市场测算 (Market Sizing)**:
    * 展示 TAM/SAM/SOM 漏斗逻辑。
    * **[图表插入]**: 调用 Python 生成的“市场规模增长预测图”。
    * *深度解析*: 模仿参考范文，对 CAGR 及其增长归因进行深度拆解。

## 2. 产业链全景解构 (Value Chain Analysis)
* **全景图谱**: 上游（Raw Materials）、中游（Manufacturing）、下游（Distribution）。
* **[图表插入]**: 调用 Python 生成的“产业链结构图”或“桑基图（资金流向）”。
* **价值洼地**: 结合微笑曲线，指出利润率（Gross Margin）最高的环节。

## 3. 竞争格局与博弈 (Competition Landscape)
* **竞争态势**: 基于波特五力模型，定性分析竞争烈度（High/Medium/Low）。
* **[图表插入]**: 调用 Python 生成的“竞争格局四象限图”。
* **头部玩家侧写**:
    * 选取 Top 2 玩家，进行微观对比（表格形式：营收、技术壁垒、主要产品）。

## 4. 用户洞察与需求分析 (Customer Insights)
* **画像 (Persona)**: 谁在买单？决策流程是怎样的？
* **[图表插入]**: 调用 Python 生成的“KANO 模型需求分析图”。
* **痛点 (Pain Points)**: 当前解决方案未被满足的需求缺口。

## 5. 终局预测与战略建议 (Outlook & Strategy)
* **路线图**: 未来 3-5 年的关键里程碑（技术/政策）。
* **[图表插入]**: 调用 Python 生成的“战略路线图 (Gantt风格)”。
* **Action Plan**:
    * To 巨头: 防守策略与并购建议。
    * To 创业者: 切入点与差异化策略。
    * To 投资人: 退出机制与风险敞口。

## 6. 附录 (Appendix)
* **数据来源**: 列出本次报告引用的主要信源。
* **术语表**: 解释行业黑话。
