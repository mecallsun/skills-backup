# /R2R 全局决策研究智能体（Research to Decision）

## 1. 一句话定义

把任何"复杂决策 / 待研究课题"自动跑通 **7 步标准流程**，输出 **微软雅黑** 排版的 `深度研究报告_[课题]_[YYYYMMDD].docx`。

## 2. 7 步硬约束（不可省略、不可改顺序）

| 步骤 | 动作 | 强制要求 |
|---|---|---|
| ① 用户输入 | 用户给一句话课题 | — |
| ② 设计选择题追问 | AI 设计 **3-5 个选择题**（必须是 A/B/C/D 单选或多选，**严禁问答题**） | 每题 ≥2 选项、≤5 选项；选项互斥穷尽 |
| ③ 拆题 | AI 根据用户回答拆解为 **3-6 个深度研究主题** | 每个主题含 `id / theme / focus` |
| ④ 深度研究 | 每个主题调用 MCP Tavily/EXA 深研；**单主题 >4000 字**；成果**全部独立保存**为 `研究_[id]_[safe_topic]_[theme].md` | 数据**带出处**；"近两年、查不到别编" |
| ⑤ 第二轮选择题追问 | 结合研究再做 **3-5 个选择题**（仍必须是选择题，**严禁问答题**） | 用于补充研究盲区 |
| ⑥ 聚合 | 拼接所有研究 Markdown | — |
| ⑦ 金字塔汇总 + Word | 应用金字塔原理生成 ≥3000 字汇总 → 生成 .docx | 标题（引人思考/有格局）+ 副标题；**微软雅黑** |

## 3. 触发条件

**强触发**（任一命中即调用）：

- 用户输入 `/R2R [复杂课题]`
- 用户输入"我要一份万字报告"+"[课题]"
- 用户输入"做个深度研究"+"[课题]"
- 用户描述一个含多重未知因素的决策问题（如"我们要不要进入 X 市场"、"转型 Y 还是 Z"）
- 用户要求"金字塔原理组织内容"

**慎触发 / 不触发**：

- 单点事实问答（直接回答即可）
- 单纯代码生成（用对应编程技能）
- 短消息闲聊

## 4. 字体与排版策略（**通用版路线**）

| 元素 | 字体 | 字号 | 颜色 / 排版 |
|---|---|---|---|
| 主标题 | 微软雅黑 | 18 pt 加粗居中 | RGB(0,51,102) 深蓝 |
| 副标题 | 微软雅黑 | 14 pt 居中 | RGB(89,89,89) 灰 |
| 一级标题 | 微软雅黑 | 16 pt 加粗 | RGB(0,51,102) 深蓝 |
| 二级标题 | 微软雅黑 | 14 pt 加粗 | 黑 |
| 三级标题 | 微软雅黑 | 13 pt 加粗 | 黑 |
| 正文 | 微软雅黑 | 11 pt | 黑、行距 1.5、首行缩进 2 字符 |

**实现要点**：用 `python-docx` 时必须显式设置 Normal style 的 `eastAsia` 与每个 run 的 `font.name` —— 不显式覆盖时 Word 不会按中文微软雅黑渲染（这是最常见的坑）。

```python
from docx.oxml.ns import qn
style = doc.styles['Normal']
style.font.name = '微软雅黑'
style._element.rPr.rFonts.set(qn('w:eastAsia'), '微软雅黑')
# 每个 run:
run.font.name = '微软雅黑'
run._element.rPr.rFonts.set(qn('w:eastAsia'), '微软雅黑')
```

## 5. MCP 集成与降级策略

| 优先级 | 调用源 | 用途 |
|---|---|---|
| 1️⃣ | `mcp__tavily-3__tavily_research`（model="pro"） | 主深度研究 |
| 2️⃣ | `mcp__tavily-1__tavily_research` / `mcp__tavily-2__tavily_research` | 备选深度研究 |
| 3️⃣ | `mcp__exa-1__web_search_exa` | 英文深度 / 学术兜底 |
| 4️⃣ | 宿主 `WebSearch` 工具 | MCP 完全不可用时降级 |
| 5️⃣ | `_simulate_deep_research` 占位内容 | 仅作"无任何搜索源"占位，**输出文件需显式标注 `[SIMULATED]`** |

调用遵循用户全局 KEY 资源池规范（CLAUDE.md 已固化，跨平台轮询）。

## 6. 选择题追问规范（步骤 ② 与 ⑤）

每次 3-5 题，**必须**用选择题模板：

```markdown
**追问 N：<问题>**
- A. <选项 1>
- B. <选项 2>
- C. <选项 3>
- D. <选项 4>
（推荐 ≤2 项，可多选时显式说明）
```

**禁**：

- 问答题（如"请详细描述你的目标"）
- 模糊题（如"还有其他需要吗"）

## 7. 金字塔原理汇总结构（步骤 ⑦）

```
主标题（引人思考/有格局）+ 副标题
├── 执行摘要（核心结论先行）
├── 一、研究背景与目的
├── 二、主题研究发现（每个主题一节）
│   ├── 2.X.1 研究概述
│   ├── 2.X.2 核心发现
│   ├── 2.X.3 深度分析
│   └── 2.X.4 关键洞察
├── 三、跨主题综合洞察
├── 四、结论与建议
│   ├── 4.1 核心结论
│   ├── 4.2 战略建议
│   └── 4.3 行动计划
└── 五、研究方法说明
```

## 10. 失败与边界

| 失败 | 行为 |
|---|---|
| 用户未输入课题 | 提示"请输入研究课题"；不进入流程 |
| MCP 完全不可用 + 无 `WebSearch` | 显式提示"无法连接外部研究源"，仅使用占位内容，Word 文件标记 `[SIMULATED]` |
| 选题拆解不足 3 个 | 强制补足到 3 个（按"背景/核心要素/方案"通用模板） |
| 主题研究字数 <4000 | 重试一次；仍不足则**显式标注实际字数** |
| 汇总字数 <3000 | 强制扩写"跨主题综合洞察"章节至 ≥3000 字 |
