## 学员基本盘

| 项 | 值 |
|---|---|
| 身份 | 佛山一家跨境电商公司创始人 |
| 主营品类 | 小家电 + 家居用品 |
| 渠道 | 亚马逊美国站 + 欧洲站 |
| 店铺数量 | 5 个 |
| 体量 | 约 3 亿人民币（原 prompt 文字为 "3人民币"，量纲缺失，推断为"亿"） |
| 品牌状况 | **全部为白牌** |
| 核心指标 | **ACOS 已涨到 28%**、**净利率 <5%** |

## 现状痛点

1. 九成销量靠广告驱动
2. ACOS 持续走高，广告 ROI 压力巨大
3. 净利率被压到 5% 以下，几乎无安全垫
4. 白牌无品牌溢价，无复购积累

## 学员明确想研究的问题（来自 prompt）

1. **别人踩过的坑** — 同行 / 标杆企业的失败案例与教训
2. **SKU 该按什么标准砍** — 砍 SKU 的判断模型
3. **独立站和亚马逊的流量配比怎么规划** — 双引擎流量结构
4. **转型期现金流怎么撑过去** — 财务安全垫

## 转型方向

**铺货模式 → 精品品牌模式**

具体动作：

- 砍 SKU，聚焦 2-3 个核心类目
- 注册自有品牌（商标 + 专利 + 包装 + VI）
- 建独立站（DTC，沉淀用户）
- 提高客单价 + 复购率
- 摆脱对单一渠道（亚马逊广告）的依赖

## R2R 推荐拆题（已固化进 r2r_skill.py）

| 5 | 品牌注册与合规壁垒 | 商标 / 专利、海外仓 / FBA、VAT / FDA / FCC |

## 用户硬要求（来自 prompt）

- "我要一份**万字报告**" → 单主题深研字数 ≥4000 + 主题数 ≥5 → 总量 ≥20000 字
- 汇总章节字数 ≥3000（默认下限）
- **最终成果必须是 Word 文件**，结构化排版
- 主标题：引人思考、显格局
- 副标题：明确研究范围
- **字体：微软雅黑**（通用版路线）

## 标杆研究参考

- **安克创新 Anker**：从亚马逊 3C 卖家到全球品牌，亚马逊 + 独立站协同；可作为转型范本
