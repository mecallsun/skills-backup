# 投资分析框架

## 分析目标

为投资者提供全面、客观、深入的公司分析，帮助做出明智的投资决策。

## 核心原则

1. **客观性**：基于数据和事实，避免主观臆断
2. **全面性**：覆盖行业、商业模式、财务、竞争、估值等多个维度
3. **深度性**：不仅看表面数字，更要理解背后的商业逻辑
4. **实用性**：提供可操作的投资建议

## 分析框架

### 1. 行业分析（自上而下）

**目的**：理解公司所处的外部环境

**关键问题**：
- 这是一个好行业吗？（市场空间、增长性）
- 行业竞争激烈吗？（竞争格局）
- 公司在行业中的位置如何？（市场地位）

**分析要点**：
- 行业市场规模（TAM）
- 行业增长率（CAGR）
- 行业集中度（CR5、HHI）
- 行业驱动因素
- 行业周期性
- 公司市场份额和排名

### 2. 商业模式分析（核心）

**目的**：理解公司如何赚钱，为什么能赚钱

**关键问题**：
- 公司为客户创造什么价值？
- 公司如何获取收入？
- 公司的成本结构如何？
- 公司有什么竞争壁垒？

**分析框架**：
```
价值主张 → 客户细分 → 收入模式 → 成本结构 → 竞争壁垒
```

**竞争壁垒类型**：
- **技术壁垒**：专利、技术领先
- **品牌壁垒**：品牌认知、客户忠诚度
- **规模经济**：成本优势
- **网络效应**：用户越多价值越大
- **转换成本**：客户切换成本高
- **监管壁垒**：牌照、资质

→ 详见 `competitive_analysis.md` 竞争壁垒评分方法

### 3. 竞争格局分析

**目的**：量化公司在行业中的竞争地位，识别威胁和机会

**核心工具**：
- **2×2 竞争定位矩阵**：竞争优势强度 × 市场吸引力
- **波特五力模型**：供应商、买家、新进入者、替代品、行业竞争
- **竞争壁垒评分**：6类壁垒各维度 1-5 分
- **市场份额追踪**：份额变化趋势分析

**关键结论**：
- 公司护城河宽窄
- 主要竞争威胁来自哪里
- 差异化优势是否可持续

→ 详见 `competitive_analysis.md`

### 4. 财务分析（杜邦框架）

**目的**：量化评估公司的盈利能力和财务健康度

**核心指标**：ROE（股东权益回报率）

**分析框架**：
```
ROE = 净利率 × 资产周转率 × 权益乘数
```

**分析步骤**：
1. 计算 ROE 及三因素（5年数据）
2. 与行业对比
3. 分析趋势变化
4. 结合商业模式解释
5. 识别风险信号

**详细指标**：
- **盈利能力**：毛利率、净利率、ROE、ROIC
- **运营效率**：应收账款周转、存货周转、资产周转
- **财务杠杆**：资产负债率、有息负债率、流动比率
- **现金流**：经营现金流、自由现金流、现金流/净利润
- **成长性**：营收增长率、利润增长率

→ 详见 `dupont_analysis.md`

### 5. 风险分析

**目的**：识别可能影响投资回报的风险因素

**财务风险**：
- **偿债能力风险**：
  - 流动比率 < 1：短期偿债压力
  - 速动比率 < 0.8：流动性风险
  - 资产负债率 > 70%：高杠杆风险
- **现金流风险**：
  - 经营现金流 < 净利润：利润质量问题
  - 自由现金流为负：需要持续融资
- **应收账款风险**：
  - 应收账款/营收 > 30%：回款压力
  - 应收账款增速 > 营收增速：可能虚增收入
- **商誉风险**：
  - 商誉/净资产 > 30%：减值风险
- **债务到期风险**：
  - 短期借款占比高：再融资风险

**竞争风险**（结合竞争格局分析）：
- 市场份额被蚕食
- 护城河被技术颠覆
- 新进入者带来价格战

**市场情绪风险**（基于新闻/web_search）：
- 负面舆论
- 争议性话题
- 投资者担忧的问题

### 6. 估值分析（多方法交叉验证）

**目的**：判断当前股价是否合理

#### 相对估值（Comps）

通过对比同类上市公司估值倍数，判断相对位置：

| 倍数 | 适用场景 |
|------|---------|
| EV/EBITDA | 最通用，跨行业可比 |
| P/E | 成熟盈利公司 |
| EV/营收 | 高增长/尚未盈利公司 |
| P/B | 金融/重资产行业 |
| PEG | 成长股（P/E ÷ 增长率）|

**关键步骤**：
1. 筛选 3-8 家可比公司
2. 计算行业中位数、75分位、25分位
3. 目标公司定位于分布中的位置
4. 判断溢价/折价是否有理由

→ 详见 `comps_methodology.md`

#### 绝对估值（DCF）

通过预测未来自由现金流折现，计算内在价值：

```
企业价值 = Σ(UFCF / (1+WACC)^t) + 终值
每股内在价值 = (企业价值 - 净负债) / 稀释后股数
```

**三情景分析**：

| 情景 | 说明 |
|------|------|
| Bear | 保守增长，利润率承压 |
| Base | 基准情景，管理层指引 |
| Bull | 市场扩张，经营杠杆显现 |

**关键参数（中国市场）**：

| 市场 | 无风险利率 | ERP | WACC典型范围 |
|------|-----------|-----|------------|
| A股 | 10Y国债 ~2.0-2.8% | 6-8% | 8-15% |
| 港股 | 10Y美债 ~4.0-4.5% | 5.5-7% | 9-14% |
| 美股 | 10Y美债 ~4.0-4.5% | 5-6% | 8-13% |

→ 详见 `dcf_methodology.md`

#### 估值交叉验证

```
Comps 估值区间
    ↕ 交叉确认
DCF 内在价值（三情景）
    ↕ 参考
历史估值分位（当前 vs 历史均值）
```

三方法结论一致 → 较强的估值信号
三方法分歧 → 需要识别分歧原因，说明哪个方法更适用

### 7. 投资建议

**目的**：提供可操作的投资建议

**建议框架**：
```
投资逻辑 → 风险收益比 → 操作策略 → 关注要点
```

**投资逻辑**：
- 核心看点（3-5个要点）
- 支撑逻辑
- 预期收益来源（估值修复 / 业绩增长 / 两者兼有）

**风险收益比**：
- 上行空间（基于 Bull 情景）
- 下行风险（基于 Bear 情景）
- 风险收益比评估（建议 ≥ 2:1）

**操作策略**：
- 建议仓位
- 买入时机（估值区间 / 催化剂触发）
- 止损止盈参考位
- 下一次重要数据点（季报、行业数据等）

## 分析流程

### 第一步：快速扫描（30分钟）
- 公司是做什么的？
- 所属行业如何？
- 财务数据是否健康？
- 主要竞争对手是谁？

### 第二步：深度研究（2-4小时）
- 行业深度分析 + 竞争格局
- 商业模式拆解 + 护城河评估
- 财务数据详细分析（杜邦分解）
- 可比公司筛选和 Comps 分析

### 第三步：估值建模
- DCF 三情景（Bear/Base/Bull）
- 敏感性分析（WACC × 永续增长率）
- Comps 估值区间确认

### 第四步：风险评估
- 识别所有风险
- 评估风险严重程度
- 判断风险可控性

### 第五步：形成结论
- 投资逻辑
- 目标价区间
- 投资建议
- 关注要点

## 报告撰写要求

### 1. 结构清晰
- 使用标题层级
- 逻辑连贯
- 重点突出

### 2. 数据准确
- 引用数据要有来源
- 计算要准确
- 使用表格展示关键数据

### 3. 分析深入
- 不仅列数据，更要解释原因
- 结合商业模式分析财务数据
- 识别异常和风险

### 4. 客观中立
- 避免过度乐观或悲观
- 既要看到优势，也要看到风险
- 提供平衡的观点

### 5. 可读性强
- 使用简洁的语言
- 避免过多专业术语
- 重要结论要突出

## 常见陷阱

1. **只看财务数据，不看商业模式**：数字背后的逻辑更重要
2. **只看增长，不看质量**：高增长可能是虚假繁荣
3. **只看优势，忽视风险**：风险往往被低估
4. **只看当前，不看趋势**：趋势比绝对值更重要
5. **只看公司，不看行业**：行业天花板限制公司成长
6. **DCF 终值占比过高**：终值 >75% 意味着结论高度依赖长期假设
7. **Comps 同质性不足**：不可比的公司放在一起会误导结论
8. **估值方法单一**：单一方法容易偏差，需要交叉验证

## 质量检查清单

### 完整性检查
- [ ] 行业分析是否全面？
- [ ] 商业模式是否清晰？
- [ ] 竞争格局是否分析？（护城河、五力模型）
- [ ] 财务分析是否深入？
- [ ] ROE 三因素是否分解？
- [ ] 风险是否充分识别？
- [ ] 估值是否用多方法交叉验证？
- [ ] 投资建议是否明确？

### Comps 质量
- [ ] 可比公司确实可比？（业务模式、规模）
- [ ] 数据时间段一致？
- [ ] 统计量（中位数、四分位）已计算？
- [ ] 目标公司定位结论明确？

### DCF 质量
- [ ] WACC 参数是否合理？（使用市场适配值）
- [ ] 永续增长率 < WACC？
- [ ] 终值占 EV 比重在 50-70%？
- [ ] 三情景假设有充分依据？
- [ ] 敏感性分析是否覆盖？

### 数据和引用
- [ ] 数据引用是否准确？
- [ ] 逻辑是否连贯？
- [ ] 结论是否客观？
