# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 全局规则

**所有 skill 执行前，必须先读取根目录的 `persona.md`**，将其中的账号名、主播名、身份背书、CTA、内容方向、目标受众等参数代入 skill 的对应位置，覆盖 skill 文件内的任何硬编码人设信息。

首次使用时，先调用 `0-初始化/初始化.md` 生成 `persona.md`，之后无需重复初始化。

所有文件路径均为相对于仓库根目录的相对路径。

---

## 仓库用途

本目录是一套**AI驱动的自媒体内容生产系统**，包含从选题到发布的完整工作流，由多个专用 skill 提示词文件组成。所有 `.md` 文件均为人工智能提示词（skills）或内容数据库，不含可执行代码。

## 账号人设核心

**人设配置统一存放在根目录 `persona.md`**，首次使用前运行 `0-初始化/初始化.md` 生成该文件。

`persona.md` 包含：主播名、账号名、身份背书、核心价值观、固定开场白、固定结尾CTA、内容方向、冷启动优先方向、目标受众、统一隐线、语言风格。

所有 skill 运行时以 `persona.md` 为准，不使用各 skill 文件内的硬编码人设值。

## Skill 工作流

内容生产的标准流水线，按序调用：

| 编号 | Skill 文件 | 职责 |
|------|-----------|------|
| 0 | `0-初始化/初始化.md` | **首次使用必跑**，生成 persona.md 人设配置文件 |
| 1 | `1-研究规划/研究规划师.md` | 输入选题关键词 → 拆解子主题 + 生成研究提示词 |
| 2 | `2-深度研究/深度研究员.md` | 针对单个子主题 → 输出结构化研究报告（≥1500字）|
| 3 | `3-内容库整合/内容库整合师.md` | 整合多份研究报告 → 按钩子/论据/故事/金句分类 |
| 4 | `4-脚本创作/脚本创作师.md` | 基于素材库 → 生成完整口播脚本（含制作版+口播版）|
| 11 | `11-人设守护/人设守护者.md` | 发布前最终检查，防止人设漂移 |

**选题类型决定流程分支：**
- **类型A（经验/观察类）**：直接进脚本创作师
- **类型B（事件评论类）**：必须先走研究规划师→深度研究员
- **类型C（方法论/干货类）**：用户提供框架后适当补充数据

## 运营管理 Skill

| Skill 文件 | 职责 |
|-----------|------|
| `5-选题管理/选题管家.md` | 记录选题想法/检索已有资产/更新状态（想法→已复盘）|

| `7-方法论沉淀/方法论沉淀师.md` | 将复盘结论提炼为可复用框架，写入框架库 |
| `8-工作流优化/工作流优化师.md` | 每10条内容后调用一次，收集反馈并改进各 skill |
| `9-竞品观察/竞品观察师.md` | 分析同类账号爆款，识别差异化机会 |
| `10-选题日历/选题日历.md` | 管理发布排期、热点借势分析 |

**选题雷达触发方式：**
- 直接触发（不带关键词）→ 自主扫描，输出本周候选清单（3-6条雷达卡）
- 定向触发："帮我看看[关键词/事件]值不值得做"
- 竞品触发："[账号名]最近有条视频很火，帮我分析"（C类跟拍评估）

## 成品文件规范

路径：`0-成品文件/`
命名：`[3位流水号]-[选题关键词]-[时长]-[平台].md`（示例：`036-AI职场竞争力-5分钟-抖音视频号.md`）
新建文件前务必用 `ls 0-成品文件/` 确认当前最大流水号，在此基础上递增。

每个文件必须包含两部分：
1. **制作版**：带时间标注 `[0:00-0:15 钩子]`、情绪锚点 `[情绪锚点：危机感]` 的完整脚本 + 附件（金句/封面标题/话题标签）
2. **口播版**：去掉所有标注，连续段落格式，可直接复制进口播软件

时长参考：1分钟≈200字，5分钟≈1000字，10分钟≈2000字

## 脚本结构规范

固定开头：`[钩子] → [persona.md 固定开场白，若无则直接进正文]`
固定结尾：`persona.md 固定结尾CTA`

钩子三选一：数据冲击 / 地点+事件+冲突三合一 / 身份代入（前3秒必须出现核心关键词）

四段结构：
1. **钩子**（前15秒，10%）
2. **建立信任**（10-20%，≤30秒，自然植入人设背书）
3. **核心内容**（50-60%，每观点≤90秒，先现象→再本质→再结论）
4. **情绪收尾**（15-20%，扎心结论→给出希望→CTA）

## 封面设计规范

每条视频必须输出三要素：
- **主钩**：5字以内，用数字/反差词/身份词
- **标题1**：9字以内
- **标题2**：9字以内（与标题1为递进或分行关系）

## 人设语言风格禁忌

❌ 书面感强、口语拗口的词（"今天还不存在"→改为"今天还没有"）
❌ "非常""特别""超级"等程度副词堆叠
❌ "震惊""颠覆""史上最"等标题党词汇
❌ "小白都能学会""保姆级教程"等低端定位
❌ 过度煽情或鸡汤式表达
❌ 背书生硬堆砌（每条内容最多1-2个背书点）

## 发布时间参考

- 抖音：工作日 12:00-13:00 或 18:00-20:00
- 视频号：工作日 7:00-9:00 或 20:00-22:00
- 复盘时机：抖音发布48小时后，视频号发布72小时后

## 修改 Skill 的原则

直接编辑对应 skill 的 `.md` 文件。使用工作流优化师（`8-工作流优化/工作流优化师.md`）做系统性改进时，改动须记录进 `数据库/框架库.md` 末尾的「工作流进化日志」区块。
