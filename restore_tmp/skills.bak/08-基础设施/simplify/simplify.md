# Simplify Skill

Review code for improvements in reuse, quality, and efficiency, then apply fixes.

## When to Use

- Refactoring code
- Cleaning up redundant or complex code
- Improving code quality and maintainability
- Finding reusable patterns
- Fixing performance issues
- Reducing code duplication

## Usage

```
/simplify
```

## Process

1. **Scan** - Analyze the code for:
   - Duplicate code that could be consolidated
   - Complex logic that could be simplified
   - Functions that could be more generic/reusable
   - Unnecessary abstractions
   - Performance bottlenecks

2. **Report** - Present findings with:
   - Specific locations (file:line)
   - What the issue is
   - Why it matters
   - Suggested fix

3. **Fix** - Apply improvements with user approval

## Focus Areas

- Eliminate dead code and comments
- Consolidate similar logic
- Simplify complex conditionals
- Improve naming clarity
- Extract reusable utilities
- Reduce file complexity
- Optimize performance
