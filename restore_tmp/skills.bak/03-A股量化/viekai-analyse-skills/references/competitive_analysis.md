# 竞争分析方法论指南

> 投行级竞争分析框架，适配 A股 / 港股 / 美股

---

## 1. 概述

竞争分析回答的核心问题：**这家公司凭什么赢，能赢多久，赢多少？**

### 适用场景

| 场景 | 用途 |
|------|------|
| 首次覆盖报告 | 建立行业竞争格局基准 |
| 估值锚定 | 支撑终端增长率假设 |
| 可比公司筛选 | 剔除业务模式不同的"假可比" |
| 风险识别 | 发现潜在颠覆者或份额侵蚀者 |
| 催化剂追踪 | 竞争格局变化即为估值重估信号 |

### 分析顺序

```
行业边界界定 → 五力模型 → 竞争壁垒评分 → 市场份额追踪 → 对手画像 → 差异化定位
```

---

## 2. 核心框架：竞争定位矩阵

以 **2×2 矩阵** 快速锚定公司战略位置：

- **X 轴**：竞争优势强度（1–5，弱→强）
- **Y 轴**：市场吸引力（1–5，低→高，综合市场规模、增速、利润率）

```
高市场吸引力
        │  [明星区]          [王者区]
        │  安踏体育           美团
        │  高增长市场，        平台网络效应 +
        │  壁垒仍在构建中      规模已形成护城河
        │
        │  [弃守区]          [现金牛区]
        │  低壁垒红海          格力电器
低市场吸引力 │  价格战主导          成熟市场 + 强品牌
        └─────────────────────────────
         弱竞争优势              强竞争优势
```

**如何定位公司：**
1. 市场吸引力：用 TAM 增速 × 行业平均 ROIC 打分
2. 竞争优势：用第4节壁垒评分的加权均值
3. 箭头方向代表战略方向（公司自我定位 vs 实际位置的差距即为风险）

## 3. 波特五力模型（中国市场适配）

> 原始五力需根据中国市场特点调整：政策因素作为"第六力"单独列出。

| 力量 | 评分维度 | 中国市场特殊考量 | 案例 |
|------|---------|----------------|------|
| **现有竞争者** | 竞争者数量、价格战频率、产能利用率 | 地方国企保护、补贴导致劣势方不退出 | 光伏行业：央企背书导致产能长期过剩 |
| **潜在进入者** | 资本壁垒、牌照要求、技术门槛 | 互联网企业跨界频繁、国家队可随时入场 | 美团进入医疗健康、外卖 |
| **替代品威胁** | 功能替代率、价格比较、转换成本 | 国产替代是系统性力量，非市场竞争 | 泡泡玛特对比普通玩具：情绪价值难替代 |
| **供应商议价** | 集中度、专用资产、向前整合能力 | 国有原材料供应商议价强，长协价保护弱 | 安踏：鞋底原材料集中，议价受限 |
| **买方议价** | 客户集中度、标准化程度、后向整合 | 电商平台作为渠道方议价强，挤压品牌商 | 消费品牌面临抖音、天猫的流量依赖困境 |
| **政策监管**（第六力）| 行业政策稳定性、牌照周期、反垄断 | 平台经济、教育、地产均有系统性政策风险 | 2021年教育双减：行业定价权归零 |

**评分规则**：每项 1–5 分，5 = 对企业威胁最大。总分越高，行业越不友好。

## 4. 竞争壁垒分析（护城河评分）

### 壁垒类型与评分标准

| 壁垒类型 | 1分（无） | 3分（中） | 5分（强） | 权重建议 |
|---------|---------|---------|---------|---------|
| **技术/IP** | 无专利，技术通用 | 有专利但可绕开 | 核心技术专利 + 持续研发壁垒 | 20% |
| **品牌** | 白牌，价格敏感 | 区域/品类知名品牌 | 溢价 20%+ 且用户忠诚度高 | 20% |
| **网络效应** | 用户间无互动价值 | 局部网络效应 | 全平台双边/多边网络效应 | 20% |
| **转换成本** | 随时可换，零成本 | 有数据迁移成本 | 深度集成，换出成本极高 | 15% |
| **规模经济** | 规模无成本优势 | 采购/物流有规模优势 | 边际成本接近零的规模优势 | 15% |
| **监管/牌照** | 无监管保护 | 牌照有限但可申请 | 稀缺牌照 + 高进入壁垒 | 10% |

### 雷达图描述（文字版）

```
泡泡玛特护城河评分：
  技术/IP     ██░░░  2  （设计IP，非技术壁垒）
  品牌        █████  5  （盲盒情绪溢价，IP稀缺性强）
  网络效应    ███░░  3  （Popmart App收藏社区）
  转换成本    ███░░  3  （收藏系列具粘性，但可转移）
  规模经济    ████░  4  （柔性供应链 + 全球快速复制）
  监管/牌照   ██░░░  2  （无特殊监管保护）
  加权总分：3.55 / 5
```

> **判断标准**：加权分 ≥4.0 = 强护城河；3.0–4.0 = 中等；＜3.0 = 脆弱，需在估值中打折。

## 5. 市场份额分析

### 追踪指标

| 指标 | 计算方式 | 意义 |
|------|---------|------|
| **CR5** | 前5名市占率之和 | 行业集中度；CR5＞70%=寡头市场 |
| **HHI** | Σ(各公司市占率²) | ＞2500=高度集中；＜1500=分散 |
| **份额变化速度** | 季度同比增减 bp | 加速得分 = 护城河增强信号 |
| **份额与利润率背离** | 份额↑但利润↓ | 价格战换量，不可持续 |

### 份额变化解读

```
份额加速扩张（+2%+/年）→ 竞争优势强化 → 估值溢价支撑
份额平稳（±0.5%）      → 格局稳固 → 按基准估值
份额缓慢失血（-1%/年）  → 警惕颠覆者 → 终端增速下调
份额快速崩塌（-3%+/年） → 战略失误或颠覆性竞争 → 重新评估商业模式
```

**安踏案例**：2019–2023年安踏集团（含FILA、始祖鸟）在中国运动鞋服市占率从15%→22%，同期李宁从10%→15%，耐克从28%→22%。份额转移速度加快 → 支撑安踏估值从20x PE扩张至30x。

## 7. 差异化分析

将竞争维度拆解为三类：

| 类别 | 定义 | 策略含义 |
|------|------|---------|
| **赢面** | 我方明显领先，客户认可 | 保持投入，放大优势 |
| **正面交锋** | 势均力敌，价格竞争激烈 | 控制资源消耗，寻找差异化切入点 |
| **劣势区** | 对手明显领先 | 主动放弃或选择差异化路线绕开 |

**差异化矩阵（泡泡玛特 vs 52TOYS）**：

| 竞争维度 | 泡泡玛特 | 52TOYS | 判断 |
|---------|---------|--------|------|
| IP 丰富度 | ✅ 100+ IP | ⚡ 20+ IP | 泡泡玛特赢面 |
| 国际化布局 | ✅ 全球门店 | ❌ 以国内为主 | 泡泡玛特赢面 |
| 盲盒外产品线 | ❌ 薄弱 | ✅ 积木/手办更丰富 | 正面交锋/52TOYS局部优势 |
| 价格带 | 中高 59–699 | 中 39–399 | 细分市场，非直接交锋 |

## 8. 整合到分析报告

### 影响 DCF 的关键节点

| DCF 假设 | 竞争分析输入 |
|---------|------------|
| **收入增速（预测期）** | 市场份额趋势 × TAM 增速 |
| **毛利率走势** | 竞争壁垒强度决定定价权 |
| **终端增长率（TV）** | 护城河评分：≥4.0 可用 4–5%；＜3.0 建议 2–3% |
| **WACC 风险溢价** | 五力模型总分高 → 适当上调行业风险溢价 |

### 影响可比公司筛选

```
真正可比的标准：
  ✅ 同一业务模式（非仅同一行业）
  ✅ 相近的竞争壁垒类型
  ✅ 相近的市场份额成熟度（成长期 vs 成熟期）
  ❌ 剔除：靠政策保护的国企（壁垒性质不同）
  ❌ 剔除：规模差异超过10x（护城河构成不同）
```

**示例**：泡泡玛特的可比公司应包含 Funko（美股）、Sanrio，而非普通玩具制造商如孩之宝——后者是规模制造业逻辑，前者是IP情绪溢价逻辑。

## 9. 质量检查清单

完成竞争分析后，逐项确认：

- [ ] 行业边界是否清晰定义（按产品/地域/客群）
- [ ] 五力模型是否加入政策/监管作为第六力
- [ ] 护城河评分是否有具体数据支撑（非主观判断）
- [ ] 市场份额数据来源是否可靠（行业协会/公司披露/第三方数据）
- [ ] 对手画像是否覆盖潜在颠覆者（不只是现有竞争者）
- [ ] 差异化矩阵是否基于客户视角（非公司视角）
- [ ] 竞争分析结论是否已传导到 DCF 终端增长率假设
- [ ] 可比公司选择是否经过竞争逻辑验证
- [ ] 是否识别出未来12个月内可能改变竞争格局的催化剂
