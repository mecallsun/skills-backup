# 可比公司分析方法论

> 基于 Anthropic Financial Services Plugins 的投行级 Comps 框架，适配 A股/港股/美股市场。

## 概述

可比公司分析（Comps）通过对标同行业/同赛道上市公司的估值倍数，评估目标公司的相对价值。核心逻辑：类似的公司应该有类似的估值。

## 适用场景

**适合：**
- 上市公司相对估值
- 同行业业绩对标
- IPO/融资定价参考
- 识别估值异常（高估/低估）
- 投委会汇报

**不适合：**
- 无可比上市公司的私有企业
- 高度多元化集团
- 困境/破产企业
- 没有收入的初创公司

---

## 核心流程

```
选择可比公司 → 收集数据 → 计算运营指标 → 计算估值倍数 → 统计分析 → 定位目标公司
```

---

## Step 1: 选择可比公司

### 筛选标准

| 维度 | 要求 |
|------|------|
| 业务模式 | 相似的核心业务 |
| 行业 | 同一细分赛道 |
| 规模 | 市值在0.5x-5x范围内 |
| 地域 | 相似的市场环境 |
| 成长阶段 | 成长期/成熟期匹配 |
| 盈利模式 | 收入来源结构相似 |

### 最佳实践

- **3-8家**可比公司最佳，太少缺乏统计意义，太多引入噪音
- 宁可排除不确定的，不要强行纳入
- 如果找不到纯对标，可按业务板块拆分对标

### 数据源

| 市场 | 数据源 |
|------|--------|
| A股 | 巨潮资讯、东方财富、同花顺 |
| 港股 | 巨潮港股频道、Futu API |
| 美股 | SEC EDGAR、Futu API |
| 实时行情 | Futu API (`http://39.96.211.212:15000/api/stock/quote/`) |

---

## Step 2: 运营指标分析

### 核心列（必须包含）

| 指标 | 说明 | 公式 |
|------|------|------|
| 营收 | 规模指标（LTM或年度）| 从财报直接获取 |
| 营收增长率 | 同比增长 | YoY% |
| 毛利 | 营收 - 营业成本 | — |
| 毛利率 | 定价能力 | 毛利/营收 |
| EBITDA | 息税折旧摊销前利润 | — |
| EBITDA利润率 | 经营效率 | EBITDA/营收 |
| 净利润 | 最终盈利 | — |
| 净利率 | 底线盈利能力 | 净利润/营收 |

### 可选指标（按行业选择）

| 行业 | 必须指标 | 可选指标 |
|------|---------|---------|
| **科技/SaaS** | 营收增长、毛利率、Rule of 40 | ARR、净留存率、获客成本 |
| **消费/零售** | 营收增长、毛利率、存货周转 | 同店增长、客单价 |
| **制造/工业** | EBITDA利润率、资产周转率、CapEx/营收 | ROA、订单积压 |
| **金融** | ROE、ROA、效率比率 | 净息差、拨备覆盖率 |
| **互联网** | 营收增长、毛利率、用户数 | ARPU、DAU/MAU、获客成本 |
| **消费品** | 营收增长、毛利率、品牌力 | 渠道结构、SKU数 |

### "5-10法则"

- **5个运营指标**：营收、增长率、2-3个利润率/效率指标
- **5个估值指标**：市值、EV、3个倍数
- = **10列**，足以讲述故事，不至于淹没在数据中
- 超过15个指标，大概率引入了噪音

---

## Step 3: 估值倍数

### 核心倍数

| 倍数 | 公式 | 适用 |
|------|------|------|
| **EV/营收** | 企业价值/营收 | 高增长、尚未盈利公司 |
| **EV/EBITDA** | 企业价值/EBITDA | 最通用的估值倍数 |
| **P/E** | 市值/净利润 | 成熟盈利公司 |
| **P/S** | 市值/营收 | 互联网/SaaS |
| **P/B** | 市值/净资产 | 金融、重资产行业 |
| **PEG** | P/E / 增长率 | 成长股 |

### 可选倍数

| 倍数 | 适用场景 |
|------|---------|
| FCF Yield | 关注现金生成的分析 |
| 股息收益率 | 高分红公司 |
| EV/EBIT | 资本密集度差异大的可比 |

### 企业价值计算

```
企业价值 (EV) = 市值 + 净负债 + 少数股东权益 - 联营投资价值

净负债 = 有息负债 - 现金及等价物
```

### 交叉引用规则

**关键：估值倍数必须引用运营指标部分的数据。** 同一数据不应出现两次。如果营收在指标部分，EV/营收应引用该数据。

---

## Step 4: 统计分析

### 必须计算的统计量

对所有可比指标（比率、利润率、增长率、倍数）计算：

| 统计量 | 说明 |
|--------|------|
| **最大值** | 行业上限 |
| **75分位** | "溢价"公司的位置 |
| **中位数** | 市场典型估值 |
| **25分位** | "折价"区域 |
| **最小值** | 行业下限 |

### 不需要统计量的列

- 绝对规模指标（营收、EBITDA、净利润的绝对值）
- 市值、企业价值（不同规模公司不可比）

### 分位数的意义

- **75分位** = 市场给"优质"公司的估值水平
- **中位数** = 行业典型估值
- **25分位** = 市场给"打折"公司的估值水平

回答核心问题：**目标公司的估值是贵还是便宜？**

---

## Step 5: 目标公司定位

### 定位方法

1. 将目标公司的各项指标放入可比公司统计分布中
2. 判断其在每个维度的分位数位置
3. 综合评估合理估值区间

### 估值推导

```
目标公司合理 EV/EBITDA = 可比公司中位数 × 调整系数

调整系数考虑：
- 增长率高于中位 → 上调
- 利润率低于中位 → 下调
- 市场地位更强 → 上调
- 治理结构较弱 → 下调

目标价 = (合理EV - 净负债) / 稀释后股数
```

## 健全性检查

### 利润率逻辑

```
毛利率 > EBITDA利润率 > EBIT利润率 > 净利率
```

如果不满足，检查数据是否有误。

### 估值合理性

| 倍数 | 典型范围 | 说明 |
|------|---------|------|
| EV/营收 | 0.5-20x | 行业差异大 |
| EV/EBITDA | 6-25x | 跨行业相对一致 |
| P/E | 8-50x | 取决于增长率 |

### 增长-估值相关性

- 更高的增长通常意味着更高的倍数
- 如果一家公司增长最快但倍数最低 → 可能被低估（或有隐藏风险）
- 如果一家公司增长最慢但倍数最高 → 可能被高估（或有独特壁垒）

## 红旗信号

| 信号 | 说明 |
|------|------|
| 🚩 时间段不一致 | 季度和年度混用 |
| 🚩 数据缺失无说明 | 应标注"N/A"并解释 |
| 🚩 负EBITDA用EBITDA倍数 | 应改用营收倍数 |
| 🚩 P/E >100x 无高增长 | 估值可能有泡沫 |
| 🚩 财年结束不同 | 造成时间错配 |
| 🚩 纯业务和多元化集团混比 | 不具可比性 |

## A股/港股特殊考虑

### A股
- 注意壳价值对小市值公司P/B的扭曲
- 北向/南向资金流向影响估值中枢
- 注意ST/*ST公司的剔除
- 同一公司A+H股估值差异（AH溢价）

### 港股
- 注意流动性折价（小盘港股流动性差）
- 中资股 vs 本地股估值差异
- 离岸 vs 在岸资金定价差异
- 注意红筹/H股/中概回港的不同结构

### 跨市场对比
- 使用统一货币（建议人民币或美元）
- 调整税率差异
- 注意会计准则差异（IFRS vs CAS vs US GAAP）
- 考虑汇率风险
