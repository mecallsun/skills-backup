# Lead Get - 客户线索获取助手

帮助你从公开渠道发现和筛选潜在客户信息。

## 何时使用此技能

当你需要：
- 从特定行业/地区寻找潜在客户
- 抓取企业官网的联系方式
- 筛选符合特定条件的公司
- 收集决策者信息（姓名、职位、邮箱）

## 技能边界

✅ **能做什么**：
- 从网页抓取公开的公司信息
- 提取联系方式（邮箱、电话、社交媒体）
- 根据条件筛选和排序线索
- 生成结构化的客户清单

❌ **不能做什么**：
- 抓取非公开信息（需要登录的内容）
- 绕过反爬虫机制
- 批量抓取大量网站（可能被封IP）
- 验证邮箱/电话号码的有效性

## 使用方式

### 方式1：基于网页抓取

**用户输入示例**：
```
帮我抓取这个页面的企业信息：
https://www.example.com/companies

我需要：
- 公司名称
- 联系邮箱
- 电话号码
- 公司地址
```

**Claude会**：
1. 使用web-reader工具读取网页内容
2. 提取企业信息字段
3. 生成结构化的CSV或Excel清单

### 方式2：基于搜索条件

**用户输入示例**：
```
帮我找深圳的制造业企业，要求：
- 员工数50-200人
- 有官网
- 营收5000万以上
```

**Claude会**：
1. 使用搜索工具（Tavily/MetaSo）搜索相关企业
2. 逐一访问公司官网
3. 提取联系信息
4. 按条件筛选和排序

### 方式3：基于已知列表

**用户输入示例**：
```
我有一份公司名单，帮我查找每家公司的联系方式：

[公司列表]
1. 华为技术有限公司
2. 腾讯科技有限公司
3. 比亚迪股份有限公司
```

**Claude会**：
1. 搜索每家公司的官网
2. 提取联系信息（商务合作邮箱、电话）
3. 查找决策者信息（高管/部门负责人）

## 最佳实践

### 1. 明确目标

好的输入：
```
帮我找上海地区的AI公司，员工20-100人，有融资记录，
需要获取CEO或产品负责人的邮箱
```

不好的输入：
```
帮我找一些客户
```

### 2. 控制数量

- 建议每次抓取10-50家公司
- 大量抓取分批次进行
- 避免在短时间内访问同一域名

### 3. 数据验证

**Claude会自动验证**：
- 邮箱格式是否正确
- 电话号码格式是否规范
- 网址是否能访问

**手动验证建议**：
- 抽查10%的线索
- 发送测试邮件验证邮箱
- Google搜索确认公司仍在运营

### 4. 合规使用

- 仅抓取公开信息
- 不抓取个人信息（GDPR等法规）
- 不用于垃圾邮件群发
- 遵守目标网站的robots.txt

## 技术实现

Claude会使用以下工具：

1. **web-reader** (mcp__web-reader__webReader)
   - 读取网页内容
   - 提取文本和结构化数据

2. **Tavily搜索** (mcp__tavily-1__tavily_search)
   - 搜索企业和联系人信息

3. **文件生成**（双模式）
   - **CSV模式**（默认）：生成4个CSV文件，使用UTF-8 BOM编码，可直接在Excel中打开
     - 客户清单.csv
     - 联系方式.csv
     - 渠道合作.csv
     - 行动计划.csv
     - ⚠️ **编码说明**：如果Excel打开乱码，运行 `fix_csv_encoding.ps1` 修复
   - **Excel模式**（需Python）：生成单个Excel文件，含4个工作表
     - 需要 Python 3.7+ 和 openpyxl 库
     - 安装指南：见 `lead-get/安装指南.md`
     - 生成脚本：见 `lead-get/generate_excel.py`

## 限制和注意事项

1. **反爬虫机制**：
   - 某些网站有访问频率限制
   - 建议每次请求间隔2-5秒
   - 避免同时抓取同一域名的多个页面

2. **数据准确性**：
   - 网页信息可能过期
   - 需要定期更新线索库
   - 建议二次验证关键信息

3. **隐私和合规**：
   - 仅抓取B2B企业信息
   - 不抓取个人隐私数据
   - 遵守当地法律法规

## 后续行动建议

抓取到线索后，你可以：

   - HubSpot、Salesforce、钉钉等

2. **启动外呼/邮件营销**

   - A/B测试不同话术

3. **社交媒体连接**
   - LinkedIn添加联系人
   - 关注公司官方账号

4. **定期跟进**
   - 设置提醒间隔（1周/1月/1季度）

## 反馈和优化

如果抓取效果不理想，可以：
- 调整搜索条件（更宽泛或更具体）
- 更换数据源（不同网站/搜索引擎）
- 优化筛选规则（增加或减少条件）
- 手动补充数据（人工验证和补充）
